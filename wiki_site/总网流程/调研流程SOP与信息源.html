  1. 查本地 RAG：ls notes/ + grep -ri "<关键词>" notes/，命中即复用，不重复调研。
  2. 本地未命中 → 调权威源：理论用 arXiv API（UA=Hermes-Agent-Research）/ HuggingFace Papers；工程用 GitHub Trending / Topic。
  3. 结果落盘：命名 主题-YYYYMMDD.md 放 notes/，结构=结论→证据(带 URL/日期)→待验证点→落地建议。
  4. 送 OC + Claude 双审：OC 挑刺找盲点，Claude 交叉验证事实；双审未过回第 2 步补证据，不许直接进执行。
  5. 执行、6. 沉淀、7. 周复盘。
