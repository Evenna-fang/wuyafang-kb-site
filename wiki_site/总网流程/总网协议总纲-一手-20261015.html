# 规则
1 七步+回边：进件分诊→P1 权威信息→计划+审→拆卡派单→执行→验收四门→收口回流；停手/失败/变更走回边 A 回③，验收失败走回边 B 回⑤
2 审查链：OpenClaw→DSH→Claude→Codex，轮 ≤ 2，超 2 报用户；执行期改计划 = 强制重审并记 ⑦
3 白名单+拆卡：派单卡写死"只这 N 件"；大任务拆小卡（单卡单目标），DSH 批量 N=5
4 凭据：密钥/凭据不进卡、不落盘、不复述，走 key 同步链路注入
5 停手规则：撞新门停手 / 同错 3 次停手（指纹去时间戳路径 ID，用 lookup_error.py "<原文>"）/ 空转 5 轮停手 / 超预算 2 倍即停
6 预算档：派单时标档（千/万/十万级），结束回填 plans/token-台账.md
7 台账：⑦ 收口写台账 + evolution-log + 处方进 Gap 到人；动手前先查 error-ledger，命中直接套用
8 绿即停：验收四门全绿即停（自报不采信 / 预埋 check 复跑 / 正负例 ≥ 5 / receipt verify G0–G9）
9 派单前必跑门禁：python3 ~/.hermes/scripts/dispatch-guard.py --task "关键词"，exit=1 不许派
10 派单后定期检查（铁律 2026-10-12）：派单后 5 分钟查 transcript 看子智能体在干啥，10 分钟查进度数字，发现迷路/卡住立刻 steer，不等 30 分钟超时；派单时写清文件路径（别让子智能体自己找）
11 派单前必读现有代码（铁律 2026-10-12）：改代码/配置/灌库类任务，先读现有代码画依赖链、列全步骤再派单；返工超过 1 次 = 规划不全，必须停下重读代码重画依赖链，不能继续派单补漏
12 收口四问：产物落位了吗 / 临时备份删了吗 / 新坑记台账了吗 / 子进程 kill 了吗（available < 1.5G 强制清）

模型切换（多 Agent 共享）：自动 source ~/shared-skills/auto-switch-model.sh <code|math|vision|quick|chat|long|coder>（→ MiMo V2.6 Flash 为主）；手动必须先 --list 展示列表问用户编号、再 switch-model.sh <provider> <编号>，禁止直接带 provider 跑；复盘规则：多 agent 失败复盘先定位 decisive error，只让那个 agent 反思，其余不陪跑。

复盘→技能沉淀（三层落地门禁）：命中"沉淀三问"（Q1 新链接→raw/ · Q2 踩坑→error-ledger · Q3 流程优化→提 Gap）后先判层再写——协议层（AGENTS.md）必须 OC 审通过；记忆层（LEARNING-INDEX.md）Hermes 自审、新条目默认 📋 候选、实战触发 ≥ 3 次后升 ✅ 已验证；技能层（references/）Hermes 自审 + 标来源、触发 3 次才转正。冲突时不写，追加 ⚠️冲突: <现有规则#> 等周复盘。

七、Trace Tampering 防御 + Debate 编排3 个重点▾ 点开看本节重点
本节重点
  • 适用所有【不免凭据】执行类派单
  • 归并规则：两结论一致且置信度都 ≥ 0.7 直接采用；置信度 < 0.7 标 ⚠️；相反且差 ≥ 0.2 高置信优先；差 < 0.2 升人审；任一方说不确定 → OC 慢思考
  • 复杂决策 Debate 编排（防 sycophancy 级联）：选型/架构/排障方向决策，派单卡头加 「mode: debate」，同时发 Claude Code + Codex 独立作答（互不可见），各自输出结论 + 证据 + 置信度 + 自己方案最大弱点；OpenClaw 对比归并

  • Trace Tampering 防御：派单时执行 agent 输出 trace 必须带 sha256sum <file> 哈希写进派单卡 trace_hash；审查时独立比对，不匹配 = 篡改，打回重跑 + 通道降级。适用所有【不免凭据】执行类派单。
  • 复杂决策 Debate 编排（防 sycophancy 级联）：选型/架构/排障方向决策，派单卡头加 mode: debate，同时发 Claude Code + Codex 独立作答（互不可见），各自输出结论 + 证据 + 置信度 + 自己方案最大弱点；OpenClaw 对比归并。归并规则：两结论一致且置信度都 ≥ 0.7 直接采用；置信度 < 0.7 标 ⚠️；相反且差 ≥ 0.2 高置信优先；差 < 0.2 升人审；任一方说不确定 → OC 慢思考。硬终止：轮次封顶 2 轮，每轮证据来自外部，第 2 轮置信度不得比第 1 轮高 ≥ 0.15。

八、派单规范 5 条（2026-09-29 实测踩坑）

3
  1. 派单卡必须标注「子智能体执行」，否则 write-guard 误杀主对话写操作。
