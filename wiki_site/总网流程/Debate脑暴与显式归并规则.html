  1. 派单：同一复杂决策题同时发 Claude Code 和 Codex，互不可见对方产出。
  2. 独立作答：各自输出 = 结论 + 证据 + 置信度(0–1) + 反对意见（自己方案的最大弱点）。
  3. OpenClaw 对比归并：OC 只做对照，不做新推理。
  4. 显式归并规则（下表）。
  5. 硬终止：任一条件触发即停，不进第 2 轮。

归并规则（预定义，不临场发挥）

3
情形 归并动作
两结论一致 + 置信度都 ≥0.7 直接采用，合证据，不进 OC 审
两结论一致但置信度 <0.7 采用但标 ⚠️低置信，派单时告知用户
两结论相反，置信度差 ≥0.2 高置信者优先，低置信者的反对意见作为"风险提示"写进结论
两结论相反，置信度差 <0.2（势均力敌） 升人审，不替用户选
任一方输出"我不确定" 自动唤起 OpenClaw 慢思考（System-2 升级）
