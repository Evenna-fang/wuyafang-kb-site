跨域纪律与流程（跨能力域 · 跨文件 · 跨 Agent）

TL;DR：本篇是"跨域"维度的纪律提炼——任务/知识跨越能力域（调研/规划/执行/审查/调试/清理）、跨越文件（共享配置/总地图/全景图/知识库）、跨越 Agent（Hermes/DSH/Claude Code/Codex/OpenClaw/QwenCode）时，必须遵守的协同纪律。每条纪律都溯源到 wiki/总网流程/ 已有文档，不新增规则、不改口径，只把散在各文档里的"跨域条款"抽出来按域归位。

口径声明：本篇是提炼整理，不是新裁决。凡本篇出现的规则数字（G1–G5、五级真值、零游离、轮≤2、回写闭环等）均可在"## 溯源"列出的文件里逐条 grep 命中；如与源文档冲突，以源文档为准并回写本篇。

B. 跨文件（共享文件/配置/资产的并发与归属）

3
  1. 冲突裁决五级真值层级（跨文件多源冲突的标准答案）：
    ① 实测命令输出 > ② 一手官方文档 > ③ 台账已验证坑 > ④ 技能库规则 > ⑤ 二手总结/凭印象
    反例（源文档原话）："SOP 写 30 天 vs 帮助中心写 14 天，AI 挑先检索到的那个 = 错，必须先按本层级裁决再引用"（总地图与资产网-N节点体系.md §三）。
  2. 串行边界/文件集互斥：跨 Agent 同时写文件的竞态（concurrent-writer-race 类问题）需"域声明 + 文件集互斥，重叠即串行/并卡"；互斥只覆盖文件系统，非文件共享面（git index/lockfile、缓存、环境变量、端口、数据库/外部 API）同样要声明（裁决依据：notes/decisions/裁决-流程优化三报告-OC审-20260925.md C2）。
  3. 动库/删数据前快照：删 chunk 前必须①备份 index ②分批删+每批 Recall 不降才继续 ③读内容判"知识 vs 垃圾"，禁按字段名间接推断（总地图与资产网-N节点体系.md §二）。总纲铁律同口径："知识库入库必标 TTL + 动库前必快照"（总网协议总纲-一手 核心结论）。
  4. 数字口径标注：数字附命令+口径（如"234 txt（find raw/courseware -iname '*.txt'）"），不裸写数字（任务闭环优化全景图机制-20261021.md 回写规则 5）。

D. 跨域收口：全景图回写闭环 + 零游离门禁

3 
任务完成 → 验收 → 闭环优化全景图(补缺口/更新进度/修正坑) → 下次照跑 → 可复用到下个项目

（任务闭环优化全景图机制-20261021.md §0）

回写规则（每单交付强制，缺一不收口）：
1. 进度图必回写：状态 ✅/🔄/⏳ + 产物路径 + 验收凭据（receipt verify 绿 / 评测数字）
2. 缺口图必补：本任务暴露的缺口当场登记，标 P0/P1/P2 + 阻塞什么
3. 坑图必修正：根因+修复+台账指纹，同步 error-ledger
4. 总地图必挂（零游离）：新资产挂对应 N 节点，orphan-asset-check.py exit=0
5. 口径标注：数字附命令+口径

三图一致性：进度图 ✅ 必须有对应产物；缺口图缺口不与进度图 ✅ 矛盾；坑图指纹进台账（C5）。

跨域协作可落成一个显式状态机，与 N1–N6 节点一一对应（伪代码骨架，字段口径见 任务闭环优化全景图机制-20261021.md §1 三张图）：

# 跨域任务状态机骨架（对应 N1-N6 + 全景图三图字段）
STATE = {"task": None, "node": "N1", "档位": None, "子单结果": [], "验收分数": None, "沉淀去向": None}

def close_out(STATE, pan_orama):
    """N6 收口：四问 + 三图回写 + 零游离，缺一不收口"""
    assert 产物落位 and 备份清 and 坑记台账 and 进程清          # 收口四问
    pan_orama["进度图"].append({"任务": STATE["task"], "状态": "✅",
                                 "产物路径": STATE["产物"], "验收凭据": STATE["receipt"]})
    pan_orama["缺口图"] += STATE["新暴露缺口"]                    # P0/P1/P2
    pan_orama["坑图"]   += STATE["踩坑"]                          # 根因+修复+台账指纹
    assert orphan_asset_check() == 0                             # 零游离门禁

def resolve_conflict(claims: list[str]) -> str:
    """跨域冲突裁决：五级真值层级（总地图与资产网-N节点体系 §三）"""
    order = ["实测命令输出", "一手官方文档", "台账已验证坑", "技能库规则", "二手总结/凭印象"]
    for tier in order:                    # 按层级取最高优先级证据，禁"谁先检索到算谁"
        hit = [c for c in claims if c.tier == tier]
        if hit:
            return hit[0]
    return "升用户裁决"                    # 无高层级证据 → 不下结论

使用流程（照跑）

3
  1. 接到跨域任务 → 读 raw/_task_orders/总地图.md（N1–N6），不凭记忆动手。
  2. 派单/派生 → 跑 dispatch-guard.py；派单前查已有产物复用（派单纪律三条.md ③）。
  3. 多 Agent 并发写 → 先声明文件集/域，重叠即串行（C2 裁决口径）；非文件共享面一并声明。
  4. 结论打架 → 按五级真值层级裁决；仍分歧→Claude Code 第三方；Claude Code 是当事方→升用户。
  5. 收口 → 跑 orphan-asset-check.py + 回写三图；数字附命令+口径。
