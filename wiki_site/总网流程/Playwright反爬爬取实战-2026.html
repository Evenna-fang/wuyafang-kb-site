二、stealth 三件套（绕 headless 识别的核心）

2

裸 headless 会被强反爬识别（navigator.webdriver 暴露自动化）。三件事去自动化特征：

# 解释器必须用 ~/ai-stack/bin/python（系统 python3 没装 playwright 包）
import asyncio
from playwright.async_api import async_playwright

async def main():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True, args=[
            "--no-sandbox", "--disable-dev-shm-usage",
            "--disable-blink-features=AutomationControlled"])   # ① 关自动化特征
        ctx = await browser.new_context(
            user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/153.0.0.0 Safari/537.36",  # ③ 真 Windows UA
            locale="en-US", viewport={"width":1280,"height":800})  # ③ locale
        await ctx.add_init_script("Object.defineProperty(navigator,'webdriver',{get:()=>undefined});")  # ② 去 webdriver 标记
        page = await ctx.new_page()
        resp = await page.goto("https://openai.com/news/", timeout=45000, wait_until="domcontentloaded")
        await page.wait_for_timeout(4000)  # 等 JS 渲染
        body = " ".join((await page.inner_text("body")).split())
        print(resp.status, len(body), body[:120])
        await browser.close()

asyncio.run(main())

三件缺一不可：① --disable-blink-features=AutomationControlled ② navigator.webdriver 置 undefined ③ 真 Windows UA + locale="en-US"。

四、环境依赖（装不好会 exitCode=127）

2
  • NSS 库：chrome 启动前提，缺则报 libnspr4.so not found → sudo apt-get install -y libnspr4 libnss3
  • playwright 版本：python 包 ~/ai-stack/bin/pip install playwright（1.63.0），配套浏览器 ~/ai-stack/bin/playwright install chromium（1243）。版本必须配套，不配套报「download new browsers」。
  • 代理前提：大陆 WSL 需开科学上网（WSL 走系统代理），否则 google/x/HF 直连 000。
