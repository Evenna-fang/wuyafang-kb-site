数学与统计直觉：表示、变换、不确定性与稳健结论

本文合并「线性代数白话、概率统计白话、统计直觉、数学基础综合」。只保留 AI 应用最常用的最小闭环：向量与矩阵管表示和变换，概率统计管不确定性，微积分管优化；所有概念最终落到形状检查、数值计算和替代分析。

验证边界：NumPy/SciPy 示例已在本机离线实跑，随机数使用固定种子；输出只是合成小样本的教学结果，不是业务显著性结论。论文方法未在本库数据上复现。

WHY

2

1. 为什么 AI 应用不能跳过数学形状与统计口径

3

Embedding 返回的是向量，批量文本组成矩阵，检索要比较方向或距离，训练要用损失与梯度调整参数。若不理解形状，A @ x 的维度错误会被误当库 bug；若不理解归一化，零向量余弦相似度会出现 NaN；若不理解样本与总体，就会把一次 RAG 评测的高分当稳定能力。

统计错误更隐蔽：均值被极端值拉动、分组样本量不同、重复试验后挑显著结果、相关被解释为因果。即使代码运行成功，错误口径仍会稳定地产出错误结论。后果是选错模型、误报提升、上线后指标回落，而且难以通过单纯调参修复。

2. 为什么还要做稳健性，而不是只跑一次

3

一次分析通常包含多个可选决定：异常值怎么处理、用均值还是中位数、指标怎样归一化、哪批样本作基线。只报告最顺手的一条路径，会把分析选择的偶然性伪装成事实。稳健性不是要求所有方法给出完全相同数字，而是检查关键结论是否依赖某个未说明的任意选择。

WHAT / WHYT

2

3. 线性代数：向量是坐标，矩阵是变换

3
  • 标量/向量/矩阵/张量：分别可看作 0、1、2 及更高维数组；形状比「几维数据」更重要。
  • 点积 x · y = Σxᵢyᵢ：同时受方向与长度影响；不能直接称为余弦相似度。
  • 余弦相似度 cos(x,y)=x·y/(||x|| ||y||)：去除长度影响，范围为 [-1,1]；零向量没有定义。
  • 矩阵乘法 A @ x：对向量做线性变换；(m,n) @ (n,) 得到 (m,)，不是逐元素乘法 A * x。
  • 线性方程组 A x=b：在数值计算中通常用 np.linalg.solve(A,b)，不要手工求逆再乘 b。
  • 特征向量/奇异值：用于理解特殊方向和低秩结构；不是「Embedding 的每一维都有固定语义」的证明。

Embedding 的近邻可以反映训练数据与模型学到的关系，但相似不保证事实相同、权限相同或检索证据充分。余弦分数也不能跨模型、跨任务直接设同一个阈值。

4. 概率统计：先问样本怎样来，再看指标

3
概念 回答的问题 不能推出什么
均值/中位数 数据中心位置的两种口径 均值相近不代表分布相同
方差/标准差/IQR 数据离散与尾部情况 波动大不自动代表异常或坏
条件概率 已知条件下事件发生的可能性 P(A|B) 不等于 P(B|A)
相关系数 线性共同变化程度 不证明因果，也不捕捉所有非线性关系
置信区间 在模型与抽样假设下的区间估计 不是「真值有 95% 概率随机落在这个已算区间」
p 值 原假设与模型成立时，观察到至少这么极端结果的概率 不是原假设为真的概率，也不代表效应大小
Bootstrap 用重抽样估计统计量不确定性 不能修复有偏采样、数据泄漏和依赖结构

《统计学习方法》的划线把统计学习组织为方法、模型、策略，并强调独立同分布等假设。实际 RAG 问题常有重复主题、时间漂移与文档聚类，普通独立样本 Bootstrap 可能低估不确定性；必要时应按文档或用户分组重抽样。

5. 微积分在最小地图中的位置

3

损失函数把预测与目标差异变成可优化数值，梯度指出局部变化方向，学习率控制步长。入门应用阶段需要知道「训练是在改参数」以及过拟合/欠拟合的含义，不必一开始就手推所有反向传播。损失下降不等于业务指标提升，训练集下降也不等于未见数据泛化改善。

6. 论文怎么说，我们怎么用

3

量尺不是中性的显示格式。Change the Number, Change the Answer（arXiv:2610.22187）研究评分量尺变化对 LLM 评审的影响，显示不同量尺设计会改变归一化分数和部分文本类别，详细 rubric 并未消除敏感性。我们的落点是：保存原始评分和量尺版本，不只保存归一化结果；更换 1–5、0–100 或不同锚点时做平行评分与排序比较，禁止把两套分数直接拼成同一趋势。

可复现不只是重跑同一脚本。AI-Driven Reproducibility and Analytical Robustness（arXiv:2610.23845）关注 AI 辅助分析与合理替代路径的稳健性。我们采用更保守的工程转化：固定数据快照与随机种子，同时改变一个合理分析选择（均值/中位数、异常值规则、聚合层级），记录结论是否翻转；不把论文自动化设想写成已验证工具能力。

HOW

2

7. 向量与线性方程：用可手算的小例子验收

3

保存为 math_demo.py（已实跑）：

import numpy as np

rng = np.random.default_rng(42)

x = np.array([1.0, 0.0])
y = np.array([1.0, 1.0])
cosine = float(x @ y / (np.linalg.norm(x) * np.linalg.norm(y)))
assert np.isclose(cosine, 1 / np.sqrt(2))
print("cosine:", cosine)

# 2a+b=5, a-b=1 -> a=2,b=1
A = np.array([[2.0, 1.0], [1.0, -1.0]])
b = np.array([5.0, 1.0])
solution = np.linalg.solve(A, b)
assert np.allclose(A @ solution, b)
print("solution:", solution)

zero = np.zeros(2)
with np.errstate(divide="ignore", invalid="ignore"):
    undefined = zero @ x / (np.linalg.norm(zero) * np.linalg.norm(x))
assert np.isnan(undefined)
print("zero-vector cosine:", undefined, "（必须显式拒绝或单独处理）")

运行（已实跑）：

python -I math_demo.py

旧稿的 np.mat 不沿用；现代代码使用 np.array 和 @。真实检索还需批量零范数检查、dtype、归一化约定和索引一致性。

8. 统计摘要、区间与替代口径

3

继续加入以下代码（已实跑）：

from scipy import stats

values = np.array([10, 11, 10, 12, 11, 60], dtype=float)
summary = {
    "n": values.size,
    "mean": values.mean(),
    "median": np.median(values),
    "std_sample": values.std(ddof=1),
    "q1_q3": np.percentile(values, [25, 75]).tolist(),
}
print("summary:", summary)

# 合成数据的均值 bootstrap；真实文档数据可能需按组重抽样
boot = np.array([
    rng.choice(values, size=values.size, replace=True).mean()
    for _ in range(2000)
])
interval = np.quantile(boot, [0.025, 0.975])
print("bootstrap_mean_95%:", interval.tolist())

# 替代口径：极端值对均值和中位数影响不同
without_max = values[values != values.max()]
print("without_max mean/median:", without_max.mean(), np.median(without_max))
assert summary["mean"] != summary["median"]

# p 值演示不是业务显著性宣称
result = stats.ttest_1samp(values, popmean=10)
print("illustrative_ttest:", {"statistic": result.statistic, "pvalue": result.pvalue})

这组数故意加入 60，让均值和中位数分离。Bootstrap 区间继承原样本的偏差，不会因为重抽 2000 次就「修复」样本代表性；t 检验在小样本、偏态和极端值下的假设也要审查。真实报告应给效应量、原始样本、图形与缺失处理，而不是只报 p 值。

9. 建立一页稳健性记录

3

每次模型或检索评测至少填写：

数据快照 ID：
样本抽取方式与时间范围：
指标公式与量尺版本：
原始评分数组位置：
主分析（模型/指标/异常值规则）：
替代分析 A（只改一个选择）：
替代分析 B（只改另一个选择）：
结论是否翻转：
随机种子、代码版本、依赖版本：

具体步骤：

  1. 先冻结数据快照，避免每次运行抽到不同题。
  2. 保存每题原始结果，不能只存最终均值。
  3. 主分析与替代分析使用同一样本，避免因换样本混淆原因。
  4. 若更换量尺，分别保留原分数、锚点、评审模型与归一化公式；比较逐题变化和排序，不只做整体缩放。
  5. 报告翻转与不确定区间，不只报告对当前方案有利的分支。

10. 最小过关题

3
  • 手算 [1,0] 与 [1,1] 的点积和余弦，并解释二者为何不同。
  • 给出 (3,2) @ (2,4) 的结果形状，说明何时乘法无定义。
  • 对 [10,11,10,12,11,60] 分别计算均值与中位数，说明哪个受极端值影响更大。
  • 解释「p=0.03」不意味着什么，并列出效应量、样本量和抽样设计三项补充信息。
  • 把一次 RAG 评测从固定量尺改成另一套合理锚点，检查逐题类别或排序是否变化；没有原始分数时先补采集，不伪造结论。

本库真实落地（源码核对，2026-11-04）

  • 向量检索全部建立在三个基础数学操作上，本库的实现能逐行对上（本次在 rag/.venv 实跑编码器）：
    1. 余弦相似度 → 距离：Chroma 返回的是 distances，本库一律换算成 1 - dist 当「相似度」（rag/query.py L783 "score": 1.0 - float(dist)）——所以距离越小越相关，0.27 是好命中，0.43 是域外。
    2. RRF 排名倒数：rag/query.py L428 scores[hid] = scores.get(hid, 0.0) + w / (k + rank_idx)，k=60——只用名次不用分数，避免 dense 的余弦与 sparse 的词法权重不同纲。
    3. 阈值决策：门禁不是「像不像」，而是「阈值的两侧是否干净可分」，rag/config.yaml L139-146 记录了双端实测：19 个正样本最低 0.0697、5 个域外负样本最高 0.8641（一条假阳），最终取 threshold: 0.45 落在 (0.0211, 0.4943] 的分离窗内。
  • 本次实跑数字（可复现）：bge-m3 对一句中文输出 dense 1024 维、首四项 [-0.0071, 0.0166, -0.0302, -0.0003]；sparse 输出 15 个 token 权重（30094→0.2633、98771→0.2377、125012→0.2920）。前者是浮点向量，后者是「稀疏字典」——同一个模型，两种数学结构。
  • 统计直觉用在「别信单次观测」：本库的 rerank 阈值注释专门记了「Q056=0.8641 是 reranker 假阳……抬阈值到 0.87 才能拦，但会误拒 3/19 正样本，得不偿失」——《统计学习方法》里讲的「样本量与误判权衡」，在这里是一个具体数字取舍。
  • 和课件讲法的差异：课件以公式推导（内积、余弦、概率分布）为主线；本库的数学全在配置注释里的实测分布中，读代码时要把 rag/config.yaml 的检索段当「带数字的数学笔记」读。
  • 本库暂无：没有做向量分布的统计画像（如各层向量范数分布、距离分位数曲线），阈值靠人工双端采样，样本量 19 正 + 5 负，属于「够用不充分」。
