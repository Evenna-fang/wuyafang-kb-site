2. 变量、对象与类型系统

2
2.1 变量是指针，不是盒子1 个重点▾ 点开看本节重点
本节重点
  • 初学最容易把变量理解成"装值的盒子"，实际上 Python 的变量是贴在对象上的标签
3

初学最容易把变量理解成"装值的盒子"，实际上 Python 的变量是贴在对象上的标签。赋值 a = [1, 2] 做两件事：在堆内存建一个列表对象 [1, 2, 3] 之外的空壳，再让名字 a 指向它。随后 b = a 不复制列表，只是让 b 也指向同一个对象，改 b[0] = 99 会连带看到 a[0] 变 99。这条规则解释了可变对象共享问题，也解释了 is 与 == 的分工：is 比较"是不是同一个对象"（内存地址），== 比较"值是否相等"。小整数（-5 到 256）和短字符串被解释器缓存复用，所以 a = 256; b = 256 时 a is b 常是 True，而 257 起就可能为 False——把 is 当值判断用是不可靠的写法。

2.2 六个基本类型与边界

3
  • int 整数：无大小上限，2 ** 100 直接算出 31 位数字；0xff 十六进制、0b1010 二进制、0o17 八进制字面量都能直接写。
  • float 浮点：IEEE 754 双精度，0.1 + 0.2 的结果是 0.30000000000000004 而非 0.3。比较浮点是否相等用 abs(a - b) < 1e-9 或 math.isclose(a, b)。
  • complex 复数：1 + 2j，z.real 取实部、z.imag 取虚部，信号处理场景才用。
  • str 字符串：不可变序列，"修改"必然生成新对象；支持索引 s[0]、切片 s[1:5]、步长 s[::2]。
  • bool 布尔：是 int 的子类，True + 1 等于 2；and、or、not 三运算符，and 返回第一个假值或最后一个值，or 返回第一个真值或最后一个值。
  • None 空值：单例对象，判断写 x is None 而非 x == None；函数无 return 语句时返回 None。

bytes 与 bytearray 表示二进制数据，b"hello" 是不可变字节串，读写网络流与二进制文件时才用。

2.3 类型检查与转换2 个重点▾ 点开看本节重点
本节重点
  • 「type(x)」 查精确类型，「isinstance(x, (int, float))」 做归属判断且支持元组多选，写库函数时优先 isinstance，因为它对子类友好
  • 这条规则在写 「if my_list:」 判空时直接用得上，比 「if len(my_list) > 0:」 更地道
3

type(x) 查精确类型，isinstance(x, (int, float)) 做归属判断且支持元组多选，写库函数时优先 isinstance，因为它对子类友好。转换三件套各有一个高频翻车点：

转换 翻车形态 正确做法
int("3.14") ValueError：字符串带小数点不能直转整数 int(float("3.14")) 得 3（截断非四舍五入）
float("abc") ValueError：无法解析 先 s.replace(',', '') 清洗，再 try/except 包住
str(3.14) 不报错但得到文本 想要两位小数写 f"{3.14:.2f}"
int(3.99) 不报错，结果 3 要四舍五入用 round(3.99) 得 4

bool 转换规则"空值皆假"：bool(0)、bool("")、bool([])、bool({})、bool(set())、bool(None) 全是 False，其余为 True。这条规则在写 if my_list: 判空时直接用得上，比 if len(my_list) > 0: 更地道。

3.2 for 循环与 range、enumerate

3

for 遍历任何可迭代对象。range 三形态：range(5) 生成 0 到 4，range(1, 6) 生成 1 到 5，range(0, 10, 2) 带步长生成 0 2 4 6 8，倒序写 range(5, 0, -1)。需要"第几项"时用 enumerate(names, start=1)，同时拿到索引与值；需要并行遍历两个序列用 zip(a, b)，长度不同时以短的为准（3.10 起可写 zip(a, b, strict=True) 让长度不等直接报错）。

3.3 while 循环与死循环控制2 个重点▾ 点开看本节重点
本节重点
  • while 在条件为真时反复执行，典型形态是"读取直到某个退出条件"：「while True:」 配 「break」
  • 排查信号：程序卡住不退出且 CPU 风扇转；改法是确保每个 while 都有明确的终止路径（break 或变量更新）
3

while 在条件为真时反复执行，典型形态是"读取直到某个退出条件"：while True: 配 break。翻车现场是忘了更新循环变量造成死循环，例如 count = 1; while count <= 5: print(count) 少写 count += 1 就永远打 1。排查信号：程序卡住不退出且 CPU 风扇转；改法是确保每个 while 都有明确的终止路径（break 或变量更新）。

3.4 break、continue 与 for-else

3

break 立即终止本层循环，continue 跳过本次进入下一次。for-else 是 Python 特有语法：循环没被 break 中断时执行 else 分支。它最经典的用法是质数判定——内层循环一旦找到因子就 break，没 break 说明是质数：

for n in range(2, 20):
    for x in range(2, int(n ** 0.5) + 1):
        if n % x == 0:
            print(f"{n} = {x} × {n // x}")
            break
    else:
        print(f"{n} 是质数")

else 分支的位置容易看错：它和 for 对齐，不是和 if 对齐。误把 else 当成 if 的一部分是新手第二大缩进类错误。

3.5 match-case（Python 3.10+）2 个重点▾ 点开看本节重点
本节重点
  • return "未找到"
  • 用在 3.9 及以下会 SyntaxError，此时退回 if-elif 链
3

多分支值分发用 match-case，比一长串 if-elif 清晰：

def handle_status(code: int) -> str:
    match code:
        case 200:
            return "成功"
        case 404:
            return "未找到"
        case 500:
            return "服务器错误"
        case _:
            return f"未知状态码: {code}"

下划线 case _ 是通配符分支。它还能解构数据：case {"op": "add", "x": a} 直接把字典字段绑到变量，case [first, *rest] 解构列表。用在 3.9 及以下会 SyntaxError，此时退回 if-elif 链。

4. 异常处理

2
4.1 为什么要有异常3 个重点▾ 点开看本节重点
本节重点
  • 程序运行时会出现"文件不存在""用户输入非数字""网络断开"这类无法预先避免的情况
  • 异常机制让错误可以被"抛出"和"捕获"，把正常逻辑和错误处理分开写
  • 反例是不用异常而用返回值约定（如返回 -1 表示失败），调用方容易忘记检查返回值，错误被静默吞掉
3

程序运行时会出现"文件不存在""用户输入非数字""网络断开"这类无法预先避免的情况。异常机制让错误可以被"抛出"和"捕获"，把正常逻辑和错误处理分开写。反例是不用异常而用返回值约定（如返回 -1 表示失败），调用方容易忘记检查返回值，错误被静默吞掉。

4.2 try/except/else/finally 四段式

3 
def safe_div(a: str, b: str) -> float | None:
    try:
        x, y = float(a), float(b)      # 可能 ValueError
        result = x / y                 # 可能 ZeroDivisionError
    except ValueError as e:
        print(f"输入不是数字: {e}")
        return None
    except ZeroDivisionError:
        print("除数不能为零")
        return None
    else:
        print("计算成功")              # 没异常才执行
        return result
    finally:
        print("本次调用结束")           # 无论是否异常都执行

四段分工：try 放可能出错的最小代码块；except 按异常类型分别捕获，类型越具体越好；else 放"只有没异常才做"的收尾；finally 放"无论如何都要做"的清理（关文件、释放锁）。

4.3 异常分级：什么时候捕获，什么时候让它冒泡3 个重点▾ 点开看本节重点
本节重点
  • 第一，当前层能给出有意义的恢复动作就捕获（比如换一个默认值重试），否则不要捕获
  • 第二，捕获后要么处理掉，要么 「raise」 重新抛出，禁止写空的 「except: pass」，那是把 bug 藏进地毯
  • 第三，自定义异常继承 Exception 而不是 BaseException，后者会连 KeyboardInterrupt 一起吞掉，导致 Ctrl+C 都停不下来
3

判断规则三条。第一，当前层能给出有意义的恢复动作就捕获（比如换一个默认值重试），否则不要捕获。第二，捕获后要么处理掉，要么 raise 重新抛出，禁止写空的 except: pass，那是把 bug 藏进地毯。第三，自定义异常继承 Exception 而不是 BaseException，后者会连 KeyboardInterrupt 一起吞掉，导致 Ctrl+C 都停不下来。分级写法示例：底层函数抛 ValueError("格式错误")，中层转成业务异常 raise DataFormatError(...) from e（from e 保留原始堆栈），顶层统一记录日志。

5.1 input 与它的坑

3

input("提示") 永远返回字符串。用户输入 "18" 得到的是 "18" 不是数字，必须 int(input(...)) 显式转换；用户直接回车得到空字符串 ""，int("") 抛 ValueError。健壮写法是循环校验：

while True:
    raw = input("请输入年龄（整数）: ").strip()
    if not raw:
        print("不能为空，请重试"); continue
    try:
        age = int(raw)
        if not 0 <= age <= 150:
            print("年龄需在 0 到 150 之间"); continue
        break
    except ValueError:
        print("请输入纯数字")
print(f"你输入的年龄是 {age}")

6. f-string 格式化与字符串细节

2

f-string 是 3.6 起的主流写法：f"{变量:格式}"。常用格式规格：:.2f 保留两位小数、:.1% 百分比、:010d 补零到 10 位、:, 千分位、>20 右对齐、<20 左对齐、^20 居中、#x 十六进制。表达式可以直接进花括号：f"{a + b = }" 会连变量名带值一起打印（3.8+）。字符串常用方法：strip() 去两端空白、split(",") 切分、",".join(list) 拼接、replace() 替换、startswith()/endswith() 判断头尾、find() 找位置（找不到返回 -1）与 index()（找不到抛异常）分工。字符串不可变意味着 s.strip() 不改原串而是返回新串，必须接住返回值。

7.1 什么情况下用（适用场景加前置条件）

3
  • if-elif-else 链：分支少于 5 个、条件是范围或布尔组合。前置：条件表达式可读。
  • match-case：3.10+ 且分支是对离散值或数据结构的匹配。前置：Python 3.10 以上。
  • for 循环：遍历序列或已知次数的重复。前置：对象可迭代。
  • while 循环：次数未知、靠条件退出（读输入、轮询）。前置：有明确的 break 或变量更新路径。
  • try/except：操作有已知的失败模式（IO、解析、网络）。前置：知道可能抛哪些异常类型。
  • f-string：所有字符串格式化场景。前置：3.6+。
7.2 什么情况下别用（反例加替代方案）3 个重点▾ 点开看本节重点
本节重点
  • 别写 「except:」 或 「except Exception: pass」：吞异常让 bug 隐形
  • 别用字符串拼接代替 f-string：「"年龄: " + str(age)」 可读性差
  • 别在深层函数里 「print」 做调试：污染输出且上线难清理
3
  • 别用循环变量控制的 while 代替 for：i = 0; while i < 10: ... i += 1 应改写 for i in range(10)，后者无忘更新风险。
  • 别写 except: 或 except Exception: pass：吞异常让 bug 隐形。替代：捕获具体类型并至少记录日志。
  • 别用字符串拼接代替 f-string："年龄: " + str(age) 可读性差。替代：f"年龄: {age}"。
  • 别用 == True、== None：写 if flag:、if x is None:。
  • 别在深层函数里 print 做调试：污染输出且上线难清理。替代：logging.debug。
  • 别把 int(input()) 直接裸写：用户输入非数字即崩。替代：第 5.1 节的循环校验模板。
  • 别依赖 is 判断值相等：小整数缓存会造成假象。替代：用 ==。

7.3 翻车长什么样（真实失败形态加排查信号加怎么改）

3
  1. SyntaxError: invalid syntax：常见于用了中文全角引号、括号或冒号，或 3.9 以下写 match-case。排查：看报错行的字符形状。改：全换英文半角；match-case 需要 3.10+。
  2. IndentationError: expected an indented block：if/for/def 后下一行没有缩进块，或混用 Tab 与空格。排查：编辑器开"显示空白字符"。改：统一用 4 空格，不用 Tab。
  3. ValueError: invalid literal for int()：把非数字字符串转整数。排查：打印原始输入看真实内容（可能带空格或小数点）。改：strip() 清洗后 try/except 包住。
  4. IndexError: list index out of range：下标越界，典型是 for i in range(len(lst)) 后用 lst[i+1]。排查：打印 len 与 i。改：用 zip(lst, lst[1:]) 遍历相邻对，或先判长度。
  5. KeyError：取不存在的字典键。排查：打印 d.keys()。改：d.get(key, default)。
  6. 死循环不退出：while 少了变量更新或 break。排查：程序卡住、CPU 占用高。改：加 break 条件，或改写 for。
  7. 0.1 + 0.2 == 0.3 判断为 False：浮点精度。排查：打印 repr(0.1 + 0.2)。改：用 math.isclose 或 round(x, 10)。
  8. else 分支没按预期执行：for-else 位置放错（缩进到 if 下）。排查：看 else 与谁对齐。改：else 与 for 对齐才表示"没 break 才执行"。
  9. 捕获了异常但程序还是崩：捕获类型不对（抓 ValueError 实际抛 TypeError）。排查：看异常类名。改：抓父类 except (ValueError, TypeError) 或改具体类型。

15. 常见死循环与性能小坑

2

死循环三形态。第一种是 while 少更新：count = 1; while count <= 5: print(count)，改法是循环体里加 count += 1。第二种是 break 条件写错：while True: if x = 0: break（赋值当判断，应写 x == 0）。第三种是 input 校验循环里忘了 return 或 break，导致永远在问同一个问题。排查手段：加一行 print("循环第 N 次", count) 观察是否收敛，或用 Ctrl+C 中断看 traceback 指向哪一行。

性能小坑。字符串在循环里用 += 拼接是反模式，每次生成新对象，10 万次拼接比 "".join(list) 慢一个数量级；改法是先收集进列表再 join。列表做成员检查 if x in big_list 是线性扫描，10 万元素的列表里查一个元素要遍历全部；改法是转成 set 或 dict 做 O(1) 查找。这两个坑在写数据处理脚本时最常踩，判断信号是"数据量一上来脚本就慢到不可用"。

脚本 G：grade_stat.py（Python 3.12）——输入 N 个分数做统计，串起本文全部知识点

#!/usr/bin/env python3
# grade_stat.py —— Python 3.12
# 运行: python grade_stat.py
def read_scores(n: int) -> list[float]:
    scores = []
    while len(scores) < n:
        raw = input(f"请输入第 {len(scores)+1} 个分数（0-100）: ").strip()
        try:
            v = float(raw)                        # 转换可能抛 ValueError
        except ValueError:
            print("不是数字，请重试"); continue
        if not 0 <= v <= 100:
            print("分数需在 0 到 100 之间"); continue
        scores.append(v)                          # 合法才收集
    return scores

def grade_of(avg: float) -> str:
    match avg:                                    # 3.10+ 模式匹配
        case a if a >= 90: return "优秀"
        case a if a >= 80: return "良好"
        case a if a >= 60: return "及格"
        case _: return "不及格"

if __name__ == "__main__":
    n = int(input("要统计几个分数？"))
    scores = read_scores(n)
    avg = sum(scores) / len(scores)               # sum 求和
    print(f"平均分 {avg:.2f}，最高 {max(scores)}，最低 {min(scores)}")
    print(f"等级评定: {grade_of(avg)}")

验收标准：输入 3 个分数 95、82、67 输出平均 81.33、等级良好；输入 "abc" 提示重试、输入 150 提示范围。这段把 input 校验、try/except、列表收集、sum/max/min、match-case 五个知识点串在一条真实任务上，是"语法到脚本"的最小闭环。

下一篇《L0-Python 函数与模块》会系统讲函数，这里先给参数语法打底，因为它和本文的类型、作用域直接相关。位置参数按顺序传入，add(3, 5) 里 3 对应 a、5 对应 b。默认参数给参数一个缺省值，greet(name, greeting="你好") 允许只传名字。关键字参数用名字传，profile(age=18, name="小明") 可以不按顺序。可变参数 *args 收集任意多个位置参数成元组，total(1, 2, 3) 里 numbers 是 (1, 2, 3)。关键字可变参数 **kwargs 收集任意多个关键字参数成字典。混合使用时顺序固定为：位置参数、默认参数、*args、**kwargs，写反会 SyntaxError。

返回值方面，return 带值返回该值；不写 return 或 return 后无值返回 None；return a, b 语法上是返回一个元组，调用方用 lo, hi = min_max(...) 解包。作用域方面，函数内赋值默认创建局部变量，要改全局变量必须显式 global count；闭包（函数内定义函数并返回）是装饰器的基础，下一篇展开。lambda 是单表达式匿名函数，常用在 sort(key=lambda s: s[1]) 这类"一次性小函数"场景，别拿它写超过一行的逻辑。

写脚本时最常用的十来个内置函数，按用途分组。长度与聚合：len(numbers) 求元素个数、max/min 取极值、sum(numbers) 求和。sorted(numbers) 返回新排序列表不改原列表，要原地排序用 numbers.sort()；reversed(numbers) 返回反转迭代器，转列表看结果写 list(reversed(numbers))。并行遍历：zip(names, scores) 把两个列表配对，3.10 起可加 strict=True 让长度不等直接报错，防止静默丢数据。真假判断：any([0, 0, 1]) 有一个真就 True，all([1, 2, 3]) 全真才 True，判"是否全部满足条件"比写循环计数清爽。类型构造：list(range(5)) 生成列表、tuple([1, 2]) 转元组、set([1, 1, 2]) 去重得 {1, 2}、dict([("a", 1)]) 由键值对列表建字典。

25. 预习：文件读写最小闭环（语法篇收尾）

2

语法的最后一环是把结果存下来、把数据读回来，这样才能写出真正"有用"的脚本。核心语法只有一句：with open("test.txt", "r", encoding="utf-8") as f:，with 离开代码块时自动关闭文件，不需要手动 f.close()。打开模式七种："r" 只读（文件不存在报错）、"w" 写入（不存在则创建、存在则从头覆盖）、"a" 追加（加到末尾）、"x" 排他创建（已存在则报错）、"r+" 读写、"rb"/"wb" 二进制读写。选错模式的典型翻车是"本想追加结果却用 w 把上次输出覆盖了"。

读取四法：f.read() 一次读全部（大文件会撑爆内存）、f.readline() 读一行、f.readlines() 读成行列表、for line in f 逐行遍历（内存最友好，处理日志大文件的标准写法）。编码必须显式：Windows 上读写中文文件务必写 encoding="utf-8"，否则默认的 gbk 或 cp936 会把中文读成乱码或写坏文件。这个坑在第 7 节翻车清单里也出现过，是 Windows 用户第一高频 IO 问题。

预告脚本：写一个 line_counter.py，统计 test.txt 的行数、字符数和最长的一行，输出格式自定。完整实现放到《L0-Python 函数与模块》开篇，用文件读写加函数封装串起来。语法到此收尾，下一篇讲函数与模块——把这二十多节的语法组织成可复用、可测试的程序结构。

27. 预习：pathlib 与 JSON（现代路径与数据交换）3 个重点▾ 点开看本章重点
本章重点
  • pathlib 是 3.4 起的标准库路径工具，比 「os.path」 的字符串拼接更安全
  • 核心对象 「Path」：「p.parent」 父目录、「p.name」 文件名、「p.suffix」 扩展名、「p.stem」 去扩展名的文件名
  • 遍历目录 「for p in Path(".").iterdir():」，递归找文件 「for p in Path(".").rglob("*.py"):」
2

pathlib 是 3.4 起的标准库路径工具，比 os.path 的字符串拼接更安全。核心对象 Path：p.parent 父目录、p.name 文件名、p.suffix 扩展名、p.stem 去扩展名的文件名。建目录写 Path("my_folder/sub").mkdir(parents=True, exist_ok=True)，parents=True 允许多级创建、exist_ok=True 目录已存在不报错。读写一行搞定：Path("a.txt").write_text("内容", encoding="utf-8") 与 Path("a.txt").read_text(encoding="utf-8")。遍历目录 for p in Path(".").iterdir():，递归找文件 for p in Path(".").rglob("*.py"):。判断 p.exists()、p.is_file()、p.is_dir()、p.stat().st_size 取字节数。

JSON 是数据交换的通用格式，Python 标准库 json 四个函数：json.dumps(obj, ensure_ascii=False, indent=2) 把对象转字符串（ensure_ascii=False 让中文直接显示不转义，indent=2 缩进美化）、json.loads(s) 反向、json.dump(obj, f) 写文件、json.load(f) 读文件。翻车点：JSON 没有元组类型，json.dumps((1, 2)) 会变成 [1, 2]；也没有日期类型，datetime 对象要先 strftime 转字符串再序列化。

29. 字面量写法补充（数字、字符串、布尔的细节）

2

【part1 补充】整数字面量可以用下划线分隔提高可读性，1_000_000_000 等价于 1000000000，适合写金额、ID、位掩码。浮点支持科学记数法 1.5e-4 表示 0.00015，处理物理量或概率时常见。复数写 3 + 4j，虚部后缀是 j 不是 i，z.real 取实部 3.0、z.imag 取虚部 4.0（都是浮点）。

字符串三种引号：单引号、双引号等价，选哪种看内容里有没有引号（"It's fine" 用双引号包住含单引号的内容）；三引号 """...""" 保留换行，适合写多行说明文本或 docstring。字符串运算四件套：len("Hello") 长度、"Hello" + " World" 拼接、"Ha" * 3 重复成 "HaHaHa"、"lo" in "Hello" 包含检查。f-string 里可以直接放表达式：f"明年我就{age + 1}岁了"。

布尔运算的真值表：True and False 是 False（与）、True or False 是 True（或）、not True 是 False（非）。比较运算全部产生布尔值：5 > 3 True、5 == 3 False、5 != 3 True、10 >= 10 True。None 的类型是 <class 'NoneType'>，用 type(result) 能看到，它既不等于 0 也不等于空字符串，判断只能用 is None。

【part1 补充】类型检查推荐 isinstance 而非 type：isinstance(42, int) 为 True，且对子类同样成立；type(x) == int 只认精确类型，写库函数时会误判子类。类型转换的三个方向字符串、整数、浮点互转都熟了之后，要特别记住 int(3.9) 得 3 是截断不是四舍五入，四舍五入写 round(3.9) 得 4。

31. 变量赋值的三种写法与命名约定1 个重点▾ 点开看本章重点
本章重点
  • 保留字不能作变量名：「if」、「for」、「class」、「import」、「return」、「None」、「True」、「False」、「lambda」 等约 35 个
2

【part1 补充】课件用"带标签的盒子"比喻变量，初学阶段够用；等写到可变对象（列表、字典）时要升级成本文第 2.1 节的"标签指向对象"模型，否则解释不了 b = a 后改 b 会影响 a。赋值三种写法：普通赋值 name = "Python"、多变量同时赋值 a, b, c = 1, 2, 3（等号两边元素个数必须一致，否则 ValueError）、同一值赋多变量 x = y = z = 0（三个名字指向同一个对象，可变对象时要小心共享）。

命名约定是团队协作的隐性契约：变量名和函数名用小写加下划线 user_name、get_total（蛇形命名，PEP 8 规定）；类名用大驼峰 BankAccount；常量全大写 MAX_RETRY = 3；模块名短小写 my_utils.py，不用连字符（会和减号混淆）。保留字不能作变量名：if、for、class、import、return、None、True、False、lambda 等约 35 个。判断某个词是不是保留字：import keyword; keyword.iskeyword("class") 返回 True。

命名的可读性优先级：宁可长一点也不要缩写到看不懂，elapsed_seconds 比 es 好；布尔变量习惯加 is_/has_ 前缀，is_valid、has_children，读代码的人一眼知道它是真假值；避免用 l、O、I 这类单字母（和数字 1、0 视觉混淆）。翻车现场是三个月后自己都读不懂 d = {k: v for k, v in x if f(k)} 这种单字母满天飞的推导式，改法是起有意义的名字，可读性永远优先于行数少。
