1. 为什么需要数据可视化与 Matplotlib

3

Matplotlib 是 Python 科学计算生态中常用的绘图库，适合探索数据、制作实验报告以及构建静态分析图表。本篇围绕十种常见图型建立基本操作体系：折线图、柱状图、散点图、直方图、饼图、箱线图、热力图、面积图、极坐标图和子图布局。学习时应先明确分析问题，再确定数据类型，最后选择视觉编码。图形中的位置和长度容易比较，面积和角度较难精确比较，因此不应仅凭外观决定图型。

表格适合保存和核对精确数值，却不总能让人迅速发现趋势、离群点、分布形态与变量关系。可视化把这些结构转换为可比较的视觉信号，帮助分析者提出假设、检查数据质量并向读者解释结论。Matplotlib 提供从数据数组到图元、坐标尺度与导出文件的完整控制，使绘图能够进入脚本和自动化流程，而不是依赖一次性手工操作。

如果缺少这一层能力，常见问题不只是“图不好看”，还包括用折线连接无序类别、用截断坐标夸大差异、把相关解释为因果、把候选异常直接删除，以及图片虽然生成却无法回答业务问题。学习 Matplotlib 的目标因此不是背诵函数，而是建立“问题—数据—图型—验证”的闭环。

2. 绘图对象与基本约定

3

Figure 是整体画布，一个 Figure 可以包含多个 Axes；Axes 是承载横纵坐标、数据图元、标题和刻度的绘图区。Axis 对象负责刻度与坐标尺度，Artist 则是图中各种可见对象的共同基础。日常分析优先使用 fig, ax = plt.subplots()，再调用 ax.plot() 等方法。相比持续依赖全局当前坐标轴，这种写法更适合函数、循环和复杂布局。

绘图前应确认数组等长、缺失值处理方式、时间顺序和类别编码。折线图必须按横轴排序，柱状图应确认每类是否已聚合，相关图要避免把类别编号误当连续变量。数值单位要写在轴标签中，日期范围和样本量可以写在标题或说明里。默认颜色只是起点，必须保证同一个颜色在整份报告中表达相同含义。

对象或方法 含义 常用操作
Figure 整体画布 控制尺寸与保存文件
Axes 独立绘图区 绘图、设置标题和标签
Axis 坐标轴与刻度 控制位置、格式和比例
图元 曲线、柱、点等对象 修改颜色、线宽、透明度
tight_layout 自动整理间距 减少文字与子图重叠

3. 图型选型的总体边界

3

图型由分析问题和数据结构共同决定，而不是由默认模板决定。下面的流程先区分趋势、类别差异、变量关系、分布、构成、矩阵和方向周期，再考虑是否需要以子图组合多个视角。

flowchart TD
    A[分析目标] --> B{看什么}
    B -->|趋势| C[折线或面积]
    B -->|类别差异| D[柱状或箱线]
    B -->|变量关系| E[散点]
    B -->|单变量分布| F[直方]
    B -->|整体构成| G[饼图]
    B -->|矩阵强度| H[热力]
    B -->|方向周期| I[极坐标]
    C --> J[需要多视角时组合子图]
    D --> J
    E --> J

4. 折线图：观察连续趋势

3

折线图适合时间、距离、迭代次数等有自然顺序的横轴，常用于观察销售趋势、实验收敛和设备温度。线段暗示相邻观测之间存在连续变化，不能把没有顺序的类别随意连起来。采样不均匀时应保留真实横轴间隔；缺测点不要随意补零，因为零是一个真实观测值。

多条线需要共享单位；如果曲线太多，应拆成子图，避免读者反复寻找图例。平滑曲线会隐藏短期波动，除非明确说明平滑窗口，否则应保留原始观测点。

5. 柱状图：比较分类数值

3

柱状图适合比较产品销量、部门预算和地区订单数，柱子的长度表达数值大小。纵轴通常从零开始，因为读者比较的是长度而非端点位置。类别名称很长时使用横向条形图，排名任务则按数值排序；如果类别有业务顺序，如季度或等级，应保留该顺序。

分组柱状图比较同类下的不同群体，堆叠柱状图比较总量和组成。若关心细微差异，应选择并排布局，因为堆叠后的中间部分缺少共同基线。

6. 散点图：探索两个变量的关系

3

散点图将两个数值变量编码为横纵位置，适合查看学习时长与成绩、广告投入与销售额、身高与体重等关系。第三个数值可以映射到点面积或颜色，但不能同时堆积过多编码。相关趋势不等于因果关系，业务解释还需要控制潜在混杂因素。

s 表示面积而不是半径，使用气泡图时必须明确大小含义；alpha 控制透明度，重叠严重时可调低；cmap 是颜色映射，连续变量适合连续色带。不要为没有数量顺序的类别使用渐变色，否则会制造不存在的大小关系。极端离群点可能压缩主体数据，应检查数据质量并考虑辅助放大图。

7. 直方图：理解单变量分布

3

直方图把连续数值分成区间，展示频数或概率密度，适合检查订单金额、响应延迟、考试成绩的偏态和尾部。区间数过少会隐藏结构，过多会放大随机波动。比较多个群体时应固定相同区间边界，否则柱高没有直接可比性。

密度的纵轴值不是概率，某个区间的概率约等于柱高乘区间宽度。长尾分布可以考虑对数横轴，但应说明对数变换及零值处理方式。

8. 饼图：表达整体构成

3

饼图适合少量类别组成同一整体，例如预算分配和流量来源。所有部分必须使用相同口径，数值应为非负，且整体定义明确。类别过多或占比接近时，条形图更便于比较。不要把同比增长率放进饼图，因为增长率之间没有可相加的整体。

autopct 控制百分比文字格式，startangle 决定起始方向，pctdistance 调整百分比距离，explode 可以突出一个类别但不宜滥用。默认归一化会把输入总和转换为百分比，报告中仍应交代原始总量。三维饼图会扭曲面积，基础分析应使用平面图。

9. 箱线图：比较群体分布

3

箱线图通过中位数、上下四分位数和须总结分布，适合比较多个门店客单价、班级成绩或服务器响应时间。箱体覆盖中间一半数据，箱内横线通常表示中位数。默认须延伸到距四分位数不超过一又二分之一倍四分位距的观测值，须外点是规则识别的候选异常，不能直接认定为错误数据。

patch_artist=True 允许填充箱体，showmeans=True 显示均值，whis 改变须的定义，showfliers=False 隐藏离群点。隐藏时必须披露，因为读者可能误判尾部风险。箱线图不能直接展示多峰结构，必要时配合直方图或小提琴图，样本量很小时可以叠加原始散点。

10. 热力图：展示二维矩阵

3

热力图将矩阵单元格数值映射为颜色，适合星期与时段的订单数、变量相关矩阵和实验条件网格。色条必须说明数值单位；多个热力图并排比较时，应固定颜色范围。单调数量使用顺序色带，正负偏差使用以零为中心的发散色带。

imshow 负责绘制矩阵，aspect="auto" 使格子适应画布，vmin 和 vmax 控制颜色端点。相关系数应固定为负一到一，而不能每张图自动缩放。矩阵较大时不要标注所有数字，应保留关键位置并提供原始表格供核对。

11. 面积图：呈现规模和组成变化

3

面积图通过曲线下方的填充强调规模，堆叠面积图进一步展示各部分对总量的贡献。适合不同渠道活跃用户或能源来源随时间变化。所有层必须使用相同单位且可相加；负值会让堆叠含义复杂，应谨慎处理。中间层缺乏稳定基线，不适合精确比较其变化幅度。

stackplot 的每个序列是一层，输入次序决定堆叠次序；labels 对应图例，alpha 调整透明度。单条曲线填充可使用 fill_between，还可以用上下界数组表达置信区间。置信区间与累计面积的含义不同，必须在说明中明确。

12. 极坐标图：表达方向与周期

3

极坐标以角度和半径定位点，适合方向强度、日内周期和雷达扫描。角度单位默认是弧度，常见错误是把角度制直接传入。若制作雷达图，指标必须具有可比较尺度，且排列顺序会改变形状，不应仅凭多边形面积评价综合能力。

projection="polar" 创建极坐标，set_theta_zero_location 设置零度方向，set_theta_direction(-1) 表示顺时针。首尾重复点使多边形闭合；半径下限应保持为零。方向类别应标注真实含义，而不能让读者猜测每个角度代表什么。

13. 子图布局：对照多个分析视角

3

子图是布局能力，能把同一指标的趋势、分布和异常放在一个画布中。适合探索报告、诊断面板和实验比较。共享横轴适用于相同时间范围，共享纵轴适用于相同单位；如果各子图尺度不同，应让刻度清楚可见，避免错误比较。

不规则布局可以进一步学习 GridSpec 和 subplot_mosaic。布局之前先确定各面板承担的问题，避免把十张互不相关的图拼成难以阅读的大图。

15. 折线图实操

3 
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

days = np.arange(1, 8)
sales = np.array([18, 22, 20, 27, 31, 29, 35])
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(days, sales, marker="o", linewidth=2, color="#2563eb", label="Sales")
ax.set(title="Weekly sales", xlabel="Day", ylabel="Sales (10k CNY)")
ax.set_xticks(days)
ax.grid(alpha=0.25)
ax.legend()
fig.tight_layout()
fig.savefig("line_basic.png", dpi=150)
plt.close(fig)
参数 作用 使用建议
marker 数据点形状 少量观测时突出实测位置
linewidth 线宽 主线可设为二，辅助线更细
linestyle 线型 虚线可表示预测或基准
label 图例名称 用业务名称说明指标

16. 柱状图实操

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

products = ["Keyboard", "Mouse", "Headset", "Monitor"]
amounts = [120, 185, 150, 92]
fig, ax = plt.subplots(figsize=(7, 4))
bars = ax.bar(products, amounts, width=0.65, color="#3b82f6")
ax.bar_label(bars, fmt="%d", padding=3)
ax.set(title="Sales by product", xlabel="Product", ylabel="Units")

参数 作用 注意事项
width 柱宽 柱间留白有助于区分类别
bottom 柱底位置 常用于堆叠，但须说明总量
color 柱颜色 无分组语义时可以统一颜色
bar_label 添加柱顶标签 小类别数时提供精确数值

import matplotlib
matplotlib.use("Agg")

import numpy as np

angles = np.linspace(0, 2 * np.pi, 8, endpoint=False)
values = np.array([62, 74, 68, 80, 71, 55, 60, 77])
closed_angles = np.r_[angles, angles[0]]
closed_values = np.r_[values, values[0]]
fig, ax = plt.subplots(figsize=(6, 6), subplot_kw={"projection": "polar"})
ax.plot(closed_angles, closed_values, color="#7c3aed", linewidth=2)
ax.fill(closed_angles, closed_values, color="#a78bfa", alpha=0.35)
ax.set_theta_zero_location("N")
ax.set_theta_direction(-1)
ax.set_ylim(0, 100)
ax.set_title("Directional satisfaction", pad=20)
fig.tight_layout()
fig.savefig("polar_basic.png", dpi=150)
plt.close(fig)

24. 子图布局实操

3 
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(4)
months = np.arange(1, 13)
values = 50 + 8 * np.sin(months / 2) + rng.normal(0, 2, 12)
fig, axes = plt.subplots(2, 2, figsize=(9, 6))
axes[0, 0].plot(months, values, marker="o")
axes[0, 0].set(title="Trend", xlabel="Month", ylabel="Value")
axes[0, 1].bar(months, values, color="#34d399")
axes[0, 1].set(title="Monthly comparison", xlabel="Month", ylabel="Value")
axes[1, 0].hist(values, bins=6, color="#fbbf24", edgecolor="white")
axes[1, 0].set(title="Distribution", xlabel="Value", ylabel="Count")
axes[1, 1].boxplot(values, vert=False)
axes[1, 1].set(title="Summary", xlabel="Value")
for ax in axes.flat:
    ax.grid(alpha=0.2)
fig.suptitle("Four views of one metric")
fig.tight_layout(rect=[0, 0, 1, 0.95])
fig.savefig("subplots_basic.png", dpi=150)
plt.close(fig)
布局参数 含义 使用建议
nrows, ncols 行列数量 用少量子图表达完整问题
figsize 画布尺寸，单位英寸 文字多时增加宽度
sharex, sharey 共享坐标尺度 仅在量纲一致时使用
rect 布局保留区域 为总标题预留顶部空间

25. 共同参数与交付检查

3

图表标题应表达主要问题，例如“第三季度各产品销量”，避免只有“分析图”这种泛称。横纵轴必须写单位，色条必须有含义，图例只承担识别任务，不要重复标题。网格线应低对比，避免盖过数据。不要给所有点都加文字，只有异常、拐点和关键业务事件值得直接标注。

26. 常见问题与排错

3

中文显示方块通常是字体缺失，可从系统字体中选择已安装的中文字体，再设置 Matplotlib 的字体参数。不要假设每台电脑都有同一种字体；跨平台交付应写清字体要求。负号显示异常可检查 axes.unicode_minus，但不要为修复字体而改动数据。示例使用英文图中文字，便于在基础环境验证真实绘制过程。

数组长度不一致时检查横纵坐标是否使用了同一筛选条件；颜色数组长度也必须与点数一致。出现全空白图时检查保存对象是否正确、数据是否为空以及是否提前关闭。图例没有显示时检查是否设置了有效 label，并在绘图之后调用 legend。色条与主图不匹配时，应直接把 scatter 或 imshow 返回的图元传给 colorbar。

直方图“高度异常”可能来自密度单位，而不是计算错误。饼图百分比总和略偏离百分之百可能来自标签四舍五入。箱线图的离群点不能自动删除；应回查业务记录。折线出现异常长连接时检查时间排序、时区和缺测间隔。热力图视觉差异过大时先检查各图是否使用了不同的颜色范围。这些排查都应回到数据和视觉编码，而不能仅通过美化掩盖问题。

27. 练习任务与验收方法

3

建议用同一份小型销售数据练习十种表达，而不是每次更换完全不同的数据集。先以日期、产品、销量和销售额构造明细表，按日期聚合后绘制折线，按产品聚合后绘制柱状，按单笔金额绘制直方与箱线。这样能够直观看到聚合层级改变后，图形回答的问题也随之变化。切勿把明细中的多笔记录直接当作每日汇总，否则同一天出现多个点时，折线会产生误导。

对每张图设定一个可检验的问题。例如折线图必须能指出高峰发生日期，柱状图必须能比较销量最高的类别，热力图必须能定位最繁忙的时段。验证时先计算原始数值，再检查图中位置和颜色是否对应计算结果；不能仅凭“图片生成了”认定正确。若业务数据包含退款，构成图应明确使用销售毛额还是净额，面积图还应确认负值对累计意义的影响。

检查样本覆盖也很重要。某家门店没有记录可能表示停业、数据缺失或真实零订单，这三种状态不能混用。固定类别顺序后，缺失类别可以显式留空或标记未知；只有确认真实为零时才填零。不同月份天数不同时，比较总量和日均量回答的是不同问题，应根据分析目标选择并写明口径。

最后进行一次脱离背景的阅读测试：让不熟悉数据的人仅凭标题、轴标签、图例和说明描述图中结论。若对方误解颜色、单位或时间范围，优先修改表达；若对方无法精确区分接近的扇区，考虑改成条形图。可视化交付不仅是程序执行结果，也是一份需要独立解释的数据证据。

28. 小结与进阶练习

3

Matplotlib 基础能力可以归纳为明确问题、选择图型、建立对象、完善解释和检查输出五步。折线看趋势，柱状看类别差异，散点看关系，直方和箱线看分布，饼图看少量构成，热力图看矩阵，面积图看累计贡献，极坐标看周期方向，子图布局把这些视角组织到同一画布。每种图都有表达边界，专业绘图的关键是让图型、数据和结论一致。

练习时可以先替换示例中的数据，再改变参数观察影响：调整直方图分箱、散点透明度、箱线须规则和热力图颜色范围。每次变化都应解释“为什么这样更容易回答问题”。完成一张图后，脱离代码独立阅读，检查读者能否看懂数据来源、单位、时间范围和主要结论。基础阶段建立这种检查习惯，比记住更多函数名称更有价值。
