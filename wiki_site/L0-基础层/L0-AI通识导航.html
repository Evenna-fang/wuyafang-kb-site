2. 三大岔路口：一句话指方向

2

小白最容易在三个岔路口卡住。每个岔路口给一句决策规则，按规则走，不纠结。

2.1 想学训练还是想学评估？3 个重点▾ 点开看本节重点
本节重点
  • 想学训练（怎么让模型学会新知识/新风格） → 去 L6-模型微调
  • 一句话决策：模型本身要改 → L6；模型不动、答案质量要量化 → L8
  • 那里讲 LoRA 微调完整 pipeline、微调到底省了什么、大模型是怎么训练出来的、梯度消失怎么解决
3

这是小白最常问的岔路：

  • 想学训练（怎么让模型学会新知识/新风格） → 去 L6-模型微调。那里讲 LoRA 微调完整 pipeline、微调到底省了什么、大模型是怎么训练出来的、梯度消失怎么解决。适合你的信号：你有明确的领域数据，想让模型「懂你的业务」，且接受训练成本。
  • 想学评估（怎么知道模型/系统答得对不对） → 去 L8-5-评估体系。那里讲 LLM 评估体系 Evals、RAG 评测三层方法论、RAGAS 指标（context_precision/context_recall/faithfulness/answer_relevancy）、RAG 管线现状与阈值标定。适合你的信号：你的系统已经能跑，但不知道好不好、怎么量化改进。

一句话决策：模型本身要改 → L6；模型不动、答案质量要量化 → L8。多数 AI 应用落地场景其实是后者（评估先行），因为「能跑」和「跑对」是两回事。

2.2 学提示词还是学 RAG？

3
  • 提示词（Prompt）：解决风格、格式、任务定义问题，零成本、快速见效。入口：L2-大模型交互，细读 Prompt 与 LangChain 与 vLLM 前沿精读、System Prompt 怎么写才好、Few-shot 和 Zero-shot 怎么选、上下文工程-Context-Engineering。
  • RAG（检索增强生成）：解决知识时效性、私有知识问题。入口：L4-RAG工程，那里有 RAG 作战手册全景图、企业级 RAG 搭建全流程、Chunk 大小怎么选、Embedding 模型选型对比、RAG 检索不准怎么排查。

一句话决策：问题出在「怎么问」→ L2；问题出在「模型不知道你的知识」→ L4。两者常配合用（Prompt 里塞 RAG 检索到的上下文），不是二选一。
