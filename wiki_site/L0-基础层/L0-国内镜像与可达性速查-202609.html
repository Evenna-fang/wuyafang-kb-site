关键结论（避坑）

2
  1. arXiv 现在直连可用，不需要用老镜像 xxx.itp.ac.cn（已死）。
  2. GitHub 代理域名生命周期短：ghproxy.com 主域已死，现在用 gh-proxy.com 或 ghproxy.net。
  3. HuggingFace 必须走 hf-mirror.com，否则下载慢/失败。
  4. 国内模型下载优先 ModelScope，比 HF 镜像快。
  5. 镜像类站点不实测直接写进知识库 = 埋坑：本次实测豆包给的旧清单 30% 是死链。
