随机变量是"把随机结果映射成数字的规则"。掷骰子的结果 1~6 本身就是随机变量；"掷出偶数记 1、奇数记 0"是另一个随机变量。概率分布是"每个可能取值对应多大份额"的完整清单。

概率的可操作定义用频率：抛一枚均匀硬币 1000 次，正面朝上的频率会稳定在 0.5 附近，稳定到的那个数就是概率。这个定义叫频率学派。贝叶斯学派把概率理解为"主观置信度"，可以对"明天会下雨吗"这种一次性事件给概率。工程上两种理解都会用到：模型评测用频率（重复采样），在线推理的置信度输出用贝叶斯（单次预测的不确定性）。

1.2 期望、方差、标准差：分布的两个抓手

3
  • 期望 E[X]：分布的重心，长期平均会稳定到的值。E[X] = Σ x·P(x)（离散）或积分（连续）。
  • 方差 Var(X) = E[(X - E[X])²]：分布的离散程度，单位是原单位的平方。
  • 标准差 σ = sqrt(Var(X))：把单位拉回原单位，更可读。
  • 协方差 Cov(X,Y)：两个变量一起变化的程度；除以各自标准差就是相关系数。

代码 1：样本均值/方差与 MLE 偏差（可直接跑）

# 运行环境: numpy 2.4.3 / scipy 1.18.1
import numpy as np

rng = np.random.default_rng(2)
x = rng.normal(size=500)

print("样本均值:", round(float(x.mean()), 4))          # 实跑 -0.0534，接近 0
print("样本方差(ddof=1):", round(float(x.var(ddof=1)), 4))  # 实跑 1.0268，除以 n-1，无偏
print("样本方差(ddof=0):", round(float(x.var(ddof=0)), 4))  # 实跑 1.0248，除以 n，MLE 有偏
print("标准差:", round(float(x.std(ddof=1)), 4))       # 实跑 1.0133

# MLE 偏差实测：np.cov 的 bias 参数
y = 1.5 * x + rng.normal(scale=0.5, size=500)
mle = np.cov(np.vstack([x, y]), rowvar=True, bias=True)     # 除以 n
unbiased = np.cov(np.vstack([x, y]), rowvar=True)           # 除以 n-1
print("cov MLE[0,1]:", round(float(mle[0, 1]), 4))     # 实跑 1.5306
print("cov 无偏[0,1]:", round(float(unbiased[0, 1]), 4))  # 实跑 1.5336
print("两者比值:", round(float(mle[0, 1] / unbiased[0, 1]), 4))  # 实跑 0.998 = (n-1)/n

ddof（delta degrees of freedom）是分母的自由度修正：ddof=1 除以 n-1 是无偏估计，ddof=0 除以 n 是最大似然估计（有偏但偏差随 n 衰减）。实测 n=500 时两者比值 0.998，正是 (500-1)/500 = 0.998。规则：做推断（置信区间、假设检验）用 ddof=1；做描述或喂模型用哪个都行，但团队代码要统一，别一处 ddof=0 一处 ddof=1。

2.2 scipy.stats：分布对象比裸函数好用

3

scipy 的 scipy.stats 把每个分布做成对象，统一四件套：rvs（采样）、pdf/pmf（密度/质量）、cdf（累积概率）、ppf（分位数，cdf 的反函数）。ppf 就是"95 分位数是多少"的答案机器。

代码 2：分布对象四件套（可直接跑）

from scipy import stats
import numpy as np

n = stats.norm(loc=100, scale=15)          # IQ 型正态：均值 100，标准差 15
print("均值/标准差:", n.mean(), n.std())     # 100.0 15.0
print("95% 分位数:", round(n.ppf(0.95), 2))  # 124.67  ← "多少算高"的答案，实跑一致
print("P(X<=115):", round(n.cdf(115), 4))    # 0.8413，实跑一致
print("采样10个:", np.round(n.rvs(10, random_state=0), 1))

b = stats.binom(n=10, p=0.3)               # 10 次试验、每次成功率 0.3
print("二项分布 E[X]:", b.mean())            # 3.0  = n*p，实跑一致
print("P(X=3):", round(b.pmf(3), 4))         # 0.2668，实跑一致

# 泊松：每秒平均 5 个请求，1 秒内 8 个的概率
p = stats.poisson(mu=5)
print("泊松 P(X=8):", round(p.pmf(8), 4))    # 0.0653，实跑一致
print("泊松 P(X>=8):", round(1 - p.cdf(7), 4))  # 实跑 0.1334，上尾概率

ppf(0.95) = 124.67 这类数字是"阈值"的标准来源：设置告警线、确定异常值边界（±3σ 之外）、算容量规划，全靠 ppf。cdf 是 ppf 的反函数，cdf(ppf(q)) = q，调试分布参数时用这对关系自检。

3. 大数定律与中心极限定理：两个最常被引用的定理

2
3.1 白话直觉3 个重点▾ 点开看本节重点
本节重点
  • 大数定律：样本量越大，样本均值越接近总体均值
  • 这就是"均值检验用 t 检验/正态近似"的合法性来源，也是"为什么样本量越大置信区间越窄"的答案
  • "抛 10 次 60% 正面，抛 10000 次就接近 50%"
3

大数定律：样本量越大，样本均值越接近总体均值。"抛 10 次 60% 正面，抛 10000 次就接近 50%"。它保证的是收敛方向，不保证"偏离会均匀缩小"。

中心极限定理（CLT）：不管总体什么分布，样本均值的分布趋近正态，且标准差缩小为 σ/√n。这就是"均值检验用 t 检验/正态近似"的合法性来源，也是"为什么样本量越大置信区间越窄"的答案。

3.2 代码：CLT 的实测证据

3

代码 3：中心极限定理实测（可直接跑）

import numpy as np

rng = np.random.default_rng(7)
# 总体：指数分布（右偏，绝不是正态）
lam = 2.0
n_reps, n_sample = 1000, 30
means = np.array([rng.exponential(1 / lam, size=n_sample).mean()
                  for _ in range(n_reps)])

print("总体均值(理论 1/λ = 0.5):", round(1 / lam, 3))          # 0.5
print("1000 组样本均值的均值:", round(float(means.mean()), 4))  # 实跑 0.5027
print("样本均值的理论标准差 σ/√n:", round((1 / lam) / np.sqrt(n_sample), 4))  # 0.0913
print("实测标准差:", round(float(means.std(ddof=1)), 4))        # 实跑 0.0900
q = np.percentile(means, [2.5, 97.5])
print("样本均值分布的 2.5%/97.5% 分位数:", np.round(q, 4))     # 实跑 [0.347  0.6948]
# 偏度检验：原始数据严重右偏，均值分布近似对称
from scipy import stats
print("原始偏度:", round(float(stats.skew(rng.exponential(1 / lam, size=10000))), 3))  # 实跑 1.996
print("均值分布偏度:", round(float(stats.skew(means)), 3))                             # 实跑 0.359

本机 scipy 1.18.1 实跑关键数字：1000 组、每组 30 个指数样本（λ=2，理论均值 0.5）的均值分布，均值 0.5027，实测标准差 0.0900 与理论 σ/√n = 0.0913 吻合；2.5%/97.5% 分位数实测 [0.347, 0.6948]；原始数据偏度 1.996（严重右偏），均值分布偏度降到 0.359——CLT 的可视化证据。注意均值分布的偏度只是"变小"不是"归零"，n=30 时正态近似仍有残余偏态，这正是小样本慎用正态近似的原因。

4. 最大似然估计（MLE）：让"观察到的数据最可能发生"

2
4.1 白话直觉3 个重点▾ 点开看本节重点
本节重点
  • 给定数据，问"什么样的参数让这组数据出现的概率最大"
  • 3. 有偏但偏差可控：样本方差的 MLE（除以 n）比无偏估计（除以 n-1）小 「(n-1)/n」 倍，n 大时可忽略——这正是 §1.2 实测的 0.998
  • 神经网络的 loss 设计几乎都是 MLE：MSE loss 对应"误差是正态"的似然，交叉熵 loss 对应"标签是伯努利/多项分布"的似然
3

给定数据，问"什么样的参数让这组数据出现的概率最大"。答案就是最大似然估计。抛硬币 10 次出现 7 次正面，MLE 就是 p̂ = 7/10 = 0.7——因为 p=0.7 时这组数据出现的概率最大。

MLE 的三个工程性质：

  1. 一致性：样本越多越接近真值。
  2. 渐近有效性：大样本下方差最小。
  3. 有偏但偏差可控：样本方差的 MLE（除以 n）比无偏估计（除以 n-1）小 (n-1)/n 倍，n 大时可忽略——这正是 §1.2 实测的 0.998。

神经网络的 loss 设计几乎都是 MLE：MSE loss 对应"误差是正态"的似然，交叉熵 loss 对应"标签是伯努利/多项分布"的似然。"最小化 loss = 最大化似然"是同一件事的两种说法。

4.2 代码：手写 MLE 与 loss 的等价性

3

代码 4：正态 MLE 与 MSE 的等价（可直接跑）

import numpy as np
from scipy import stats, optimize

rng = np.random.default_rng(11)
data = rng.normal(loc=3.0, scale=1.5, size=200)

# MLE 闭式解：正态的 μ̂ = 样本均值，σ̂ = 样本标准差(ddof=0)
mu_hat, sigma_hat = data.mean(), data.std(ddof=0)
print("MLE μ:", round(float(mu_hat), 4), "真值 3.0")   # 实跑 3.0245
print("MLE σ:", round(float(sigma_hat), 4), "真值 1.5") # 实跑 1.3837

# 数值 MLE：最大化对数似然 = 最小化负对数似然
def neg_loglik(params):
    mu, sigma = params
    return -np.sum(stats.norm.logpdf(data, loc=mu, scale=sigma))

res = optimize.minimize(neg_loglik, x0=[0.0, 1.0], method="Nelder-Mead")
print("数值 MLE:", np.round(res.x, 4), "与闭式解一致:",
      np.allclose(res.x, [mu_hat, sigma_hat], atol=1e-3))

# MSE loss = 正态负对数似然（差一个常数）
def mse_loss(params):
    mu = params[0]
    return np.mean((data - mu) ** 2)

res2 = optimize.minimize(mse_loss, x0=[0.0])
print("MSE 最优 μ:", round(float(res2.x[0]), 4), "== 样本均值:",
      np.isclose(res2.x[0], mu_hat))

from scipy import stats

# 场景：点击率估计。先验：Beta(2, 2)（温和相信点击率约 0.5）

# 观察数据：10 次曝光，3 次点击
clicks, shows = 3, 10
post_a = prior_a + clicks                            # 共轭更新：a 加成功数
post_b = prior_b + (shows - clicks)                  # b 加失败数

print("后验均值:", round(post.mean(), 4))             # 5/14 ≈ 0.3571，实跑一致

# 再来 10 次曝光、7 次点击 → 序贯更新

post2 = stats.beta(post_a, post_b)
print("两次数据后验均值:", round(post2.mean(), 4))    # 12/24 = 0.5
print("区间宽度先验→后验→两轮:",
      round(prior.interval(0.95)[1] - prior.interval(0.95)[0], 4),
      round(post.interval(0.95)[1] - post.interval(0.95)[0], 4),
      round(post2.interval(0.95)[1] - post2.interval(0.95)[0], 4))

假设检验的流程：①设原假设 H₀（"两组没差别"）；②选检验统计量；③算"如果 H₀ 是真的，观察到当前数据或更极端情况的概率"——这个概率就是 p 值；④p < 阈值（通常 0.05）就拒绝 H₀。

p 值的常见误读（三条，条条致命）：

  1. p 值不是"H₀ 为真的概率"。它是"假设 H₀ 为真时，数据有多反常"。反过来说"p=0.03 所以有 97% 概率有效"是错的。
  2. p 小 ≠ 效应大。样本量巨大时，1% 的提升也能 p<0.001。
  3. p 大 ≠ 没差别。可能是样本量不够（功效不足）。

正确读法：p 值是"数据与 H₀ 的不兼容程度"。是否上线看效应量 + 置信区间 + 业务成本，p 值只是排除随机波动的门票。

import numpy as np
from scipy import stats

rng = np.random.default_rng(42)
control = rng.normal(loc=10.0, scale=2.0, size=200)   # 对照组

print("p 值:", round(float(p), 6))
# 实跑（numpy 2.4.3/scipy 1.18.1）：t=3.6774 p=0.000268

# 效应量 Cohen's d：差值 / 合并标准差

d = (treat.mean() - control.mean()) / sp
print("Cohen's d:", round(float(d), 4))                # 实跑 0.3677，小到中效应

# 95% 置信区间（差值）
diff = treat.mean() - control.mean()
se = np.sqrt(control.var(ddof=1)/len(control) + treat.var(ddof=1)/len(treat))
ci = (diff - 1.96*se, diff + 1.96*se)
print("差值:", round(float(diff), 3), "95% CI:", np.round(ci, 3))
# 实跑：差值 0.701，95% CI = (0.327, 1.075)

# 功效：这个样本量检测 d=0.3 的能力（scipy 1.18 的 power 接口）
from statsmodels.stats.power import TTestIndPower  # 若未装则用下式手算

"""A/B 实验完整流程：生成数据 → 描述统计 → t 检验 → 效应量 → 结论。
运行: numpy 2.4.3, scipy 1.18.1"""
import numpy as np
from scipy import stats

rng = np.random.default_rng(2026)
n = 400
control = rng.normal(loc=10.0, scale=2.5, size=n)      # 对照组指标
treat = rng.normal(loc=10.45, scale=2.5, size=n)       # 实验组，真实提升 0.45

# 1) 描述统计
for name, arr in [("control", control), ("treat", treat)]:
    print(f"{name}: n={len(arr)} mean={arr.mean():.3f} std={arr.std(ddof=1):.3f} "
          f"p50={np.percentile(arr, 50):.3f} p95={np.percentile(arr, 95):.3f}")

# 2) 正态性粗检（n=400 时 CLT 已足够稳，这里只做演示）
sh = stats.shapiro(control)
print("control shapiro p:", round(float(sh.pvalue), 4))

# 3) 独立双样本 t 检验
t, p = stats.ttest_ind(treat, control, equal_var=True)
diff = treat.mean() - control.mean()
se = np.sqrt(control.var(ddof=1)/n + treat.var(ddof=1)/n)
print(f"diff={diff:.3f} 95%CI=({diff-1.96*se:.3f}, {diff+1.96*se:.3f})")
print(f"t={t:.3f} p={p:.6f}")

# 4) 效应量
sp = np.sqrt((control.var(ddof=1) + treat.var(ddof=1)) / 2)
print(f"Cohen's d = {diff/sp:.4f}")

# 5) 结论规则（写成代码而不是写在 PPT 里）
alpha, mde = 0.05, 0.3
sig = p < alpha
meaningful = abs(diff) > mde
print(f"统计显著={sig} 业务可交付={meaningful} → "
      f"{'上线' if sig and meaningful else '继续观察或放弃'}")

这段脚本把"结论规则"写成布尔表达式而不是拍脑袋：统计显著 AND 业务可交付 → 上线。实跑输出（numpy 2.4.3/scipy 1.18.1）：control 均值 10.114（标准差 2.608，p50=10.149，p95=14.247），treat 均值 10.536（标准差 2.535，p50=10.591，p95=14.531），shapiro p=0.7692（不拒绝正态），diff=0.422、95% CI=(0.065, 0.778)、t=2.319、p=0.020651、Cohen's d=0.1640。结论是统计显著（p<0.05）但效应量 d=0.16 属小效应，diff=0.422 超过 MDE=0.3 的门槛——脚本输出"上线"，但真实决策里 d=0.16 的小效应要算收益成本比。这正是 §6 三条误读的实际演示。

print("stats.poisson.fit 可用:", hasattr(stats.poisson, "fit"))  # False ← 翻车点

# 方法 3：拟合优度检验——数据真的服从泊松吗
# 注意 scipy 1.18 的 chisquare 严格校验 obs/exp 总和相等（相对容差 1.5e-8），
# 必须先合并尾部稀疏桶再归一化，否则报 ValueError
obs = np.bincount(clicks)
exp_full = stats.poisson.pmf(np.arange(len(obs)), lam_hat) * 500
k = 8                                                     # k 之后的计数并成一个"尾部桶"
obs2 = np.concatenate([obs[:k], [obs[k:].sum()]])
exp2 = np.concatenate([exp_full[:k], [exp_full[k:].sum()]])
exp2 = exp2 * (obs2.sum() / exp2.sum())                   # 归一化到同总数
chi2, p = stats.chisquare(obs2, exp2)
print(f"卡方拟合优度: chi2={chi2:.2f} p={p:.4f}", "→ 不拒绝泊松假设" if p > 0.05 else "→ 拒绝泊松假设")
# 实跑：lambda_hat=2.992, chi2=5.31, p=0.7238 → 不拒绝泊松假设

# 预测：下一小时 5 次点击以上的概率
print("P(X>=5) =", round(1 - stats.poisson.cdf(4, lam_hat), 4))   # 实跑 0.1834

三个方法互相印证：MLE 闭式、scipy.fit、拟合优度检验。stats.chisquare 的 p 值回答"泊松假设与数据是否兼容"，这是模型选择的基本动作——拟合出参数后必须回头验证分布假设，不然后面所有推断都建立在流沙上。实跑时 obs 与 exp 的形状必须一致且总和相同，stats.chisquare 要求观测频次和为样本数，不满足会报 ValueError。

13.2 期望值决策：该不该做这次尝试

3

概率最实用的形态是期望值：EV = p·收益 - (1-p)·成本 或简化 EV = p·win - cost。实测（numpy 2.4.3）：成功率 2%、成功收益 1000 元、单次成本 15 元，EV = 0.02×1000 - 15 = 5.0 元/次——值得做；盈亏平衡成功率是 cost/win = 0.015（1.5%），低于这个 p 就亏。这个框架用在：功能开关灰度（p=预期转化率）、重试策略（p=单次成功率，成本=延迟）、数据标注投入（p=标注质量提升）。注意 EV 框架假设"可重复"和"线性效用"——一次性决策或损失厌恶场景（亏 100 的痛 > 赚 100 的乐）要改用期望效用或保守准则（minimax）。

13.3 流式统计：Welford 在线算法1 个重点▾ 点开看本节重点
本节重点
  • print("Welford:", round(m, 10), round(v / (len(xs) - 1), 10))
3

数据流式到达（Kafka、日志 tail）时不能全量存下来算均值方差，Welford 算法逐条更新且数值稳定：

import numpy as np

rng = np.random.default_rng(2026)
xs = rng.normal(7, 2, 1000)
m, v = 0.0, 0.0
for i, x in enumerate(xs, 1):
    delta = x - m
    m += delta / i
    v += delta * (x - m)          # 在线方差累积
print("Welford:", round(m, 10), round(v / (len(xs) - 1), 10))
print("批量:   ", round(float(xs.mean()), 10), round(float(xs.var(ddof=1)), 10))
# 实跑：两者精确到 10 位小数完全一致：7.0421344398 / 4.251606635

实跑验证：Welford 与批量计算精确到 10 位小数完全一致。朴素做法 sum(x²)/n - (sum(x)/n)² 在大量级数据上会精度灾难（两个大数相减），Welford 用增量更新绕开。这是监控系统、实时看板的标准算法，任何"流式算均值方差"的需求都该用它而不是存全量。

13.4 样本量规划：要多少数据才够

3

置信区间半宽 hw = 1.96·σ/√n，反解 n = (1.96·σ/hw)²。实测（scipy 1.18.1）：σ=2 时，要 95% CI 半宽 ≤0.2 需要 n≥385，半宽 ≤0.1 需要 n≥1537。这个公式是实验设计、评测集规模、日志采样量的通用起点：先定"你想多精确"（hw），再算"需要多少样本"（n），而不是先收数据再看能说什么。方差未知时先跑 50 个样本估 σ，再按公式补样本——两阶段设计比"拍脑袋采 1000 条"高效。

14.2 模型校准（calibration）：置信度要诚实

3

模型输出 0.9 的置信度，应该真的有 90% 是对的。检查方法：把预测按置信度分桶，每桶比较"平均置信度"和"实际准确率"。实测（numpy 2.4.3，1000 个样本）：置信度 0.4~0.6 桶（83 个样本）置信度均值 0.538、实际准确率 0.542；0.8~1.0 桶（567 个）置信度 0.885、准确率 0.892——桶内两者接近，模型校准良好。校准差的形态：高置信桶准确率显著低于置信度（模型过度自信），修复用 Platt scaling 或 isotonic regression（对输出做单调变换），或训练时加 label smoothing。校准和准确率是两回事：准确率 90% 的模型可以完全没校准（说 0.9 的其实只有 60% 对）——风险决策（医疗、风控）必须查校准。

二分类的负对数似然 NLL = -[y·log(p̂) + (1-y)·log(1-p̂)] 就是 log-loss。实测（numpy 2.4.3）：y=[1,0,1,1,0]、p̂=[0.9,0.2,0.8,0.7,0.3]，NLL = 1.265。单个样本预测 0.9 且正确，log-loss = -log(0.9) = 0.1054；预测 0.999 且正确只罚 0.001——log-loss 对"自信且正确"的奖励无上限，对"自信且错误"的惩罚爆炸（-log(0.001) = 6.9），这就是它作为训练损失的特性：逼模型要么别猜、要猜就猜准。accuracy 没有这个性质（0.51 和 0.99 的正确预测得分一样），所以训练用 log-loss、报告用 accuracy+AUC。

14.4 熵：不确定性的度量

H(p) = -Σ p·log(p) 度量分布的混乱程度。实测（numpy 2.4.3）：均匀分布 [1/3,1/3,1/3] 的熵是 1.0986（最大不确定），尖峰分布 [0.98,0.01,0.01] 的熵是 0.1119（几乎确定）。工程用法：①决策树按"信息增益 = 父节点熵 - 子节点加权熵"选分裂特征；②主动学习选"熵最大的样本"标注（模型最不确定的）；③LLM 温度采样里温度→0 时熵→0（贪心），温度→∞ 时熵→最大（均匀）；④输出熵监控模型漂移（预测分布的熵突然变大 = 输入分布变了）。

15.1 完整流程（可直接跑）1 个重点▾ 点开看本节重点

"""贝叶斯 A/B：Beta 后验 → 后验对比 → 决策。运行: scipy 1.18.1"""
import numpy as np
from scipy import stats

# 数据：对照组 2000 曝光 120 点击（6.0%），实验组 2000 曝光 150 点击（7.5%）
ca, na = 120, 2000
cb, nb = 150, 2000
pa = stats.beta(1 + ca, 1 + na - ca)      # 后验 A：Beta(121, 1881)
pb = stats.beta(1 + cb, 1 + nb - cb)      # 后验 B：Beta(151, 1851)

# 后验采样 20 万次做对比（蒙特卡洛，不需要解析推导）
sa = pa.rvs(200000, random_state=1)
sb = pb.rvs(200000, random_state=2)
d = sb - sa

print("后验均值 A/B:", round(float(pa.mean()), 5), round(float(pb.mean()), 5))
print("E[差值]:", round(float(d.mean()), 5))
print("差值 95% CI:", np.round(np.percentile(d, [2.5, 97.5]), 5))
print("P(B > A):", round(float((sb > sa).mean()), 4))
print("E[相对提升]:", round(float((d / sa).mean()), 5))

# 决策：期望损失（选错的代价）
loss_b = float(np.maximum(sa - sb, 0).mean())    # 选 B 但 A 更好的期望损失
loss_a = float(np.maximum(sb - sa, 0).mean())    # 选 A 但 B 更好的期望损失
print("E[损失|选B]:", round(loss_b, 7), "E[损失|选A]:", round(loss_a, 5))
print("决策:", "选 B" if loss_b < 0.001 else "继续观察")

实跑输出（scipy 1.18.1）：后验均值 A=0.06044、B=0.07542（真实点击率 6% vs 7.5%）；E[差值]=0.01497，95% CI [-0.00056, 0.03057]（跨 0，说明差异仍不确定）；P(B>A)=0.9705（B 有 97% 概率更好）；E[相对提升]=25.7%（中位数 24.8%）；期望损失：选 B 是 0.00009、选 A 是 0.01506——选 B 的风险小 167 倍，决策"选 B"通过（期望损失 < 0.001 的门槛）。

15.2 与频率派的对照：同一份数据两种结论

本节重点

  • 保守策略（上线代价大）要求 「P(B>A) > 0.95」 且 「E[损失|选B] A) > 0.8」 就可以上
3

§14.5 说"任何概率阈值背后都藏着成本比"，贝叶斯 A/B 的版本是：P(B>A) 要多高才敢上线？保守策略（上线代价大）要求 P(B>A) > 0.95 且 E[损失|选B] < 业务可接受阈值；激进策略（先跑着看）P(B>A) > 0.8 就可以上。实测里 P(B>A)=0.9705 两个策略都过，但如果 P(B>A)=0.85，保守派继续观察、激进派上线——这就是贝叶斯框架的灵活性：把风险偏好写成参数而不是藏在"显著"二字里。

16. 采样方法：拒绝采样、重要性采样、分层采样（附实测）

2
16.1 拒绝采样（Rejection Sampling）：从任意分布抽样2 个重点▾ 点开看本节重点
本节重点
  • 接受率的含义：M 越松（提议分布离目标越远）接受率越低、浪费越大
  • 工程用法：贝叶斯后验采样（后验归一化常数难算）、能量模型生成；代价是高维空间接受率指数级下降（10 维就基本不可行），高维换 MCMC/变分推断（超出 L0 范围）
3

目标分布的密度函数往往算不出归一化常数（p(x) = f(x)/Z，Z 难算），拒绝采样绕开它：找一个可采样的提议分布和常数 M 使 M·g(x) ≥ f(x)，采候选点、按 f(x)/(M·g(x)) 的概率接受。实测（numpy 2.4.3）：目标 f(x) = exp(-x²/2)·(1+0.3·sin(5x))（截断在 [-3,3]，不可直接归一化），均匀提议分布，M 取 max(f)×1.1——接受率 0.25（4 个候选出 1 个有效样本），1000 个接受样本的均值 0.031、标准差 0.972。接受率的含义：M 越松（提议分布离目标越远）接受率越低、浪费越大。工程用法：贝叶斯后验采样（后验归一化常数难算）、能量模型生成；代价是高维空间接受率指数级下降（10 维就基本不可行），高维换 MCMC/变分推断（超出 L0 范围）。

16.2 重要性采样（Importance Sampling）：加权替代重采样

3

不采样、直接用加权平均估计期望：E_p[h(x)] ≈ Σ h(xᵢ)·w(xᵢ)，w = p(xᵢ)/q(xᵢ) 是重要性权重。实测（numpy 2.4.3）：同一目标分布的 E[x]，重要性采样（均匀格点 + 标准化权重）给 0.001，拒绝采样给 0.031、理论值是 0（对称分布）——两个方法都接近 0，符合预期。重要性采样的优势：不需要 M、一次算完、可复用样本；风险是权重退化（个别样本权重极大主导结果），此时诊断 max(w)/Σw 比值，过大（>0.5）就换提议分布或截断权重。

16.3 分层采样（Stratified Sampling）：方差降 100 倍3 个重点▾ 点开看本节重点
本节重点
  • 估计总体均值时，把总体按层（区间）切开、每层固定抽样，比简单随机抽样方差小得多
  • 直觉：分层强制每段区间都有样本，消除了"这次抽到的 10 个全在左边"的波动
  • 工程用法：A/B 分流按用户活跃度分层（保证各层平衡）、评测集按类别分层抽样（避免小类别漏采）、调查问卷按人口结构分层
3

估计总体均值时，把总体按层（区间）切开、每层固定抽样，比简单随机抽样方差小得多。实测（numpy 2.4.3）：U(0,1) 的均值估计，每层 1 个样本、10 层、重复 1000 次——简单随机抽样（每次 10 个独立样本）方差 0.008221，分层抽样方差 0.000082，方差比 100.3 倍。直觉：分层强制每段区间都有样本，消除了"这次抽到的 10 个全在左边"的波动。工程用法：A/B 分流按用户活跃度分层（保证各层平衡）、评测集按类别分层抽样（避免小类别漏采）、调查问卷按人口结构分层。规则：分层变量要与目标相关（与目标无关的分层不降方差），层内方差小才有效。
