2.2 定义第一个类

class Dog:
    """一只狗的类"""
    species = "犬科"                      # 类属性：所有狗共享

    def __init__(self, name: str, age: int):   # 构造方法
        self.name = name                  # 实例属性：每只狗独有
        self.age = age

    def bark(self) -> str:
        return f"{self.name}：汪汪汪！"

    def info(self) -> str:
        return f"名字：{self.name}，年龄：{self.age}岁，物种：{self.species}"

dog1 = Dog("旺财", 3)
print(dog1.name, dog1.species, dog1.bark())

四个关键点：__init__ 是构造方法（__ 包裹的是魔术方法，Python 特定时机自动调用）；self 是当前实例自己，每个实例方法第一个参数必须是 self；self.name = name 把参数存成实例属性；类属性写在方法外所有实例共享、实例属性写在 __init__ 里各实例独有。

3. 继承与多态

2
3.1 继承：复用代码1 个重点▾ 点开看本节重点
本节重点
  • 子类继承父类的属性和方法，「class Animal: ... class Dog(Animal): ...」
3

子类继承父类的属性和方法，class Animal: ... class Dog(Animal): ...。子类可重写（override）父类方法（同名方法优先用子类的），也可用 super().方法名() 调用父类实现。价值是"共性上提、差异下放"：Animal 提供 eat()，Dog 加 bark()，Cat 加 meow()，不用每个子类重写 eat。

3.2 多态：同一接口不同行为

3

多态是"同一个函数处理不同类型的对象"：def make_sound(animal): animal.speak() 传 Dog 打"汪"、传 Cat 打"喵"。Python 是鸭子类型（duck typing），不检查继承关系，只要有 speak() 方法就能用，比 Java 的强类型多态更灵活。isinstance(x, Animal) 判断归属（支持子类），type(x) == Animal 只认精确类型。

3.3 多重继承与 MRO3 个重点▾ 点开看本节重点
本节重点
  • 类可继承多个父类 「class D(B, C)」，方法查找顺序（MRO，Method Resolution Order）用 C3 线性化算法，「D.mro()」 可查看
  • 「super()」 沿 MRO 链调用下一个实现
  • 经验规则：多重继承能不用就不用，用 Mixin 模式（功能单一的小基类组合）比深层继承树安全

4.2 property：像属性一样访问方法

3 
class Person:
    def __init__(self, age: int):
        self._age = age

    @property
    def age(self) -> int:
        return self._age

    @age.setter
    def age(self, value: int):
        if not 0 <= value <= 150:
            raise ValueError("年龄需在 0 到 150 之间")
        self._age = value

p.age 读取走 getter、p.age = 20 赋值走 setter（带校验）。价值是"外部像访问属性一样用，内部加逻辑不改接口"。classmethod（@classmethod 第一个参数是 cls）做工厂方法，staticmethod（@staticmethod 无 self）做工具函数。

5. 魔术方法速查

2

魔术方法（dunder method）让自定义对象像内置类型一样好用：__str__ 面向用户的可读输出（print 时调用）、__repr__ 面向开发者的调试输出（repr() 和交互式回显调用）、__eq__ 定义 ==、__hash__ 定义哈希（改 __eq__ 必须同时改 __hash__，否则对象不能作字典键）、__len__ 支持 len()、__getitem__ 支持下标访问、__iter__/__next__ 支持 for 遍历、__enter__/__exit__ 支持 with、__call__ 让实例可调用（obj()）。规则：__repr__ 必写（调试无它寸步难行），__str__ 与 __repr__ 不同写法二选一即可。

6.1 什么情况下用（适用场景加前置条件）

3
  • 类：数据和操作要绑定（账户、爬虫、连接池）、需要多个实例各带状态。
  • 继承：有明确的 is-a 关系（Dog is Animal）、要复用父类代码。
  • 多态：同一接口要处理多种类型（支付方式、图形绘制、通知渠道）。
  • 封装（property/下划线）：内部状态需要校验或计算、不希望外部直接改。
  • 抽象类：要强制子类实现某方法（插件接口、驱动规范）。
  • 爬虫类：抓取逻辑超过 50 行、要复用 session 或状态。
6.2 什么情况下别用（反例加替代方案）3 个重点▾ 点开看本节重点
本节重点
  • 别用继承复用工具方法：is-a 不成立时继承是滥用
  • 别写超过 3 层的继承链：MRO 难推理
  • 别用 「__del__」 做资源清理：调用时机不确定
3
  • 别用类包装单个函数：class Math: def add(a, b) 没状态，直接写函数。替代：模块级函数。
  • 别用继承复用工具方法：is-a 不成立时继承是滥用。替代：组合（把工具类作为属性）。
  • 别写超过 3 层的继承链：MRO 难推理。替代：Mixin 或组合。
  • 别用 __del__ 做资源清理：调用时机不确定。替代：with 上下文管理器或显式 close。
  • 别把所有属性设公开：外部随意改内部状态。替代：单下划线加 property。
  • 别在爬虫类里写死 URL 和选择器：页面改版就全挂。替代：配置化（类属性或配置文件）。
  • 别用同步 requests 做大规模并发抓取：性能差且易被封。替代：asyncio 加 aiohttp（进阶）。

6.3 翻车长什么样（真实失败形态加排查信号加怎么改）

3
  1. TypeError: __init__() missing 1 required positional argument: 'self'：直接调类的 __init__ 忘了实例化。改：obj = MyClass() 而不是 MyClass.__init__(...)。
  2. 实例方法里忘写 self 参数：def bark(): 调用 dog1.bark() 报缺参数。改：每个实例方法第一个参数加 self。
  3. 类属性被实例修改影响所有实例：dog1.species = "猫科" 只改 dog1（实例属性遮蔽类属性），但 Dog.species = "猫科" 改所有。排查：打印 dog1.species 与 Dog.species。
  4. 重写 __eq__ 后对象不能作字典键：忘同时定义 __hash__（Python 自动把 __hash__ 设为 None）。改：__eq__ 和 __hash__ 成对写。
  5. property 改成普通属性后代码全崩：外部一直在用 p.age = 20（走 setter），改公开属性后语义变化。改：保持 property 接口不变。
  6. 多继承方法调用错乱：MRO 顺序不直观。排查：print(D.mro())。改：显式用 super() 沿链调用。
  7. 爬虫抓到空数据：页面是 JavaScript 动态渲染，requests 拿到的 HTML 没有目标节点。排查：打印 response.text 长度、用浏览器开发者工具看真实 DOM。改：找页面的真实 API 接口（XHR 请求）或用 Selenium/Playwright 渲染。
  8. 爬虫被封 IP（403/429）：请求太频繁或没带 User-Agent。改：加 User-Agent 请求头、time.sleep(1) 礼貌延迟、控制并发数。
  9. BeautifulSoup 选择器找不到节点：class 名带空格（多类名）或页面结构变了。改：用 soup.select("div.quote") CSS 选择器、多写几个备选选择器。

脚本 A：oop_tour.py（Python 3.12）——类、继承、多态、property 一次跑通

#!/usr/bin/env python3
# oop_tour.py —— Python 3.12
# 运行: python oop_tour.py

class Animal:
    """抽象基类：定义 speak 接口"""
    def speak(self) -> str:
        raise NotImplementedError

class Dog(Animal):
    def __init__(self, name: str, age: int):
        self._name = name          # 单下划线：内部使用
        self._age = age

    @property
    def age(self) -> int:          # property getter
        return self._age

    @age.setter
    def age(self, value: int):     # property setter 带校验
        if not 0 <= value <= 30:
            raise ValueError("狗的年龄需在 0 到 30 之间")
        self._age = value

    def speak(self) -> str:
        return f"{self._name}：汪！"

    def __repr__(self) -> str:     # 调试输出必写
        return f"Dog(name={self._name!r}, age={self._age})"

class Cat(Animal):
    def __init__(self, name: str):
        self._name = name

    def speak(self) -> str:
        return f"{self._name}：喵~"

def make_sound(animal: Animal) -> str:   # 多态：同一接口不同行为
    return animal.speak()

dog, cat = Dog("旺财", 3), Cat("咪咪")
print(make_sound(dog), make_sound(cat))
print(repr(dog))
dog.age = 5
print("改年龄后:", dog.age)
try:
    dog.age = 99                   # 超范围触发 setter 校验
except ValueError as e:
    print("校验拦截:", e)

验收标准：make_sound 分别打印"汪"和"喵"（多态）、repr 打印 Dog(name='旺财', age=3)、dog.age = 99 抛 ValueError。四支柱（封装 property、继承 Animal、多态 make_sound、抽象 NotImplementedError）一次演示。

脚本 B：scraper_lab.py（Python 3.12）——requests 加 BeautifulSoup 抓名言（真实端点）

#!/usr/bin/env python3
# scraper_lab.py —— Python 3.12
# 需先装: pip install requests beautifulsoup4
# 运行: python scraper_lab.py
import json, time
from pathlib import Path
import requests
from bs4 import BeautifulSoup

class WebScraper:
    """简单网页爬虫：抓 quotes.toscrape.com"""
    BASE = "https://quotes.toscrape.com"

    def __init__(self, delay: float = 1.0):
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": "Mozilla/5.0 (Student Bot)"})
        self.delay = delay
        self.results = []

    def fetch(self, url: str) -> str | None:
        try:
            resp = self.session.get(url, timeout=10)
            resp.raise_for_status()
            return resp.text
        except requests.RequestException as e:
            print(f"请求失败 {url}: {e}")
            return None

    def parse(self, html: str) -> list[dict]:
        soup = BeautifulSoup(html, "html.parser")
        out = []
        for div in soup.find_all("div", class_="quote"):
            text = div.find("span", class_="text")
            author = div.find("small", class_="author")
            tags = [a.text for a in div.find_all("a", class_="tag")]
            if text and author:
                out.append({"text": text.text, "author": author.text, "tags": tags})
        return out

    def scrape(self, pages: int = 2):
        for page in range(1, pages + 1):
            url = f"{self.BASE}/page/{page}/"
            print(f"抓取 {url}")
            html = self.fetch(url)
            if html:
                quotes = self.parse(html)
                self.results.extend(quotes)
                print(f"  得到 {len(quotes)} 条")
            time.sleep(self.delay)          # 礼貌爬取
        return self.results

    def save(self, path: str):
        Path(path).write_text(json.dumps(self.results, ensure_ascii=False, indent=2),
                              encoding="utf-8")
        print(f"已保存 {len(self.results)} 条到 {path}")

if __name__ == "__main__":
    s = WebScraper(delay=0.5)
    s.scrape(pages=2)
    s.save("/tmp/quotes.json")

验收标准：运行后打印两行"抓取"加两行"得到 N 条"，/tmp/quotes.json 存在且含名言数据。真实端点 https://quotes.toscrape.com/page/1/ 是公开的练习爬虫站点，适合学习。翻车排查：抓到 0 条是选择器错了（打印 soup.prettify() 看结构）；403/429 是被限速（加 delay、换 User-Agent）。

12. 封装三例：访问控制、property、classmethod（handbook 补充）

2

【handbook 补充】访问控制的三档约定（Person 案例）：name 公开（谁都能访问）、_age 受保护（约定仅供类内部和子类用，外部访问不报错但不礼貌）、__salary 私有（Python 做名称改写，p.__salary 直接访问抛 AttributeError，强制访问要写 p._Person__salary 但不推荐）。经验规则：内部状态默认加单下划线，真要防子类覆盖才用双下划线；把"能否直接改"当成接口设计问题而不是语言限制问题。

property 的完整案例（Temperature 温度类）：celsius 是 getter 加 setter（setter 里校验 value < -273.15 抛 ValueError 绝对零度底线），fahrenheit 和 kelvin 是只读计算属性（getter 里实时换算，不存冗余数据）。temp.celsius = -300 会被 setter 拦截，temp.fahrenheit 只读没有 setter 所以赋值会 AttributeError。三种 property 用法对应三种需求：受控访问（校验）、计算属性（派生值）、只读属性（不许改）。对照 dataclass：dataclass 的字段是公开的，要校验得手写 __post_init__，property 更适合单字段的精细控制。

classmethod 与 staticmethod：@classmethod 第一个参数是 cls（类本身），适合做"替代构造器"（工厂方法）：Date.from_string("2026-10-23") 比 Date(2026, 10, 23) 更表达意图；@staticmethod 无 self 无 cls，就是"放在类命名空间里的普通函数"，适合工具函数（DateUtils.is_leap_year(2024)）。判断用哪个：要访问类属性或做实例化用 classmethod，纯工具逻辑用 staticmethod，访问实例状态用普通方法。

16. 插件系统完整案例：ABC 加管理器（handbook 补充）

2

【handbook 补充】插件系统是抽象类的最佳练兵：Plugin(ABC) 定义两个契约——name property（插件名）和 execute(data) -> str（执行逻辑），@abstractmethod 强制子类实现否则不能实例化。三个实现各司其职：UpperPlugin（data.upper() 大写转换）、ReversePlugin（data[::-1] 反转）、EncryptPlugin（凯撒密码偏移 3 位，chr((ord(ch) - base + shift) % 26 + base) 循环移位）。新增插件只需加一个类，管理器代码一行不改——这就是"开闭原则"（对扩展开放、对修改关闭）的直观体现。

#!/usr/bin/env python3
# abc_plugin.py —— Python 3.12
# 运行: python abc_plugin.py
from abc import ABC, abstractmethod

class Database(ABC):
    """数据库抽象基类：三个抽象方法定义契约"""
    @abstractmethod
    def connect(self) -> None: ...
    @abstractmethod
    def execute(self, sql: str) -> list[dict]: ...
    @abstractmethod
    def close(self) -> None: ...

    def run_query(self, sql: str) -> list[dict]:    # 模板方法
        self.connect()
        try:
            return self.execute(sql)
        finally:
            self.close()

class SqliteDB(Database):
    def connect(self): print("✅ 连接 SQLite")
    def execute(self, sql): print(f"📝 执行 {sql}"); return [{"result": "mock"}]
    def close(self): print("🔌 断开")

class DateUtils:
    def __init__(self, year: int, month: int, day: int):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, date_str: str) -> "DateUtils":    # 工厂方法
        y, m, d = date_str.split("-")
        return cls(int(y), int(m), int(d))

    @staticmethod
    def is_leap(year: int) -> bool:                        # 静态方法
        return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

    def __str__(self): return f"{self.year}年{self.month}月{self.day}日"

db = SqliteDB()
print(db.run_query("SELECT 1"))
d = DateUtils.from_string("2024-02-29")
print(d, "2024是闰年:", DateUtils.is_leap(2024))

import json, time
from pathlib import Path
import requests
from bs4 import BeautifulSoup

class ScraperConfig:                     # 配置与逻辑分离
    BASE_URL = "https://quotes.toscrape.com"
    HEADERS = {"User-Agent": "Mozilla/5.0 (Student Bot)"}
    DELAY = 1.0                          # 礼貌延迟秒数
    TIMEOUT = 10                         # 请求超时秒数
    OUTPUT = Path("data/quotes.json")

class QuoteScraper:
    def __init__(self, config: ScraperConfig):
        self.cfg = config
        self.session = requests.Session()
        self.session.headers.update(self.cfg.HEADERS)
        self.results: list[dict] = []

    def fetch(self, url: str) -> str | None:
        try:
            r = self.session.get(url, timeout=self.cfg.TIMEOUT)
            r.raise_for_status()
            return r.text
        except requests.RequestException as e:
            print(f"抓取失败 {url}: {e}")
            return None

    def parse(self, html: str) -> list[dict]:
        soup = BeautifulSoup(html, "html.parser")
        out = []
        for div in soup.select("div.quote"):          # CSS 选择器
            text = div.select_one("span.text")
            author = div.select_one("small.author")
            if text and author:
                out.append({"text": text.text, "author": author.text})
        return out

    def run(self, pages: int = 2):
        for p in range(1, pages + 1):
            html = self.fetch(f"{self.cfg.BASE_URL}/page/{p}/")
            if html:
                self.results.extend(self.parse(html))
            time.sleep(self.cfg.DELAY)
        self.cfg.OUTPUT.parent.mkdir(parents=True, exist_ok=True)
        self.cfg.OUTPUT.write_text(json.dumps(self.results, ensure_ascii=False, indent=2),
                                   encoding="utf-8")
        print(f"共 {len(self.results)} 条 → {self.cfg.OUTPUT}")

if __name__ == "__main__":
    QuoteScraper(ScraperConfig()).run(pages=2)

#!/usr/bin/env python3
# crawler_guard.py —— Python 3.12
# 运行: python crawler_guard.py
import time, random
import requests

def fetch_with_retry(url: str, max_attempts: int = 3) -> str | None:
    for attempt in range(1, max_attempts + 1):
        try:
            r = requests.get(url, timeout=10,
                             headers={"User-Agent": "Mozilla/5.0"})
            if r.status_code == 429:                  # 被限速
                wait = 2 ** attempt
                print(f"429 限速，等 {wait}s 后重试")
                time.sleep(wait); continue
            r.raise_for_status()
            return r.text
        except requests.Timeout:
            print(f"第{attempt}次超时")
        except requests.ConnectionError:
            print(f"第{attempt}次连接失败")
        time.sleep(random.uniform(0.5, 1.5))          # 随机延迟防检测
    return None

if __name__ == "__main__":
    html = fetch_with_retry("https://quotes.toscrape.com/page/1/")
    print("抓取成功" if html else "抓取失败", len(html or ""))
