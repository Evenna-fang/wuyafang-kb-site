1. 均值与中位数：先看分布形状再选摘要

2
1.1 怎么算2 个重点▾ 点开看本节重点
本节重点
  • 均值是所有值加总除以个数；中位数是排序后正中间的值（偶数个取中间两个的平均）
  • 两者对数据的"敏感度"完全不同：均值被每个值拉动，中位数只被位置拉动——一个 10^9 的极端值能把均值拉飞，中位数纹丝不动

import numpy as np

# 右偏数据：对数正态模拟"文章阅读量"
rng = np.random.default_rng(2026)
reads = np.exp(rng.normal(4.0, 1.2, size=1000))    # 中位数 exp(4)≈54.6

print("均值:", round(float(reads.mean()), 1))            # 实跑 120.0
print("中位数:", round(float(np.median(reads)), 1))       # 实跑 57.0
print("均值/中位数比:", round(float(reads.mean() / np.median(reads)), 2))  # 实跑 2.1
print("p95:", round(float(np.percentile(reads, 95)), 1))  # 实跑 396.4
print("最大值:", round(float(reads.max()), 1))             # 实跑 2653.1

实跑输出（seed=2026）：均值 120.0、中位数 57.0、比值 2.1、p95=396.4、最大值 2653.1——均值被头部内容拉到中位数的 2 倍以上，最大值是中位数的 46 倍。这就是"均值不能当典型值"的定量证据。

1.2 什么时候信、什么时候不信

3
  • 对称分布（正态型）：均值 ≈ 中位数，用哪个都行，均值统计性质更好（可做 t 检验）。
  • 右偏分布（收入、阅读量、延迟、粉丝数）：均值 > 中位数，且比值越大偏得越狠。判据：均值/中位数 > 1.2 就别用均值当"典型值"，改报中位数 + p95 + p99。
  • 重尾分布（极端值常见）：均值本身不稳定——换一批样本均值能跳 50%。判据：bootstrap 均值的置信区间宽度/均值 > 0.5（见 §5.2），此时用中位数或截尾均值（去掉最高最低各 5% 后再平均）。

2.2 分位数：方法选错数字就变

3

np.quantile(data, q, method=...) 在 numpy 2.x 支持多种插值方法，同一个 q 在不同 method 下给出不同数字。实测（数据 = [1..10]，q=0.25）：

import numpy as np
data = np.arange(1, 11, dtype=float)
for m in ["linear", "lower", "higher", "nearest", "midpoint"]:
    print(m, float(np.quantile(data, 0.25, method=m)))
# 实跑输出：linear 3.25 / lower 3.0 / higher 4.0 / nearest 3.0 / midpoint 3.5

五个方法给 3.0~4.0 不同的值。规则：

  • 默认 linear：连续插值，通用，报表用这个。
  • lower/higher/nearest：必须"落在真实数据点上"的场景（比如取一个真实存在的用户做示例）。
  • midpoint：取中间值，保守派的"分位数下界+上界平均"。
  • 对 SLA 阈值（如 p99 延迟 < 200ms）：用 higher，偏保守——宁可阈值严一点也不放水。

np.percentile(data, 95) 就是 quantile(data, 0.95) 的百分数写法，等价。p50 就是中位数。

3. 方差、标准差与变异系数：量纲陷阱

3.1 怎么算2 个重点▾ 点开看本节重点
本节重点
  • 方差 Var：「mean((x - mean(x))²)」，单位是原单位的平方
  • 标准差 SD：「sqrt(Var)」，单位回到原单位，可读
3
  • 方差 Var：mean((x - mean(x))²)，单位是原单位的平方。
  • 标准差 SD：sqrt(Var)，单位回到原单位，可读。
  • 变异系数 CV = SD / Mean：无量纲的相对离散度，用于跨量纲比较。
import numpy as np

# 两组"波动"：一组是价格（单位 元），一组是比例（单位 无）
prices = np.array([10.0, 10.4, 10.2, 10.9, 11.3, 11.1, 11.8])
ratios = np.array([0.10, 0.104, 0.102, 0.109, 0.113, 0.111, 0.118])

print("prices SD:", round(float(prices.std(ddof=1)), 4), "CV:", round(float(prices.std(ddof=1) / prices.mean()), 4))
print("ratios SD:", round(float(ratios.std(ddof=1)), 6), "CV:", round(float(ratios.std(ddof=1) / ratios.mean()), 4))
# 实跑：prices SD 0.6466 CV 0.0598；ratios SD 0.006466 CV 0.0598 ← CV 相同！

实跑结论：两组数据只是单位不同（元 vs 比例），SD 差 100 倍（0.6466 vs 0.006466），但 CV 完全相同（0.0598）——跨量纲比较离散度必须用 CV，用 SD 会得出完全错误的结论。这是"比较两个模型的预测稳定性"（一个预测金额一个预测概率）时的标准动作。

3.2 什么时候信、什么时候不信

3
  • SD 对离群点极敏感（平方放大），重尾数据的 SD 会被单个极端值撑大。判据：max |z-score| > 6 时 SD 不可靠，换 MAD（中位数绝对偏差）或分位数间距（IQR = p75 - p25）。
  • CV 只对"真零点有意义"的比率尺度有效（价格、长度、计数）。温度（摄氏度）的 CV 无意义（零点任意），这是量纲分析的红线。
  • ddof=1（除以 n-1）是样本标准差的无偏口径，ddof=0 是 MLE 口径；报告里写清用哪个（详见《概率统计白话》§1.2 的实测比值 0.998）。

  • 皮尔逊（Pearson）：线性相关，默认选择。对离群点敏感。
  • 斯皮尔曼（Spearman）：秩相关，只看单调关系，抗离群点。

import numpy as np
from scipy import stats

rng = np.random.default_rng(2026)
x = rng.normal(size=200)
y_mono = np.exp(x) + rng.normal(scale=0.3, size=200)   # 单调非线性
y_out = 1.5 * x + rng.normal(scale=0.4, size=200)
y_out[0] = 25.0                                         # 塞一个离群点

print("单调非线性: Pearson", round(float(stats.pearsonr(x, y_mono).statistic), 3),
      "Spearman", round(float(stats.spearmanr(x, y_mono).statistic), 3))
print("含离群点: Pearson", round(float(stats.pearsonr(x, y_out).statistic), 3),
      "Spearman", round(float(stats.spearmanr(x, y_out).statistic), 3))

实跑输出（seed=2026）：单调非线性数据（y=exp(x)+噪声）上 Spearman=0.948、Pearson=0.752（皮尔逊被非线性拖低）；含离群点数据（y=1.5x 塞入 25.0 的离群点）上 Pearson 从应有的 ~0.96 掉到 0.623、Spearman 保持 0.945 几乎不动。判据：散点图有弯钩或离群点时信 Spearman，线性且干净时信 Pearson。

4.2 三条纪律

3
  1. 相关 ≠ 因果。混杂变量可以让两个无关变量相关（"冰淇淋销量"和"溺水人数"都随夏天涨）。判据：有没有做随机对照？没有就只能说"相关"。替代方案：A/B 实验、工具变量、控制混杂变量后算偏相关。
  2. 显著性依赖样本量。n=10000 时 ρ=0.02 也能 p<0.001。判据：看效应量（|ρ|）而不是 p 值——经验阈值 |ρ|<0.1 视为可忽略，0.1~0.3 弱，0.3~0.5 中，>0.5 强（Cohen 惯例，领域差异大）。
  3. 相关矩阵只抓线性冗余。非线性冗余（y = x²）相关不高但完全可预测。判据：去掉相关 >0.95 的列后模型效果没变差，说明删对了；变差了说明有非线性信息，换互信息或树模型特征重要性。

5.2 置信区间的两种算法：正态近似 vs bootstrap

3 
import numpy as np

rng = np.random.default_rng(5)
x = rng.normal(loc=5.0, scale=2.0, size=60)

# 方法 1：正态近似 CI = mean ± 1.96 * SEM
sem = x.std(ddof=1) / np.sqrt(len(x))
ci_norm = (x.mean() - 1.96 * sem, x.mean() + 1.96 * sem)
print("正态近似 CI:", np.round(ci_norm, 4), "SEM:", round(float(sem), 4))   # 实跑 (4.0888, 5.0518) SEM 0.2457

# 方法 2：bootstrap（重采样 2000 次的均值分布取分位数）
boot = np.array([rng.choice(x, size=len(x), replace=True).mean() for _ in range(2000)])
ci_boot = np.percentile(boot, [2.5, 97.5])
print("bootstrap 95% CI:", np.round(ci_boot, 4))   # 实跑 (4.0909, 5.0438)

实跑数字（seed=5）：正态近似 SEM=0.2457，CI = (4.0888, 5.0518)；bootstrap 95% CI [4.0909, 5.0438]。两者接近但不相同——n=60 时 CLT 已经不错，bootstrap 的优势在非正态、分位数、复杂统计量（中位数、比率、AUC）上：正态近似对中位数无效，bootstrap 照样能给区间。规则：均值+大样本用正态近似（快），其他一律 bootstrap（稳）。

  1. 多重比较：同时看 20 个指标，期望假阳性 1 个。校正：Bonferroni（α/20）或 Benjamini-Hochberg（控制 FDR）。判据：指标数 > 5 就必须校正。
  2. 偷看提前停：每天看一次 p 值、显著就停，实际 α 膨胀到 0.15~0.3（远超名义 0.05）。改法：预定样本量跑完，或用序贯检验（mSPRT）。
  3. 功效不足：n=30 想检测 5% 相对提升，功效不到 20%，"不显著"大概率是测不出来不是没效果。改法：实验前算 MDE 和功效，power ≈ Φ(√(n/2)·d - 1.96)。

5.4 翻车形态

3
  • 现象：p=0.04 宣布上线，复现实验 p=0.6。排查信号：单次实验且没预注册假设、没校正多重比较。改法：预注册主指标 + 校正 + 报告效应量 CI。
  • 现象：两组 A/B 指标差 3%，p=0.2，结论"无差异，不上线"。排查信号：功效计算显示需要 4000 样本，实际只有 800。改法：扩样本或接受"当前样本量下无法判断"，别写"无差异"。
  • 现象：Mann-Whitney U 和 t 检验结论相反。排查信号：分布明显偏态或有大量并列值。改法：信非参数检验，或先做数据变换（取对数）再 t 检验。

"""用统计规则找异常值：z-score、IQR、分位数三法对比。
运行: numpy 2.4.3, scipy 1.18.1"""
import numpy as np

rng = np.random.default_rng(2026)
# 90 个正常值 + 5 个注入异常（订单金额场景）
normal = np.exp(rng.normal(3.0, 0.4, size=90))       # 正常订单，中位数约 20 元
outliers = np.array([200.0, 350.0, 500.0, 180.0, 420.0])
amounts = np.concatenate([normal, outliers])
rng.shuffle(amounts)

mean, std = amounts.mean(), amounts.std(ddof=1)
med = np.median(amounts)
mad = np.median(np.abs(amounts - med))                # 中位数绝对偏差
q1, q3 = np.percentile(amounts, [25, 75])
iqr = q3 - q1

z_flags = np.abs((amounts - mean) / std) > 3
iqr_flags = (amounts < q1 - 1.5 * iqr) | (amounts > q3 + 1.5 * iqr)
robust_flags = np.abs((amounts - med) / (1.4826 * mad)) > 3.5   # 稳健 z-score

print(f"总数 {len(amounts)}，注入异常 5 个")
print(f"z-score(3σ) 标出: {z_flags.sum()} 个")
print(f"IQR(1.5倍) 标出: {iqr_flags.sum()} 个")
print(f"稳健z(MAD, 3.5) 标出: {robust_flags.sum()} 个")
print(f"均值 {mean:.2f} vs 中位数 {med:.2f}（右偏被异常拉高）")
print(f"MAD={mad:.2f}, IQR={iqr:.2f}")

实跑输出（seed=2026）：总数 95（90 正常 + 5 注入异常），z-score 标出 3 个、IQR 标出 9 个、稳健 z 标出 8 个；均值 38.90 vs 中位数 20.55（异常把均值拉高 89%）；MAD=5.49、IQR=12.33。三种规则标出数量差异显著——z-score 因为均值和 SD 被异常值污染（异常值参与了 mean/std 计算），漏标了真实异常；IQR 标出 9 个比注入的 5 个多，说明 1.5 倍 IQR 规则在小样本上偏激进，会把正常尾部也划进来。这是"先算统计量再找异常"的经典循环依赖：异常值污染统计量，统计量又决定谁是异常。解法：用稳健统计量（中位数、MAD、IQR）做第一轮，再人工/规则复核；或用迭代剔除（先剔最极端 1 个再重算），阈值按业务误伤成本调（金融风控偏保守用 3×IQR，日志清洗用 1.5×IQR）。

7. 实战完整脚本：两组对比从检验到结论（可直接跑）

2 
"""两组指标对比完整流程：描述 → 分布检验 → 参数/非参数检验 → 结论规则。
运行: numpy 2.4.3, scipy 1.18.1"""
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
a = np.exp(rng.normal(2.0, 0.6, size=150))   # 对照组：右偏（对数正态）
b = np.exp(rng.normal(2.15, 0.6, size=150))  # 实验组：中位数提升约 16%

# 1) 描述（右偏数据：报中位数+分位数，不报均值）
for name, arr in [("A", a), ("B", b)]:
    print(f"{name}: n={len(arr)} 中位数={np.median(arr):.2f} "
          f"p25={np.percentile(arr,25):.2f} p75={np.percentile(arr,75):.2f} "
          f"p95={np.percentile(arr,95):.2f}")

# 2) 正态性检验（右偏数据预期拒绝正态）
for name, arr in [("A", a), ("B", b)]:
    print(f"{name} shapiro p={stats.shapiro(arr).pvalue:.2e}")

# 3) 参数 vs 非参数检验并排
t, pt = stats.ttest_ind(b, a, equal_var=False)     # Welch t（不假定等方差）
u, pu = stats.mannwhitneyu(b, a, alternative="two-sided")
print(f"Welch t={t:.3f} p={pt:.4f}")
print(f"Mann-Whitney U={u:.1f} p={pu:.4f}")

# 4) 效应量：中位数比 + Cliff's delta 近似
med_ratio = np.median(b) / np.median(a)
cliff = 2 * u / (len(a) * len(b)) - 1               # 从 U 统计量换算
print(f"中位数比={med_ratio:.3f} Cliff's delta={cliff:.3f}")

# 5) 结论规则
alpha = 0.05
print("结论:", "实验组显著更好" if pu < alpha and med_ratio > 1.05 else "继续观察")

这段脚本体现了"分布形状决定检验选择"的纪律。实跑输出（seed=7）：A 组中位数 6.90（p25=4.67, p75=9.18, p95=15.71），B 组中位数 8.36（p25=5.67, p75=11.83, p95=20.78），两组 shapiro p 分别为 1.57e-09 和 5.90e-08（强烈拒绝正态，符合右偏设计）；Welch t=3.010（p=0.0028）、Mann-Whitney U=13458.0（p=0.0033），两个检验都显著且 p 值接近；中位数比=1.213、Cliff's delta=0.196。右偏数据上效应量该报中位数比和 Cliff's delta（非参数效应量，从 U 统计量直接换算：delta = 2U/(n1n2) - 1），而不是 Cohen's d（假定正态）——效应量的选择同样要跟分布走。Cliff's delta=0.196 的含义是"随机取一对 B 和 A，B 更大的概率比 A 更大的概率高 19.6 个百分点"，属小到中效应，取值 [-1,1]，可读性强。

12.2 比率指标的"均值陷阱"：ratio of sums ≠ mean of ratios

3

Σ分子/Σ分母 和 mean(每个样本的比率) 是两个不同的数。实测（numpy 2.4.3）：分子 [10,12,8,15,9]、分母 [20,30,25,10,15]，ratio of sums = 0.5400，mean of ratios = 0.6640——差 23%。原因：mean of ratios 给小分母样本过高权重（分母 10 的那个样本比率 1.5，在均值里和分母 30 的样本一样重）。规则：转化率、点击率这类比率指标一律用 ratio of sums（总点击/总曝光），mean of ratios 只在"每个用户等权"的语义下才对（如人均点击率）。报表口径打架时先查是不是这两种算法混用了。

17.1 滚动分位数 vs 全局分位数：监控告警的口径坑

3

监控面板上的 p95 延迟，"过去 24 小时的全局 p95"和"每 5 分钟窗口的 p95"是两个不同的数，告警语义完全不同。实测（numpy 2.4.3）：900 个正常请求（均值 100ms）+ 100 个慢请求（均值 300ms）混合，全局 p95 = 296.3ms（落在慢请求群里）；但按 200 个请求/窗口滚动算 p95，四个窗口的 p95 分别是 117.9 / 116.8 / 116.9 / 115.2ms（正常水平）——全局 p95 被 10% 的慢请求顶到 300ms，滚动 p95 却稳定在 116ms。

差异原因：全局分位数把两群数据混在一起排序，滚动分位数受窗口内占比影响。规则：①SLA 告警用滚动窗口 p95/p99（响应快，能定位时段）；②容量规划用全局分位数（反映整体体验）；③面板上注明口径（"rolling 5min p95" vs "24h global p95"），这是 §2.2 分位数口径纪律在时间维度的延伸。窗口越短越灵敏也越噪声大——5 分钟窗口在低流量服务上（<100 请求/窗口）分位数本身就不稳定，此时改用均值或加长窗口。

§6 用 MAD/IQR 找异常值，但找到异常值之后不一定要删——删了会低估真实尾部（延迟的极端值是真实用户体验）。两个"不删但降权"的标准做法：

import numpy as np

rng = np.random.default_rng(2026)
x = np.concatenate([rng.normal(50, 5, 100), [400.0, 450.0, 500.0]])   # 3 个极端值

print("原始均值:", round(float(x.mean()), 2))                    # 实跑 61.41
lo, hi = np.percentile(x, [5, 95])
wins = np.clip(x, lo, hi)                                        # winsorize：截断到 5%/95%
print("winsorized 均值:", round(float(wins.mean()), 2))          # 实跑 50.05
trim = np.sort(x)[int(0.05 * len(x)):int(0.95 * len(x))]         # trimmed：删掉两端 5%
print("trimmed 均值:", round(float(trim.mean()), 2))              # 实跑 49.98
print("中位数:", round(float(np.median(x)), 2))                   # 实跑 50.33

实跑：原始均值 61.41 被 3 个极端值拉高 23%；winsorized 均值 50.05、trimmed 均值 49.98、中位数 50.33——三个稳健摘要几乎一致，都接近真实中心 50。区别：winsorize 保留样本量（截断值替换极端值，适合喂模型），trimmed 直接删行（适合统计报告），中位数最稳健但损失了"离散程度"信息。规则：对外报告用中位数 + p95；喂模型用 winsorize（保持 n）；统计检验用 trimmed 或非参数方法。

17.3 季节性指数：周节律的量化

3

"周末流量跌"是定性描述，量化成季节性指数才是可比口径。实测（numpy 2.4.3）：构造周一到周日的流量倍数 [1.2, 1.1, 1.0, 1.0, 1.05, 0.8, 0.7]（周末明显低），以第一周均值为基准算指数，实跑输出 [1.229, 1.126, 1.018, 1.020, 1.073, 0.817, 0.716]（噪声让指数略偏离设定值，但形状一致：周一最高、周日最低）。

19.1 AUC 的概率语义：随机正例得分高于随机负例的概率2 个重点▾ 点开看本节重点

AUC 不只是 ROC 曲线下面积，它的概率含义是：随机抽一个正例和一个负例，模型给正例打分更高的概率。实测（numpy 2.4.3）：正例得分 normal(1,1) 500 个、负例 normal(0,1) 500 个，直接成对比较 (pos[:,None] > neg[None,:]).mean() 得 AUC=0.7715，手写 ROC 曲线（按阈值扫）后 np.trapezoid(tpr, fpr) 也是 0.7715——两种算法精确一致。这个概率语义的用处：AUC=0.5 是随机猜测，AUC=0.77 意味着"排序对的比例 77%"，比"准确率 77%"更可解释（不依赖阈值）。

19.2 KS 统计量：分布差异的最大缺口

3

KS 统计量 = max|CDF₁(x) - CDF₂(x)|，两条累积分布曲线的最大垂直距离。实测（scipy 1.18.1）：normal(0,1) 200 个 vs normal(0.3,1) 200 个，ks_2samp 统计量 0.130、p=0.068——p 略大于 0.05，200 样本对 0.3 的分布偏移功效不足（和《概率统计白话》§6 的功效概念呼应）。风控领域 KS 统计量直接当模型区分度指标用（KS>0.3 算可用、>0.5 算好），与 p 值并用：KS 值大且 p 小才是"差异大且可靠"。

19.4 PSI：分布漂移的监控指标

3

PSI（Population Stability Index）量化"现在"相对"基线"的分布漂移：PSI = Σ (cur% - base%)·ln(cur%/base%)。实测（numpy 2.4.3）：基线 [0.4, 0.4, 0.2]、当前 [0.3, 0.4, 0.3]，PSI = 0.0693。行业经验阈值（经验值，不同团队口径不同，待验证）：PSI < 0.1 稳定、0.1~0.25 中度漂移、>0.25 严重漂移需重训。工程用法：特征分布的 PSI 每天算，超阈值告警；模型预测分布的 PSI 突然变大 = 输入数据变了或模型过期。这是《L0-数据分析》§13 数据质量巡检的定量指标。

2

特征工程的统计错误比模型调参错误更隐蔽——它们不报错、只让线上指标悄悄变差。三个陷阱各给实测数字（numpy 2.4.3 / scipy 1.18.1）。

23.1 目标泄漏：相关 0.999 的"神特征"

3

目标泄漏是"特征里混进了标签的信息"，最典型是用了"未来数据"（如用"本月总消费"预测"本月是否流失"——消费本身就是流失前的行为）。实测（numpy 2.4.3）：构造 leaky = x*2 + 噪声（本质是目标的线性变换），corr(x, leaky) = 0.999——离线指标漂亮到不可信，线上立刻露馅。排查信号：①某个特征的单变量重要性远超其他（>10 倍）；②训练集指标 0.99 但验证集 0.6；③特征的业务含义上"不可能在预测时点拿到"。规则：每个特征写一行"预测时点可得性"注释，泄漏特征的检查靠业务审查而非统计量——统计上它看起来就是好特征，这正是泄漏的可怕之处。

23.2 异常值对回归系数的扭曲3 个重点▾ 点开看本节重点
本节重点
  • 离群点不仅污染均值，还直接扭曲线性模型的斜率
  • 这就是 §6 异常值检测和 §17.2 winsorize 在建模环节的落点：喂线性模型前先处理异常值，否则模型学到的系数是"被污染数据的最优解"，上线后对正常数据系统性偏差
  • 树模型对此鲁棒（分裂不看幅度），所以异常值处理的优先级：线性模型 > 神经网络 > 树模型
3

离群点不仅污染均值，还直接扭曲线性模型的斜率。实测（numpy 2.4.3）：y = 2x + 噪声 100 个样本，干净斜率 2.006；前 5 个 y 塞 +20 的异常值后斜率变成 2.339（被拉高 17%）；3σ 剔除异常值后斜率 2.048（基本恢复）。这就是 §6 异常值检测和 §17.2 winsorize 在建模环节的落点：喂线性模型前先处理异常值，否则模型学到的系数是"被污染数据的最优解"，上线后对正常数据系统性偏差。树模型对此鲁棒（分裂不看幅度），所以异常值处理的优先级：线性模型 > 神经网络 > 树模型。

23.3 样本量幻觉：n=2000 也可能测不出真实相关

3

§4.2 说"显著性依赖样本量"，这里补一个反直觉实测：构造 y = 0.05x + 噪声（真实相关很弱），不同样本量的 Pearson 检验结果——实测（scipy 1.18.1）：n=20 时 r=0.128、p=0.59（测不出）；n=200 时 r=0.206、p=0.0035（显著！但 r 本身 0.206 只是噪声波动，真实相关是 0.05）；n=2000 时 r=0.023、p=0.305（回到不显著）。这个三段式揭示：同一份"真实弱相关"的数据，n=200 恰好给了一个假显著——单次检验的 p<0.05 不代表发现真相关，重复实验/预注册主假设才是防线（§21.4 的报告清单）。规律：n 大时任何微小相关都显著（r=0.03 也 p<0.01），此时该看效应量 |r| 而不是 p 值。
