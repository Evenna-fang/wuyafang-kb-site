「我要从零开始学 AI，最后能自己搭一个 RAG 知识库，该按什么顺序学？」这是本库被问最多的问题之一。网上的路线图要么太泛（「学机器学习、深度学习、NLP」），要么跳步（上来就讲 Transformer 数学推导）。这张图按真实文档排路径：每一步都指向本库里已经写好的文档，学完一步就知道下一步去哪，不需要自己拼路线。

适用场景：零基础或近零基础（会用电脑但没写过代码）；目标明确是「搭一个能检索自己文档、能问答的 RAG 系统」；时间有限，想走最短路径不绕路。

前置条件：一台能上网的电脑（Windows/macOS/Linux 都行）；每天能挤出 1~2 小时。

① 环境搭建（1-2 天）

3

目标文档：L0-环境与工具链

学什么：装 Python 3.12+、建虚拟环境、配 pip 镜像、装编辑器（VS Code 或 PyCharm）、跑通验证脚本。文档里有 verify_env.py 检查脚本，跑完核心检查全 PASS 才算过关。

学到什么程度算过关：能在终端跑 python --version 看到 3.12+；能创建并激活 .venv；能 pip install requests 装上包；能用编辑器跑一个 print("hello")。

常见卡点：Windows 忘勾「Add python.exe to PATH」导致 python 不是内部或外部命令；PowerShell 报「禁止运行脚本」；WSL 里 python 调用了 Windows 的 python.exe。这些翻车现场文档第 8.3 节都列了排查和修复方法，别自己瞎试。

③ 数学最小集（3-5 天）

3

目标文档：L0-数学最小集-线性代数白话、L0-数学最小集-概率统计白话、L0-统计直觉

学什么：向量（Embedding 就是向量）、矩阵乘法（神经网络前向传播的底层数学）、距离与相似度（余弦相似度是 RAG 检索的核心）、概率与统计直觉（模型输出是概率分布）。只需要最小集，不需要完整微积分和线性代数课程——RAG 用到的是「向量算相似度」这一件事。

学到什么程度算过关：能用 numpy 算两个向量的余弦相似度；能解释「为什么向量距离近就是语义相似」；能看懂 Softmax 把一堆数变成概率分布。

常见卡点：想把数学学全导致卡死在推导上。记住目标是「能用」不是「能证」，看不懂的证明先跳过，回到 RAG 场景反推理解。

⑤ 提示词工程（2-3 天）

3

目标文档：L2-大模型交互-最佳答案（域总纲），细读 System Prompt 怎么写才好、Few-shot 和 Zero-shot 怎么选

学什么：Prompt 六要素（角色+任务+背景+输入+约束+输出格式）、System/User/Assistant 角色分工、Few-shot 示例、思维链 CoT、结构化输出（让模型返回 JSON）。RAG 的生成质量很大程度取决于 Prompt 怎么写——检索到的内容要通过 Prompt 组装进上下文。

学到什么程度算过关：能写出带角色、约束、输出格式的 Prompt 并稳定得到 JSON 结构输出；能解释为什么「模型不知道公司规章」要加外部知识而不是改 Prompt。

常见卡点：输出格式不稳定（JSON 解析失败）。约束句要明确「只输出 JSON，不要任何解释」，并用代码解析校验而不是靠模型自觉。

学什么：RAG 三步流程（索引化→检索→生成）、文档解析与 chunk 切分、Embedding 向量化、向量库存储与检索（Chroma 入门）、Prompt 组装上下文、带引用的回答。目标是跑通一个「上传 PDF → 提问 → 带引用回答」的最小 RAG。

学到什么程度算过关：能用代码把一个真实 PDF 切块、向量化、存进 Chroma；能检索 Top-K 并组装 Prompt 让模型回答；能标注「答案出自第几页」。跑不通就回到上一步补 Python 或数据工程。

常见卡点：chunk 太大检索不准、太小上下文断裂（经验值中文 300~600 字/块、重叠 50~100 字，必须用自己的数据实验）；检索到了但答案还是错（Prompt 没约束「只依据已知信息回答」）；中文乱码（入库前统一 UTF-8）。
