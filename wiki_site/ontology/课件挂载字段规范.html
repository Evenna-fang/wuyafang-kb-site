课件挂载字段规范（wiki→courseware 关联）

来源: 2026-10-20 对标调研 Q2（RepoGraph/CodexGraph 双图分立 + tree-sitter AST 分块）
用途: raw/courseware 25809 个源码文件挂到 wiki 知识节点时, metadata 统一字段命名。

字段表

2
字段 含义 示例
file_path 课件/源码相对路径（相对 raw/courseware/） L2-Python/第3章装饰器/demo.py
symbol_name 主要符号名（函数/类, tree-sitter 提取） memoize_cache
symbol_type symbol 分类 function / class / module
dep_versions 依赖+版本（requirements/package 声明的子集） {"langchain":"0.1.0"}
tech_stack 所属技术栈（对齐 ontology edge-schema 实体类型） FRAMEWORK / PROTOCOL / ...
wiki_ref 知识节点路径（wiki/ 相对路径） wiki/L1-RAG基础/RAG基础架构.md

规则

2
  1. 双图分立: 知识节点只放引用（file_path+symbol_name），不复制源码内容（RepoGraph 模式）。
  2. 分块粒度: 按 tree-sitter 函数/类节点切（不整文件/不固定 token）。
  3. 对齐 edge-schema.json: tech_stack 字段取值必须命中 edge-schema 实体类型, 保持图谱类型一致。
