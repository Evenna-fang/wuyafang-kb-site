GPT-6.1 Sol

2
  • 定义: OpenAI 于 2026-09-29 发布的旗舰大模型（Product 类），配套有 Safety Addendum。属 GPT-6.x 系列（GPT-6.1/6/5.6/5.5）。
  • 适用场景: 跟踪 OpenAI 模型能力边界、FDE 交付时评估 OpenAI 系模型选型。
  • conflict_status: active
  • 关系标注: 与 Gemini 3.8 — complementary: 两大厂商 2026-09 同期旗舰，OpenAI 主打 safety cases/frontier training，DeepMind 主打 Live/Extended Thinking/Agent 化。

Gemini 3.8（Flash / Live / Extended Thinking）

2
  • 定义: Google DeepMind 于 2026-09 发布的模型系列，含 Flash（含 Cyber 安全版）、Live（含 Live Avatar 数字人、实时）、Extended Thinking（扩展推理）多个变体。
  • 适用场景: 需要实时交互、长推理、数字人、Agent 化视频理解的场景。
  • conflict_status: active
  • 关系标注: 与 GPT-6.1 Sol — complementary（见上）。「Extended Thinking」与推理模型（reasoning model）— specialization: 是 Gemini 的长推理变体。

Computer-use Agent

2
  • 定义: 能操作计算机界面（点击/输入/截图/多窗口）完成任务的通用 Agent，区别于纯 API 工具调用 Agent。代表：HF Holo4（generalist computer-use agents）。
  • 适用场景: 需要 Agent 代替人操作 GUI 软件/网页的自动化交付。与本项目的 computer_use 工具、hermes-browser-automation 同方向。
  • conflict_status: active
  • 关系标注: 与「反爬绕过/浏览器自动化」— complementary: computer-use agent 是更高层的"替人操作"，浏览器自动化是其底层能力之一。

GRPO（Group Relative Policy Optimization）

2
  • 定义: 一种 RLHF/RL 训练算法（组相对策略优化），用于大模型对齐。HF 已支持 Async GRPO + LoRA across HF Jobs（免 NCCL 分布式）。
  • 适用场景: 低成本/本地模型对齐训练（结合 LoRA 微调）。与 DPO 同属 post-training 手段。
  • conflict_status: active
  • 关系标注: 与 DPO — complementary: 均为 post-training 对齐算法，GRPO 偏 RL 式（组内相对奖励），DPO 偏偏好对（直接偏好优化）。

Safety Cases（前沿 AI 训练安全论证）

2
  • 定义: 针对前沿 AI 训练的安全论证框架（OpenAI 提出 towards safety cases for frontier AI training），系统论证训练/部署的安全性。
  • 适用场景: 合规交付、客户安全审查、监管对接（对应信息源总表的合规维度）。
  • conflict_status: active
  • 关系标注: 与「双盲评测 double-blind evaluations」— complementary: safety cases 论证安全性，双盲评测保证可复现性，均为可信 AI 交付的组成部分。
