3
  • 统计学习的定义与对象：统计学习是关于计算机基于数据构建概率统计模型并运用模型进行预测与分析的学科，研究对象是多样化的数据。数据可以是数字、文字、图像、视频、音频及其组合，方法的任务是从数据中提取特征、抽象模型、发现知识，再回到分析与预测。
  • 三要素框架：统计学习方法由模型的假设空间、模型选择的准则和模型学习的算法构成，简称模型、策略、算法。比较两个方法时，不能只比较模型名称，还要追问损失函数、正则化方式、优化过程和停止条件。
  • 基本假设：统计学习假设同类数据具有一定统计规律性；监督学习进一步假设训练数据与测试数据依联合概率分布P(X,Y)独立同分布产生。这个假设支撑了经验风险对未来风险的估计，也说明分布漂移时需要重新评估模型。
  • 问题类型划分：输入输出均为连续变量为回归问题，输出为有限离散变量为分类问题，输入输出均为变量序列为标注问题。任务边界决定标签表示、评价指标以及预测时的输出结构。
  • 模型评估与选择：经验风险反映训练集拟合程度，结构风险则把经验风险与模型复杂度惩罚结合起来。正则化、交叉验证和验证集的作用，都是在拟合数据与控制泛化误差之间建立可操作的平衡。
  • 泛化误差上界：它是样本容量的函数（样本增加则上界趋于0），也是假设空间容量的函数（容量越大越难学，上界越大）。因此，提升训练集成绩并不自动意味着测试集更好，模型容量、样本量和噪声必须一起考虑。
  • 生成模型与判别模型：生成模型先描述联合分布或数据生成过程，判别模型直接描述条件概率或决策边界。前者便于解释数据生成机制，后者往往更直接地服务于分类与标注。

第2章 感知机

3
  • 模型：二分类的线性分类模型，以分离超平面将特征空间划分为正负两类。它适合线性可分数据，不能直接表达复杂的非线性边界。
  • 策略：以误分类点到超平面的总距离（等价于误分类驱动的损失）为损失函数。只有被错误分类的样本推动参数更新，因此训练目标和错误样本高度相关。
  • 算法：基于随机梯度下降的误分类驱动更新，原始形式与对偶形式并存。原始形式直接更新权重，样本较少或特征维度较低时易理解；对偶形式把更新次数与样本内积联系起来，便于利用核函数思想。
  • 适用边界：若数据线性不可分，感知机可能持续更新而不能得到稳定的零误分类解，此时应引入软间隔、特征变换或改用逻辑斯谛回归、支持向量机等方法。

第4章 朴素贝叶斯法

3
  • 生成式模型：基于贝叶斯定理与特征条件独立假设，学习联合概率分布后进行分类。预测时比较各类别的先验概率与条件概率乘积。
  • 核心假设：条件独立性假设大幅简化计算，但以牺牲一定准确性为代价。即使现实特征存在相关性，只要类别间的相对排序仍然有效，模型仍可能取得实用效果。
  • 后验概率最大化：分类时等价于选择使后验概率最大的类别，即期望风险最小化。对数变换可以把概率乘积改成加法，降低下溢风险并简化计算。
  • 参数估计与平滑：极大似然估计直接使用频数，零频率会使整类概率归零；加入平滑可以避免这一问题，但平滑强度也会影响稀有特征的贡献。

  • 模型：以树形结构对实例进行分类，内部结点为特征测试，叶结点为类别。路径本身提供了相对直观的解释。

第6章 逻辑斯谛回归与最大熵模型

3
  • 逻辑斯谛回归：以sigmoid函数建模条件概率，是经典的线性对数几率分类模型。线性部分负责组合特征，sigmoid把结果映射到概率空间。
  • 最大熵原理：在满足约束的条件下选择熵最大的模型，导出最大熵模型。它不额外引入未经证实的偏好，只保留训练数据明确提供的信息。
  • 统一视角：两者均属对数线性模型，可用极大似然估计与最优化方法求解。特征函数和权重把输入输出关系表达为可加的指数族形式。
  • 正则化作用：L1正则化倾向于产生稀疏参数，L2正则化倾向于抑制大权重并提升稳定性。正则项既是数值优化中的约束，也是控制泛化的重要手段。

第8章 提升方法

3
  • 基本思想：将弱分类器组合为强分类器，通过改变样本权重聚焦难分样本。每轮学习都针对上一轮留下的错误，从而形成逐步修正。
  • AdaBoost：自适应地调整样本权重与分类器权重，理论上有训练误差上界保证。错误率低的弱分类器权重更大，难以分类的样本在下一轮获得更高关注。
  • 前向分步算法：将提升方法解释为加法模型的逐轮优化，统一理解提升框架。它每次只加入一个基学习器，固定已得到的部分，再寻找当前最有用的增量。
  • 风险提示：提升方法对异常点和噪声标签较敏感，过多轮次可能强化错误样本；实际应用要结合验证误差和早停策略判断训练轮数。

  • 收敛性：每次迭代保证似然函数不减，收敛到局部最优
  • 似然不下降不等于得到全局最优，初始化和模型假设仍会影响最终结果
3
  • 核心思想：含隐变量概率模型的极大似然估计，通过E步求期望、M步最大化交替迭代。E步用当前参数估计隐变量分布，M步据此更新模型参数。
  • 收敛性：每次迭代保证似然函数不减，收敛到局部最优。似然不下降不等于得到全局最优，初始化和模型假设仍会影响最终结果。
  • 推广：GEM算法放宽M步要求，只需提升下界即可。这个思想适合复杂模型中无法精确完成最大化的情形。
  • 应用方法：高斯混合模型是典型例子，隐变量表示样本所属成分；计算时要关注协方差退化、初始参数和停止阈值。

第10章 隐马尔可夫模型

3
  • 模型结构：由初始状态分布、状态转移概率与观测概率构成，描述隐藏状态序列生成观测序列。它假设当前状态主要依赖前一状态，当前观测由当前状态生成。
  • 三个基本问题：概率计算（前向—后向算法）、学习（Baum-Welch/EM）、预测（维特比算法）。三者分别回答序列概率、参数估计和最可能状态路径问题。
  • 算法特点：动态规划避免枚举所有状态序列，把指数级路径搜索压缩为递推计算。长序列计算时常使用对数概率或缩放因子避免数值下溢。
  • 应用定位：适用于标注问题，如序列建模与语音、自然语言处理任务；当观测独立假设不合适或特征需要跨位置组合时，应考虑更灵活的条件模型。

第12章 监督学习方法总结

3
  • 方法谱系：从生成式（朴素贝叶斯、HMM）到判别式（逻辑斯谛回归、SVM、CRF）的对照梳理。生成式方法强调联合分布，判别式方法强调决策边界或条件分布。
  • 选择依据：依据数据规模、特征性质、任务类型与可解释性需求综合权衡方法。小样本、强先验、序列依赖和高维稀疏特征往往需要不同的建模策略。
  • 统一比较方法：同一任务应固定训练验证划分和评价指标，再比较偏差、方差、计算成本与解释性，不能只依据单次准确率选模型。

第14章 聚类方法

3
  • 核心任务：依据样本间相似度将数据划分为若干簇，使簇内相似、簇间相异。相似度定义决定了聚类结果的含义。
  • 层次聚类：通过合并或分裂构建聚类树，按距离度量与链接准则决定合并顺序。树状结构便于观察不同粒度的分组，但计算成本和异常点影响不可忽略。
  • k均值聚类：以簇中心迭代优化平方误差，简单高效但需预设k且对初值敏感。每轮先分配样本，再更新中心，目标函数通常只能保证局部下降。
  • 使用边界：球状、尺度相近的簇更适合k均值；非凸形状、不同密度或大量异常点需要重新选择距离、算法和簇数判据。

第16章 主成分分析

3
  • 核心思想：通过正交变换将相关变量转为线性无关的主成分，保留最大方差方向。第一主成分解释最大方差，后续成分在正交约束下继续解释剩余方差。
  • 等价视角：可视为样本协方差矩阵的特征分解，或数据矩阵的奇异值分解。中心化是理解结果的关键，尺度差异很大时还要考虑标准化。
  • 用途：降维、特征提取与可视化，以少数主成分概括数据主要变异。它优化的是方差保留，不保证保留分类标签最有用的信息。
  • 实践边界：主成分是原始特征的线性组合，解释性可能下降；缺失值、异常值和非线性结构也会影响结果，应结合任务目标判断是否使用。

第18章 概率潜在语义分析

3
  • 生成式视角：假设文档—主题—词的概率生成过程，以EM算法估计参数。文档先选择主题，主题再生成词，主题分布和词分布由数据学习。
  • 与LSA对比：PLSA引入概率解释，但参数随文档增长，易过拟合。新文档的主题分布还需要额外推断，模型规模也会随语料增加。
  • 使用重点：EM的初始化、停止条件和主题数会影响结果；主题解释应观察高概率词的整体语义，而不是孤立地看一个词。

3
  • 核心思想：通过构造马尔可夫链使其平稳分布为目标分布，从中采样做统计推断。它以样本近似难以直接积分的后验分布。
  • 代表算法：Metropolis-Hastings与吉布斯采样，适用于高维复杂分布的采样。前者通过接受率修正提议分布，后者逐坐标从条件分布抽样。
  • 应用定位：为贝叶斯推断与复杂概率模型提供通用计算工具。实际使用要检查烧入期、自相关、有效样本量和链的混合情况。

第20章 潜在狄利克雷分配

3
  • 模型：文档—主题—词三层贝叶斯生成模型，主题分布与词分布均服从狄利克雷先验。每篇文档可以混合多个主题，每个主题也可以生成多个词。
  • 推断：常用吉布斯采样或变分推断估计后验，实现主题发现。采样方法直观但迭代成本高，变分方法速度快但依赖近似族。
  • 定位：PLSA的贝叶斯化推广，有效控制过拟合。先验参数影响主题稀疏程度，主题数则需要结合语料规模和解释需要选择。

第22章 无监督学习方法总结

3
  • 方法对照：从矩阵分解类（SVD、PCA、LSA）到概率生成类（PLSA、LDA）及采样类（MCMC）梳理脉络。矩阵方法擅长表示与近似，概率方法提供生成解释，采样方法提供后验计算工具。
  • 选择依据：依据数据结构、任务目标（降维/聚类/主题发现）与计算可行性选择方法。先确定要找的是几何方向、离散簇、主题分布还是复杂后验，再选择算法。
  • 综合判断：无监督方法的结果需要和业务解释、可重复性及下游效果结合，不能仅凭可视化图形就断言发现了真实结构。
