本书以“从零实现”为主线，用Python3在不依赖外部库的前提下，带领读者从感知机出发，逐步构建神经网络、误差反向传播与卷积神经网络，深入浅出地讲透深度学习的原理与实现细节，是初学者建立完整知识体系的理想入门书。全书的学习路径不是先记住大量框架接口，而是先理解数据如何经过层、损失如何衡量误差、梯度如何推动参数更新，再把这些概念写成可运行的程序。这样的顺序能把“模型结构”“训练算法”和“工程实现”连接起来：读者既能看懂神经网络为什么有效，也能定位代码中维度、激活函数、损失函数和更新步骤的错误。书中还通过手写数字识别、卷积和池化等内容，展示从数学表达式到矩阵运算、从单个神经元到完整网络的逐层落地过程。

第2章 感知机

3
  • 核心观点1：感知机是神经网络的起源：接收多个输入信号，输出一个信号，是实现简单逻辑电路（与门、与非门、或门）的基础。它把输入加权求和，再与阈值比较，展示了参数如何决定输出。
  • 核心观点2：权重与偏置作用不同：权重控制输入信号的重要性，偏置调整神经元被激活的容易程度。理解二者的区别，是以后理解线性层、卷积核和参数学习的基础。
  • 核心观点3：单层感知机有局限性，无法表示异或门，但通过叠加层，即多层感知机，可实现更灵活的表示。层的组合使模型能够把简单变换组织成复杂逻辑。
  • 核心观点4：感知机实现可以先写成接受两个输入的函数，再扩展到数组和多个神经元。实现时要明确权重、偏置、加权和以及阈值函数的位置，避免把参数含义混在一起。
  • 核心观点5：学习即确定参数。机器学习的课题不是人为逐一写出所有规则，而是把决定参数值的工作交给计算机，人负责设计模型结构并提供训练数据。
  • 核心观点6：从逻辑门出发能建立模型边界意识：一个简单的线性分割器能解决一部分问题，但遇到线性不可分的数据，就必须引入层、非线性或更有表达力的结构。

    而机器学习的课题就是将这个决定参数值的工作交由计算机自动进行。学习是确定合适的参数的过程，而人要做的是思考感知机的构造（模型），并把训练数据交给计算机。
    也就是说，通过叠加层（加深层），感知机能进行更加灵活的表示
    偏置和权重、的作用是不一样的。具体地说，和是控制输入信号的重要性的参数，而偏置是调整神经元被激活的容易程度（输出信号为1的程度）的参数。

  • 核心观点1：激活函数决定信号激活方式，其作用在于决定如何激活输入信号的总和。它把线性组合转化为非线性表达，使网络能够学习复杂关系。
  • 核心观点2：必须使用非线性激活函数；使用线性函数会使加深层数失去意义，因为多层线性变换仍可合并为一次线性变换。sigmoid具有平滑性，现代网络则主要使用ReLU。

  • 核心观点4：输出层激活函数依任务而定，回归问题用恒等函数，分类问题用softmax函数；分类时softmax可省略，尤其在只比较最大得分的推理阶段。
  • 核心观点5：神经网络可自动学习权重，其重要性质是能从数据中自动学习到合适的权重参数。模型结构决定可表达的范围，参数学习决定在这个范围内如何贴合数据。
  • 核心观点6：三层网络的实现要同时检查每层输入输出维度。矩阵乘法的维度对齐、激活函数的逐元素处理、输出层的类别数量，都是手写代码中最容易出错的地方。
  • 核心观点7：手写数字识别把预训练参数、输入图像、前向传播和预测结果串起来，说明推理阶段可以不更新参数，只把数据依次通过网络并选择得分最高的类别。

    神经网络的激活函数必须使用非线性函数。换句话说，激活函数不能使用线性函数。为什么不能使用线性函数呢？因为使用线性函数的话，加深神经网络的层数就没有意义了。
    激活函数的作用在于决定如何来激活输入信号的总和。
    通过矩阵的乘积一次性完成计算的技巧，在实现的层面上可以说是非常重要的。

第4章 神经网络的学习

3
  • 核心观点1：损失函数是学习的指标，表示神经网络性能的“恶劣程度”，即对监督数据的不拟合程度。训练的目标是寻找能让损失变小的参数，而不是直接凭感觉调整权重。
  • 核心观点2：不能用识别精度作指标，因为绝大多数地方导数为0，导致参数无法更新。损失函数通常提供更连续的变化信号，便于梯度方法知道应该向哪个方向移动。
  • 核心观点3：梯度指示参数更新方向；导数为负则权重向正方向改变以减小损失，导数为正则向负方向改变。学习率控制每次移动的步幅，过大可能震荡，过小则收敛缓慢。
  • 核心观点4：数值微分用于验证梯度，是理解梯度与实现学习算法的基础工具。它通过微小扰动分别观察损失变化，虽然速度慢，却适合检查手写反向传播是否正确。
  • 核心观点5：学习流程可以拆成小批量采样、计算梯度、按学习率更新参数和重复迭代。小批量让计算成本可控，也让每次更新使用训练数据的一部分。
  • 核心观点6：验证训练效果不能只看一次损失。应观察损失是否总体下降、预测是否改善、训练集与验证集是否出现明显差距，并检查学习率和参数初始化是否合理。

    之所以不能用识别精度作为指标，是因为这样一来绝大多数地方的导数都会变为0，导致参数无法更新。
    损失函数是表示神经网络性能的“恶劣程度”的指标，即当前的神经网络对监督数据在多大程度上不拟合，在多大程度上不一致。
    如果导数的值为负，通过使该权重参数向正方向改变，可以减小损失函数的值；反过来，如果导数的值为正，则通过使该权重参数向负方向改变，可以减小损失函数的值。

第5章 误差反向传播法3 个重点▾ 点开看本节重点
本节重点
  • 核心观点1：计算图使计算过程可视化，便于直观理解正向与反向传播
  • 核心观点2：链式法则是反向传播的核心，通过局部导数逐层相乘高效求梯度
  • 核心观点3：分层实现各功能层，将加法、乘法、激活函数、Affine、Softmax等封装为层，提升模块化与效率
3
  • 核心观点1：计算图使计算过程可视化，便于直观理解正向与反向传播。正向传播从输入计算输出和损失，反向传播则从损失出发沿相反方向传递局部梯度。
  • 核心观点2：链式法则是反向传播的核心，通过局部导数逐层相乘高效求梯度。它避免了数值微分对每个参数重复计算，令多层网络的训练变得可行。
  • 核心观点3：分层实现各功能层，将加法、乘法、激活函数、Affine、Softmax等封装为层，提升模块化与效率。每层保存反向传播所需的输入或中间结果，再在backward中返回上游梯度。
  • 核心观点4：反向传播大幅提速，相比数值微分能高效计算梯度，是深度学习实用的关键。实现时要区分前向接口和反向接口，并保证梯度形状与参数形状一致。
  • 核心观点5：Softmax与交叉熵损失组合后，反向结果可以简化为预测概率与监督标签之差，这让输出层的梯度计算更稳定、更容易实现。
  • 核心观点6：计算图的价值还在于定位错误。若最终梯度异常，应逐层检查输入缓存、局部导数、矩阵转置和广播，而不是只盯着最后一行参数更新。

第6章 与学习相关的技巧

3
  • 核心观点1：参数更新方法影响收敛。SGD之外还有Momentum、AdaGrad、Adam等策略，它们通过利用历史梯度、调整步幅或累积信息，改善方向选择和收敛速度。
  • 核心观点2：权重初始值至关重要。合适的初始值，如Xavier、He初始化，能避免梯度消失或爆炸；初始化过大、过小或全部相同，都会损害学习。
  • 核心观点3：Batch Normalization使各层激活值分布更稳定，提升训练速度和稳定性。它不是替代合理学习率和初始化，而是帮助深层网络更容易训练。
  • 核心观点4：正则化抑制过拟合，权重衰减、Dropout等手段提升泛化能力。训练误差低而验证误差高时，应考虑模型容量、数据量和正则化，而不是盲目增加训练轮数。
  • 核心观点5：超参数需用验证集调优。学习率、批大小、权重衰减强度和网络结构都不能只依据训练集判断，应划分验证数据，比较不同组合的泛化表现。
  • 核心观点6：技巧必须和诊断结合。损失不下降先检查数据、标签、梯度和学习率；出现过拟合再选择正则化；训练不稳定则检查初始化、归一化和更新方法，不能把所有问题都归结为模型不够深。
第7章 卷积神经网络3 个重点▾ 点开看本节重点
本节重点
  • 核心观点1：CNN专为图像设计，整体结构由卷积层、池化层与全连接层组合而成
  • 核心观点2：卷积层提取局部特征，利用滤波器在空间上共享权重，保留形状信息
  • 核心观点3：卷积输出尺寸由输入尺寸、滤波器大小、步幅和填充共同决定
3
  • 核心观点1：CNN专为图像设计，整体结构由卷积层、池化层与全连接层组合而成。它利用图像的局部性和空间结构，减少全连接层直接处理像素带来的参数负担。
  • 核心观点2：卷积层提取局部特征，利用滤波器在空间上共享权重，保留形状信息。浅层可能响应边缘和纹理，层层组合后可以表达更复杂的局部模式。
  • 核心观点3：卷积输出尺寸由输入尺寸、滤波器大小、步幅和填充共同决定。实现时必须先明确批量、通道、高度、宽度的维度顺序，再检查输出形状。
  • 核心观点4：池化层在通道方向独立处理，缩小空间尺寸并增强对小幅位置变化的鲁棒性。池化会损失部分精细位置信息，因此要结合任务判断下采样是否合适。
  • 核心观点5：CNN的实现需要把四维张量转换为适合矩阵乘法的形式，再在输出时恢复空间结构。im2col等技巧能把卷积转成矩阵运算，提升实现效率。
  • 核心观点6：CNN可视化揭示特征，通过可视化可观察各层学到的边缘、纹理等特征。可视化有助于理解网络究竟在响应什么，也可作为数据和训练是否异常的辅助证据。
  • 核心观点7：LeNet、AlexNet等代表性CNN奠定基础，说明结构设计、数据规模、激活函数和计算硬件会共同影响视觉模型的发展。

第8章 深度学习

3
  • 核心观点1：加深网络能提升识别精度，多层叠加可以学习更抽象、更具表达力的特征，但深度增加也会带来优化困难、计算成本和过拟合风险。
  • 核心观点2：深度学习有清晰的发展脉络，从早期神经网络到现代深度模型，关键推动力包括算法改进、数据积累和计算能力提升，三者缺一不可。
  • 核心观点3：高速化依赖GPU与分布式计算。深度学习中大量矩阵运算适合并行处理，但工程上还要关注显存、数据传输、批量大小和可复现性。
  • 核心观点4：应用涵盖自动驾驶、图像生成、强化学习等多个领域。不同任务仍可回到同一基本框架：准备数据、设计模型、定义损失、优化参数、验证泛化。
  • 核心观点5：未来潜力巨大，但模型效果不能脱离数据质量、评价指标和实际约束。深度模型不是自动解决问题的魔法，使用者仍需理解任务边界、错误代价和部署环境。
