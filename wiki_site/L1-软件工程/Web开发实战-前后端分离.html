前后端分离是现代 Web 开发的标准架构——前端负责展示与交互，后端负责数据与逻辑，通过 RESTful API 通信。这种架构让团队协作更高效、系统更易扩展、维护成本更低。

WHY 为什么这个知识重要

2

1. 团队协作效率提升：前端和后端可以并行开发，互不阻塞。

2. 系统可扩展性强：前端可以是 Web、移动端、小程序，后端只需提供统一 API。

3. 技术栈灵活：前端可以用 Vue/React，后端可以用 Node.js/Python/Java，互不影响。

4. 部署独立：前端静态资源可以放 CDN，后端可以水平扩展。

Q1：前后端分离和传统 MVC 有什么区别？

A1：传统 MVC 中，前端页面由后端渲染（如 JSP、PHP）；前后端分离中，前端独立渲染，后端只提供数据（JSON）。

Q2：什么时候用 RESTful API，什么时候用 GraphQL？

A2：简单场景用 RESTful，复杂查询（如移动端需要灵活字段）用 GraphQL。

Q3：跨域问题怎么解决？

A3：后端设置 CORS 头，或使用 Nginx 反向代理。
