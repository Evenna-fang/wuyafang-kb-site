FastAPI 的核心优势：类型即文档。Pydantic 模型自动生成 OpenAPI 规范，Swagger UI 自动在 /docs 可用。

# main.py — 最小示例
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="L1 Demo", version="0.1")

@app.get("/")
def read_root():
    return {"message": "Hello L1"}

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}

启动命令：

pip install "fastapi[all]" uvicorn
uvicorn main:app --reload --port 8000

浏览器打开 http://localhost:8000/docs，Swagger UI 自动出现。这就是 FastAPI 与 Flask 的核心差异——你写类型注解，它给你一整套 API 文档和校验。

from pydantic import BaseModel, Field, EmailStr
from datetime import datetime

class UserCreate(BaseModel):
    name: str = Field(..., min_length=2, max_length=50, example="张三")
    email: EmailStr
    age: int = Field(..., ge=0, le=150, description="年龄 0-150")
    is_active: bool = True
    created_at: datetime | None = None

    model_config = {
        "json_schema_extra": {
            "examples": [
                {"name": "张三", "email": "zhangsan@example.com", "age": 28}
            ]
        }
    }

@app.post("/users/", response_model=UserCreate, status_code=201)
def create_user(user: UserCreate):
    # 自动校验：name 太短会 422，age=200 会 422，email 格式错会 422
    return user

2.2 常见校验陷阱

3
写法 问题 正确做法
age: int 没范围限制，age=9999 也通过 Field(..., ge=0, le=150)
name: str 空字符串通过 Field(..., min_length=1)
email: str 不校验格式 EmailStr（需 pip install email-validator）
响应直接 return ORM 对象 序列化失败 response_model= 指定输出模型
三、文件上传接口实操3 个重点▾ 点开看本章重点
本章重点
  • @app.post("/upload/")
  • 关键点：「UploadFile」 是异步接口，大文件不会把内存撑爆（FastAPI 自动用 SpooledTemporaryFile 滚动写磁盘）
  • shutil.copyfileobj(file.file, buffer)
2 
from fastapi import UploadFile, File, Form
import shutil
from pathlib import Path

UPLOAD_DIR = Path("./uploads")
UPLOAD_DIR.mkdir(exist_ok=True)

@app.post("/upload/")
async def upload_file(
    file: UploadFile = File(..., description="上传文件"),
    category: str = Form("default", description="分类标签")
):
    # 安全校验：扩展名白名单
    allowed = {".png", ".jpg", ".jpeg", ".pdf", ".md"}
    suffix = Path(file.filename).suffix.lower()
    if suffix not in allowed:
        return {"error": f"不支持的文件类型 {suffix}"}

    # 保存到磁盘
    save_path = UPLOAD_DIR / file.filename
    with save_path.open("wb") as buffer:
        shutil.copyfileobj(file.file, buffer)

    return {
        "filename": file.filename,
        "content_type": file.content_type,
        "size": save_path.stat().st_size,
        "category": category
    }

关键点：UploadFile 是异步接口，大文件不会把内存撑爆（FastAPI 自动用 SpooledTemporaryFile 滚动写磁盘）。

4.2 FastAPI 路由挂载

# backend/main.py
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from routers import users, uploads

app = FastAPI(title="L1 前后端分离 Demo")

# CORS：开发环境允许 Vue dev server 跨域
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # Vite 默认端口
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(users.router, prefix="/api/users", tags=["用户"])
app.include_router(uploads.router, prefix="/api/upload", tags=["上传"])

// frontend/src/api/index.js
import axios from 'axios'

const api = axios.create({
  baseURL: 'http://localhost:8000/api',
  timeout: 10000,
})

// 响应拦截：统一处理 422 校验错误
api.interceptors.response.use(
  res => res.data,
  err => {
    if (err.response?.status === 422) {
      const detail = err.response.data.detail
      console.error('参数校验失败:', detail)
    }
    return Promise.reject(err)
  }
)

export const fetchUsers = () => api.get('/users/')
export const createUser = (data) => api.post('/users/', data)
export const uploadFile = (formData) => api.post('/upload/', formData)

4.4 Vue 组件调用示例

3 
<!-- frontend/src/views/UserList.vue -->
<script setup>
import { ref, onMounted } from 'vue'
import { fetchUsers, createUser } from '../api'

const users = ref([])
const form = ref({ name: '', email: '', age: null })

onMounted(async () => {
  users.value = await fetchUsers()
})

async function submit() {
  await createUser(form.value)
  users.value = await fetchUsers()  // 刷新列表
}
</script>

<template>
  <div>
    <h2>用户列表</h2>
    <ul><li v-for="u in users" :key="u.email">{{ u.name }}</li></ul>
    <form @submit.prevent="submit">
      <input v-model="form.name" placeholder="姓名" />
      <input v-model="form.email" type="email" placeholder="邮箱" />
      <input v-model.number="form.age" type="number" placeholder="年龄" />
      <button>提交</button>
    </form>
  </div>
</template>
