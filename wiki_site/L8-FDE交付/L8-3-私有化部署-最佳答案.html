4. 三条口诀（据[一手源]：FDE私有化离线部署-外部调研-20261012，技术边界见 技术专项）

3
  • "offline"不等于 air-gapped：vLLM 文档的 offline 指批量推理，客户要的是 egress-denied（出口拒绝）。必设 HF_HUB_OFFLINE=1、VLLM_NO_USAGE_STATS=1、--enable-offline-docs；模型解析链 6 步（config 查找→解析→model_type 分派→RoPE 补丁→AutoTokenizer→权重）本地路径只短路一部分，必须在真实断网环境冷启动验证。
  • 硬件决定模型档位：纯 CPU 上 8B≈3 tok/s 不进生产；RTX 3090 24GB 上 8B≈80、24B≈35、32B≈25 tok/s（tier 2 单用户实测）；小团队起步配二手 RTX 3060 12GB；量化默认 Q4_K_M。
  • 进场先填现场约束清单：网络（断网/白名单）· 硬件与驱动 · 操作系统权限 · 数据脱敏与审计 · 更新方式（离线包/U 盘）与版本锁定 · 等保级别与驻场 · 既有系统集成。对客话术：air-gap 是"消除一整类控制"，但必须配套书面 AI Governance Framework。

# offline_rag.py —— 全程本地，零外网依赖
from fastapi import FastAPI
from pydantic import BaseModel
import chromadb
from sentence_transformers import SentenceTransformer, CrossEncoder
from openai import OpenAI

app = FastAPI()
embedder = SentenceTransformer("/models/bge-m3", device="cuda")
reranker = CrossEncoder("/models/bge-reranker-v2-m3", device="cuda")
chroma = chromadb.PersistentClient(path="/data/chroma")
collection = chroma.get_or_create_collection("kb")
llm = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="EMPTY")

@app.post("/ask")
def ask(q: Query):
    emb = embedder.encode(q.question, return_dict=True)
    docs = collection.query(query_embeddings=emb["dense"], n_results=q.top_k)["documents"][0]
    scores = reranker.predict([(q.question, d) for d in docs])
    ranked = sorted(zip(docs, scores), key=lambda x: -x[1])[: q.final_k]
    context = "\n---\n".join([d for d, _ in ranked])
    prompt = f"基于以下内部资料回答，不知道就说不知道。资料：{context}\n问题：{q.question}"
    out = llm.chat.completions.create(model="qwen2.5-14b-awq",
        messages=[{"role": "user", "content": prompt}], temperature=0.2)
    return {"answer": out.choices[0].message.content, "sources": ranked}

常见坑（血泪）3 个重点▾ 点开看本节重点
本节重点
  • 1. pip wheel 漏包：只导直接依赖漏了 transitive → 用 「pip download」 而不是拷 site-packages
  • 3. GGUF vs AWQ 混用：Ollama 只吃 GGUF，vLLM 只吃 AWQ/GPTQ，别想转换 → 一开始就定推理引擎再选量化格式
  • 4. 向量库索引忘导出：Chroma/Qdrant 索引数据要挂到宿主机目录，镜像重建不丢
3
  1. 把 vLLM「offline」当成 air-gapped：本地路径起得来≠断网起得来。漏设 HF_HUB_OFFLINE=1 / VLLM_NO_USAGE_STATS=1，新模型的 tokenizer/processor 分支仍会尝试联网，遥测也会外发（据[一手源]：FDE私有化离线部署-外部调研-20261012 §五，particula 2026-04 实测 egress-denied 场景）。
  2. pip wheel 漏包：只导直接依赖漏了 transitive → 用 pip download 而不是拷 site-packages。
  3. PyTorch CUDA 版本错位：镜像里 torch cu118，客户机器 cu121 驱动 → 从一开始就用官方 vLLM/PyTorch 镜像，别自己 pip install torch。
  4. GGUF vs AWQ 混用：Ollama 只吃 GGUF，vLLM 只吃 AWQ/GPTQ，别想转换 → 一开始就定推理引擎再选量化格式。
  5. 向量库索引忘导出：Chroma/Qdrant 索引数据要挂到宿主机目录，镜像重建不丢。
  6. 大镜像 U 盘拷不过：FAT32 单文件 4G 上限 → split -b 4000M 分包，客户侧 cat part-* > bundle.tar。
