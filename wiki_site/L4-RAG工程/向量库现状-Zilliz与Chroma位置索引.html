结论先行

3

本地和云端两套都在，云端（Zilliz Cloud）是活的，有 2 万多条真实数据。

  • 本地：ChromaDB（~/kb-local/rag/index/chroma.sqlite3，463MB，索引目录 2.3G）
  • 云端：Zilliz Cloud 托管 Milvus（杭州 serverless），3 个集合共 23,674 条

问"有没有用 Milvus"→ 有，走的是 Zilliz Cloud 托管版，不是本地自建。
本地 docker ps 查不到 Milvus 容器 不代表没在用。

判断口径（防再误判）

3
  1. 问"用没用某向量库"→ 先查 cloud_backend.py 是否被主流程 import，再查云端集合条数，不能只因本地无容器就否定
  2. 查凭据→ 同时查 ~/.hermes/.env 和 ~/.hermes/secrets.env（后者是真源）
  3. 云端与本地并存是设计现状，不是冲突：本地 Chroma 供离线/开发，云端供多端访问

import os
env={}
for line in open(os.path.expanduser('~/.hermes/secrets.env'),encoding='utf-8',errors='replace'):
    line=line.strip()
    if line.startswith('#') or '=' not in line: continue
    k,v=line.split('=',1); env[k.strip()]=v.strip().strip('"').strip("'")
from pymilvus import MilvusClient
c=MilvusClient(uri=env['ZILLIZ_URI'], token=env['ZILLIZ_TOKEN'])
for n in c.list_collections():
    print(n, c.get_collection_stats(n).get('row_count'))

本节 2026-11-05 补写，逐条核验路径与函数名（可 grep 复核），不复述正文快照数字。

  • 本地 Chroma 侧：主检索链路全部走本地（rag/query.py retrieve_hybrid() L867 等），索引目录与集合名由 rag/config.yaml 的 index 段控制；scripts/build_kb.py chroma_stats()（L196）用 sqlite 只读直查 embedding_metadata 统计 chunk/文件数（不启 Chroma 客户端）。
