把图像直接拉成向量喂给全连接网络，有两个致命问题：

  1. 参数爆炸：224x224x3 的图像拉平是 15 万维，接一个 1000 类的输出层就要 1.5 亿参数，一张显卡都装不下。
  2. 丢失空间结构：拉平后像素间的相邻关系消失，网络无法利用"边缘、角点、纹理"这些局部模式的平移不变性。

CNN 的两个设计直接解决这两个问题：

  • 局部感受野：每个输出单元只看输入的一小块（如 3x3），提取局部特征（边缘、角点、纹理）。
  • 参数共享：同一组卷积核在图像所有位置复用，参数量与图像尺寸无关，只与核大小和通道数有关。

加上平移等变性（同一特征出现在图像不同位置，卷积核都能响应），CNN 天然适合图像分类、目标检测、语义分割等视觉任务。什么情况下用：输入是网格结构（图像、频谱图、某些时间序列），有局部相关性和平移不变性，样本量不足以训 ViT 时。什么情况下别用：输入是一维序列且长距离依赖强（用 Transformer/RNN）；输入是表格特征无空间结构（用树模型）；数据量极大且算力充足——ViT 在超大数据集上能超过 CNN（见 §5.4）。

翻车总纲：特征提取不出来→感受野不足或核初始化错；边缘区域响应异常→padding 伪影；小目标丢失→stride 过大；shape 不匹配崩溃→池化尺寸计算错。每种形态在 §6 给症状→根因→改法三段。

1. 卷积：从"变化率"到"特征提取"

2

卷积这个词在数学和深度学习里含义略有不同，先对齐概念再谈实现。数学卷积是两个函数的加权叠加（带翻转），深度学习里实际用的是互相关（cross-correlation，不翻转），但因为核的值是学出来的（翻转与否只是符号约定），两者表达能力等价，工程上都叫"卷积"。CNN 里的卷积本质是用一个小矩阵（核）在输入上滑动，每个位置做局部加权求和，输出一个特征图。核的值决定了它检测什么模式，训练时这些值由反向传播自动学出。

理解卷积要抓住三个关键词：局部（每个输出只看一小块输入）、共享（同一组核用在所有位置）、平移等变（特征移到别处，响应也移到别处）。这三个性质是 CNN 处理图像优于全连接的根本原因，也是后面所有设计（池化、感受野、多尺度）的基础。

1.2 二维卷积：核滑过图像

3

把一维核扩展到二维，就是 CNN 的卷积层。一个 3x3 核在图像每个位置做逐元素乘加（互相关，深度学习惯例不翻转核），输出一个特征图（feature map）。不同核提取不同特征：

  • 垂直边缘核（[[-1,0,1],[-1,0,1],[-1,0,1]]）：检测左右方向的亮度变化。
  • 水平边缘核（[[-1,-1,-1],[0,0,0],[1,1,1]]）：检测上下方向的亮度变化。
  • 锐化核、模糊核、角点核：通过核值设计检测不同模式。

训练时核的值不是人工设计的，是从数据里学出来的——反向传播自动调整核值，让网络学到最有判别力的特征。这是 CNN 与传统图像处理（手工设计 Sobel/Canny 核）的本质区别。

本节重点

  • 这决定了卷积层本身是线性的，非线性靠后面的激活函数提供
  • 平移等变性：输入平移 k，输出也平移 k（不考虑 padding 边缘）

  • 交换性：数学卷积满足交换律，但深度学习用互相关（不翻转核），实现更简单且等效（核值可学，翻转与否无所谓）。

  • 参数共享的收益：一个 7x7x3 的核只有 147 个参数（+1 偏置），但可以滑过整张 224x224 图像，在每个位置做特征检测。参数量与图像尺寸无关，这是 CNN 能处理高分辨率图像的根本原因。

输入 (H, W)，核 (k, k)，步长 stride=s，padding=p：

输出 H_out = (H + 2p − k) / s + 1（向下取整）

这是 CNN shape 错误的头号来源，写代码前必须手算一遍。实跑验证：

import numpy as np

def conv2d(x, k, stride=1, pad=0):
    # x: (H, W), k: (kh, kw) —— 2D 互相关(深度学习惯例,不做翻转)
    H, W = x.shape
    kh, kw = k.shape
    xp = np.pad(x, pad)
    Ho = (H + 2 * pad - kh) // stride + 1
    Wo = (W + 2 * pad - kw) // stride + 1
    out = np.zeros((Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            patch = xp[i * stride:i * stride + kh, j * stride:j * stride + kw]
            out[i, j] = (patch * k).sum()
    return out

x = np.zeros((32, 32))
k = np.zeros((5, 5))
print("32x32, k5, s1, p0 ->", conv2d(x, k).shape)      # (28,28)
print("32x32, k5, s2, p2 ->", conv2d(x, k, stride=2, pad=2).shape)  # (16,16)

实跑输出 (28, 28) 和 (16, 16)。核太大或 stride 太大都会让特征图迅速缩小，深层网络很容易出现非整数尺寸，先用公式算清楚再写代码。

2.2 边缘检测实跑：卷积核在干什么

3

8x8 图像（左半暗右半亮，含垂直边缘），用垂直边缘核和水平边缘核卷积：

import numpy as np

# 8x8 图像: 左半暗右半亮(垂直边缘)
img = np.zeros((8, 8)); img[:, 4:] = 1.0

k_v = np.array([[-1, 0, 1],
                [-1, 0, 1],
                [-1, 0, 1]])        # 垂直边缘核(检测左右变化)
k_h = np.array([[-1, -1, -1],
                [ 0,  0,  0],
                [ 1,  1,  1]])      # 水平边缘核(检测上下变化)

def conv2d(x, k, stride=1, pad=0):
    H, W = x.shape; kh, kw = k.shape
    xp = np.pad(x, pad)
    Ho = (H + 2 * pad - kh) // stride + 1
    Wo = (W + 2 * pad - kw) // stride + 1
    out = np.zeros((Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            patch = xp[i * stride:i * stride + kh, j * stride:j * stride + kw]
            out[i, j] = (patch * k).sum()
    return out

o_v = conv2d(img, k_v, pad=1)
print("垂直边缘核输出:\n", o_v.astype(int))
o_h = conv2d(img, k_h, pad=1)
print("水平边缘核输出:\n", o_h.astype(int))

  [ 0  0  0  3  3  0  0 -3]

  • 参数量 = k² × C_in × C_out + C_out（偏置）

3.1 最大池化与平均池化

3

池化在每个 kxk 窗口内取最大值（maxpool）或平均值（avgpool），stride 通常等于 k，输出尺寸缩小 k 倍。作用：

  • 降低分辨率：减少后续层的计算量和参数量。
  • 扩大感受野：池化后每个单元覆盖的原始输入区域变大（见 §4）。
  • 平移不变性：特征在窗口内小范围平移，池化输出不变。
import numpy as np

def maxpool2d(x, size=2, stride=2):
    H, W = x.shape
    Ho = (H - size) // stride + 1
    Wo = (W - size) // stride + 1
    out = np.zeros((Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            out[i, j] = x[i * stride:i * stride + size, j * stride:j * stride + size].max()
    return out

x = np.array([[1.0, 3.0], [2.0, 0.5]])
print("2x2 maxpool:", maxpool2d(x).tolist())  # [[3.0]]

实跑输出 [[3.0]]——2x2 窗口取最大值 3.0。池化层没有可学习参数，只有超参数（窗口大小、stride），这也是它不会过拟合的原因。

3.2 池化的反向传播：梯度只传给 argmax3 个重点▾ 点开看本节重点
本节重点

  • print("maxpool out:", out.tolist()) [[3.0]]
  • print("argmax mask:", mask.astype(int).reshape(2, 2).tolist()) [[0,1],[0,0]]

最大池化前向只取最大值，反向传播时上游梯度只传给前向时取到最大值的那个位置，其余位置梯度为 0。实测：

import numpy as np

x = np.array([[1.0, 3.0], [2.0, 0.5]])
def maxpool_with_mask(x):
    flat = x.reshape(1, 2, 1, 2)
    out = flat.max(axis=(1, 3))
    mask = (flat == out[:, None, :, None])
    return out, mask
out, mask = maxpool_with_mask(x)
print("maxpool out:", out.tolist())           # [[3.0]]
print("argmax mask:", mask.astype(int).reshape(2, 2).tolist())  # [[0,1],[0,0]]
dx = mask.astype(float).reshape(2, 2)
print("反传梯度 dx:", dx.tolist())            # [[0.0,1.0],[0.0,0.0]]

实跑输出：

maxpool out: [[3.0]]
argmax mask: [[0, 1], [0, 0]]
反传梯度 dx: [[0.0, 1.0], [0.0, 0.0]]

只有 (0,1) 位置（前向取到 3.0 的位置）收到梯度，其余 3 个位置梯度为 0。这就是 maxpool 的"梯度路由"机制：只有"赢"的神经元收到学习信号，输的完全不动。这也是死神经元的一种来源（CNN 版）：如果某单元从未在任何池化窗口中赢过，它的梯度永远是 0。

3.3 全局平均池化（GAP）

3

传统 CNN 末端用全连接层把特征图拉平再分类，参数量巨大（VGG 的全连接层占总参数 90%+）。全局平均池化把每个通道的特征图取平均，输出 (C,) 向量直接接 softmax：

  • 参数量从"特征图大小×类别数"降到 0（GAP 无参数）。
  • 强迫每个通道对应一个语义类别（特征图就是类别激活图），可解释性更好。
  • 天然抗过拟合（无参数可过拟合）。

现代 CNN（ResNet、MobileNet）末端基本都用 GAP 替代全连接。

3.4 平均池化 vs 最大池化：怎么选3 个重点▾ 点开看本节重点
本节重点
  • 最大池化：取窗口最大值，保留最显著特征（最强响应），对噪声鲁棒（异常值被 max 忽略）
  • 分类网络默认用 maxpool，因为"最强特征"比"平均特征"更有判别力
  • 平均池化：取窗口平均，保留整体信息，平滑但可能稀释显著特征
3
  • 最大池化：取窗口最大值，保留最显著特征（最强响应），对噪声鲁棒（异常值被 max 忽略）。分类网络默认用 maxpool，因为"最强特征"比"平均特征"更有判别力。
  • 平均池化：取窗口平均，保留整体信息，平滑但可能稀释显著特征。GAP（全局平均池化）用在末端做维度压缩；某些分割网络的上采样路径用 avgpool 做平滑下采样。
  • 判据：隐藏层下采样用 maxpool（特征提取阶段要"找最强"），末端维度压缩用 GAP（要"整体汇总"）。不要混用——在需要强特征的地方用 avgpool 会让特征变糊。

3.5 池化层的取舍：现代网络里池化在变少

3

池化曾是 CNN 标配，但现代设计有减少池化的趋势：

  • stride 卷积替代池化：用 stride=2 的卷积替代池化，既下采样又可学习，参数略增但表达更强。很多现代架构（ResNet 变体）用 stride=2 卷积替代 pool。
  • 空洞卷积替代池化：分割任务要保持高分辨率，用空洞卷积在不缩小特征图的前提下扩大感受野（§4.3）。
  • 完全无池化：某些极简网络全用 stride 卷积，池化只在 GAP 用一次。

判据：常规分类网络用池化没问题；分割/检测等需要高分辨率的任务优先用 stride 卷积或空洞卷积；不要为了"更现代"盲目去掉池化——它便宜、稳定、抗过拟合。

4.1 感受野公式

3

第 l 层某个单元"看到"的原始输入区域大小就是感受野（receptive field）。递推公式：

R_l = R_{l-1} + (k_l − 1) × J_{l-1}
J_l = J_{l-1} × s_l

其中 R 是感受野大小，J 是跳距（相邻两个单元在输入上的距离），k 是核大小，s 是 stride。R_0=1，J_0=1。

实跑验证：

def rf(layers):
    r, j = 1, 1  # 感受野, 跳距
    for k, s in layers:
        r = r + (k - 1) * j
        j = j * s
    return r

print("3层3x3 s1 感受野:", rf([(3, 1)] * 3))           # 7
print("2层3x3 s2 感受野:", rf([(3, 2), (3, 2)]))       # 7
print("3x3s1 + 2x2s2 + 3x3s1 感受野:", rf([(3, 1), (2, 2), (3, 1)]))  # 8

实跑输出：

3层3x3 s1 感受野: 7
2层3x3 s2 感受野: 7
3x3s1 + 2x2s2 + 3x3s1 感受野: 8

两个 3x3 核等效一个 5x5 核，三个 3x3 等效一个 7x7，但参数量更少（3×9=27 vs 49）且非线性更强（每层一次激活）。这是 VGG 用堆叠 3x3 替代大核的动机。

感受野的递推直觉：每加一层核大小 k、stride s，感受野增加 (k−1)×跳距，跳距乘以 s。stride 是感受野增长的加速器——一个 2x2 stride=2 的池化让后续所有层的跳距翻倍，感受野增长速度也翻倍。这就是为什么"卷积+池化"交替堆叠能快速覆盖整图：每池化一次，后续每个单元"看"的范围翻倍。

有效感受野 vs 理论感受野：理论感受野是公式算出的覆盖范围，但有效感受野（实际起作用的区域）远小于理论值，且集中在中心、呈高斯衰减。这意味着堆很多层后理论感受野很大，实际网络还是主要看中心区域。扩大有效感受野的办法：加注意力机制（显式加权）、用空洞卷积（核元素间隔扩大）、减小 stride（保持高分辨率）。

4.3 空洞卷积：不缩小特征图扩大感受野

3

空洞卷积（dilated convolution）在核元素之间插入空洞（间隔 r−1 个零），等效核大小变成 k + (k−1)(r−1)，但参数量不变、输出尺寸不变。实测感受野：

def rf_dilated(layers):
    # layers: (kernel, dilation, stride)
    r, j = 1, 1
    for k, d, s in layers:
        eff_k = k + (k - 1) * (d - 1)   # 等效核大小
        r = r + (eff_k - 1) * j
        j = j * s
    return r

print("3层3x3 d=1:", rf_dilated([(3, 1, 1)] * 3))       # 7
print("3层3x3 d=2:", rf_dilated([(3, 2, 1)] * 3))       # 15
print("3层3x3 d=4:", rf_dilated([(3, 4, 1)] * 3))       # 31

实跑输出：3 层 3x3、dilation=1 感受野 7，dilation=2 感受野 15，dilation=4 感受野 31——层数不变、参数量不变，感受野指数增长。语义分割（DeepLab 系列）用这个技巧在保持输出分辨率的同时覆盖整图上下文。

5.1 卷积层梯度的直觉3 个重点▾ 点开看本节重点
本节重点
  • 卷积层的梯度公式和全连接层是同一套链式法则，只是矩阵乘法换成"卷积/转置卷积"
  • return float((o 2).sum())
  • 实跑输出 「7.81e-09」（浮点精度极限附近），卷积层反向传播实现正确
3

卷积层的梯度公式和全连接层是同一套链式法则，只是矩阵乘法换成"卷积/转置卷积"。对卷积核 k 的梯度：

∂loss/∂k[i,j] = Σ_{p,q} (∂loss/∂out[p,q]) · input_pad[p+i, q+j]

直觉：核的每个参数的梯度=上游梯度×对应输入位置的加权和——核在训练中被"拉向"能产生正确响应的方向。卷积层的梯度核对（数值 vs 解析）实测：

import numpy as np

rng = np.random.default_rng(42)

def conv2d(x, k, stride=1, pad=0):
    H, W = x.shape; kh, kw = k.shape
    xp = np.pad(x, pad)
    Ho = (H + 2 * pad - kh) // stride + 1
    Wo = (W + 2 * pad - kw) // stride + 1
    out = np.zeros((Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            patch = xp[i * stride:i * stride + kh, j * stride:j * stride + kw]
            out[i, j] = (patch * k).sum()
    return out

x = rng.normal(size=(8, 8))
k0 = rng.normal(0, 1, size=(3, 3))

def loss_fn(k):
    o = conv2d(x, k, pad=1)
    return float((o ** 2).sum())

def analytic_grad(k):
    o = conv2d(x, k, pad=1)
    xp = np.pad(x, 1)
    g = np.zeros_like(k)
    for i in range(3):
        for j in range(3):
            s = 0.0
            for p in range(8):
                for q in range(8):
                    s += 2 * o[p, q] * xp[p + i, q + j]
            g[i, j] = s
    return g

g_ana = analytic_grad(k0)

eps = 1e-6
g_num = np.zeros_like(k0)
it = np.nditer(k0, flags=["multi_index"])
while not it.finished:
    idx = it.multi_index
    old = k0[idx]
    k0[idx] = old + eps; lp = loss_fn(k0)
    k0[idx] = old - eps; lm = loss_fn(k0)
    k0[idx] = old
    g_num[idx] = (lp - lm) / (2 * eps)
    it.iternext()

print("卷积核梯度 max|analytic-numeric| =", float(np.abs(g_ana - g_num).max()))

实跑输出 7.81e-09（浮点精度极限附近），卷积层反向传播实现正确。与神经网络篇 §2.2 同理：手写卷积 backward 后必须做数值梯度核对，否则"loss 下降"可能只是巧合。

5.2 maxpool 的梯度路由

3

最大池化前向只取最大值，反向传播时上游梯度只传给前向时取到最大值的那个位置（argmax），其余位置梯度为 0。这是 CNN 版的"梯度路由"机制。实测（2x2 输入，上游梯度全 1）：

import numpy as np

def maxpool_with_mask(x):
    flat = x.reshape(1, 2, 1, 2)
    out = flat.max(axis=(1, 3))
    mask = (flat == out[:, None, :, None])
    return out, mask

xp = np.array([[1.0, 3.0], [2.0, 0.5]])
out, mask = maxpool_with_mask(xp)
dx = mask.astype(float).reshape(2, 2)
print("maxpool out:", out.tolist(), "反传 dx:", dx.tolist())

实跑输出 maxpool out: [[3.0]] 反传 dx: [[0.0, 1.0], [0.0, 0.0]]——只有 (0,1) 位置（前向取到 3.0）收到梯度。潜在问题：如果某卷积单元在所有训练样本的池化窗口里都"输"（从未成为 argmax），它的梯度永远为 0，权重永远不更新——这是 CNN 版死神经元，比 ReLU 死神经元更隐蔽。监控方法：统计每层各通道的 argmax 命中率，长期为 0 的通道考虑删掉或加 LeakyReLU。

import numpy as np

def loss_full(k):
    o = conv2d(x, k, pad=1)          # 8x8
    o = np.maximum(0, o)             # relu
    o2 = np.zeros((4, 4))
    for i in range(4):
        for j in range(4):
            o2[i, j] = o[2 * i:2 * i + 2, 2 * j:2 * j + 2].max()  # 2x2 maxpool
    return float(o2.sum())

g_num2 = np.zeros_like(k0)
it = np.nditer(k0, flags=["multi_index"])
while not it.finished:
    idx = it.multi_index
    old = k0[idx]
    k0[idx] = old + eps; lp = loss_full(k0)
    k0[idx] = old - eps; lm = loss_full(k0)
    k0[idx] = old
    g_num2[idx] = (lp - lm) / (2 * eps)
    it.iternext()
print("端到端(conv+relu+maxpool)核梯度非零元素数:", int((np.abs(g_num2) > 1e-9).sum()), "/ 9")

实跑输出 9 / 9（9 个核参数全部收到梯度，梯度值如 0.0126, 5.4587, -2.0756...）。说明 relu+maxpool 的组合没有把梯度完全切断——只要每层都有部分位置激活/赢池化，梯度就能传回来。极端情况下（所有位置 relu 后为 0，或某通道全输池化）梯度会断，此时要看是不是学习率过大导致死神经元（神经网络篇 §5.4）。

6.8 网络设计的通用模式

3

从 LeNet 到 ResNet 的演进不是随机试错，是几个设计模式的反复应用：

  1. 用小核堆叠替代大核：两个 3x3 等效一个 5x5，但参数 18 vs 25、非线性 2 次 vs 1 次。现代网络几乎全用 3x3（偶用 1x1 降维）。
  2. 1x1 卷积做通道压缩：在保持空间分辨率的前提下跨通道线性组合，降维/升维都靠它（Inception/ResNet 的核心技巧）。
  3. 残差连接解决深度瓶颈：网络超过 20 层后单纯堆叠会退化，shortcut 让梯度直达输入，是深度网络的标准组件。
  4. 全局平均池化替代末端全连接：参数量从"特征图×类别"降到 0，抗过拟合且可解释。
  5. 多尺度并行提取：不同大小的核看不同尺度的目标，拼接融合（Inception/FPN）。

架构搜索（NAS）：这些模式现在可以用神经架构搜索自动找，但搜索成本极高（几百 GPU 天），工程上还是先用成熟架构（ResNet/EfficientNet）微调，实在不行再考虑 NAS。

3

数据少时不要从头训，用预训练模型做迁移学习。CNN 的迁移学习分三档：

  1. 特征提取：冻结全部卷积层，只重训末端全连接（分类头）。适合数据很少（<1000 样本），训练几分钟就够。
  2. 微调（fine-tune）：解冻后面几层卷积，用预训练权重 1/100 的小学习率一起训。适合数据中等（1000~10 万）。
  3. 从头训：数据充足（>10 万）且与预训练分布差异大（如医学影像 vs 自然图像）时才考虑。

为什么有效：CNN 浅层学到的是通用特征（边缘、纹理、颜色斑点），跨任务通用；深层才是任务相关特征。冻结浅层=复用通用特征提取能力，只调深层=适配新任务。多模态场景（课件 §6.7）的 CNN 提特征+LLM 推理就是这个逻辑的延伸：CNN 主干当通用视觉特征提取器，Transformer 当任务适配头。

学习率分层设置：微调时不要给所有层同一个学习率——浅层用更小的学习率（已经学好，微调即可），深层用更大的学习率（任务相关，需要多改）。框架里的 param_groups 就是为这个设计的。

7.2 翻车形态：卷积核初始化对称

3
  • 症状：所有卷积核输出相同，后续层无差别，网络等价于单核，特征多样性丧失。
  • 根因：初始化为常数（如全 1 或全 0），对称性未打破，反向传播梯度相同，权重永远相同。

import numpy as np

rng = np.random.default_rng(42)
img = rng.normal(size=(8, 8))
k_const = np.ones((3, 3)) / 9.0

def conv2d(x, k, pad=0):
    H, W = x.shape; kh, kw = k.shape
    xp = np.pad(x, pad)
    out = np.zeros((H - kh + 1 + 2 * pad, W - kw + 1 + 2 * pad))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = (xp[i:i + kh, j:j + kw] * k).sum()
    return out

o3 = conv2d(img, k_rand, pad=1)
print("[2] 改法 随机核两次输出是否相同:", np.allclose(o1, o3))  # False

8. 模型选择：交叉验证与小样本评估

2

CNN 训练完要看泛化能力，但单次训练/验证切分的指标波动大，尤其小样本时。交叉验证（K 折 CV）是更可靠的评估方式。实测（60 样本、10 维、线性模型，对比单次切分与 5 折 CV）：

import numpy as np
from statistics import mean, stdev

rng = np.random.default_rng(77)
N, D = 60, 10
X = rng.normal(size=(N, D))
w_true = np.zeros(D); w_true[:3] = [2.5, -1.5, 1.0]
y = X @ w_true + rng.normal(0, 0.8, size=N)

def fit(Xtr, ytr, Xte, yte, l2=0.01, steps=500, lr=0.05):
    w = np.zeros(Xtr.shape[1])
    for _ in range(steps):
        g = Xtr.T @ (Xtr @ w - ytr) / len(ytr) + l2 * w
        w -= lr * g
    pred = Xte @ w
    return float(((pred - yte) ** 2).mean())

# 单次 80/20 切分, 不同随机种子 -> 指标波动
mses = []
for seed in range(10):
    r = np.random.default_rng(seed)
    idx = r.permutation(N)
    tr, te = idx[:48], idx[48:]
    mses.append(fit(X[tr], y[tr], X[te], y[te]))
print("单次切分 10个种子 MSE: 均值=%.4f 标准差=%.4f 范围=[%.4f, %.4f]" % (
    mean(mses), stdev(mses), min(mses), max(mses)))

# 5折交叉验证: 每折都当一次验证
def kfold(k=5, seed=0):
    r = np.random.default_rng(seed)
    idx = r.permutation(N)
    folds = np.array_split(idx, k)
    mses = []
    for i in range(k):
        te = folds[i]
        tr = np.concatenate([folds[j] for j in range(k) if j != i])
        mses.append(fit(X[tr], y[tr], X[te], y[te]))
    return mses

for seed in [0, 1, 2]:
    mses = kfold(5, seed)
    print(f"5折CV seed={seed}: 每折MSE={[round(m,4) for m in mses]} 均值={mean(mses):.4f} 标准差={stdev(mses):.4f}")

实跑输出（节选）：

单次切分 10个种子 MSE: 均值=0.8134 标准差=0.2533 范围=[0.3139, 1.1795]
5折CV seed=0: 每折MSE=[1.0476, 0.6213, 0.6956, 0.8615, 0.7142] 均值=0.7880 标准差=0.1692
5折CV seed=1: 每折MSE=[0.9989, 0.6144, 0.459, 0.7678, 0.727] 均值=0.7134 标准差=0.1995

怎么读：单次切分 10 个种子的 MSE 范围 [0.31, 1.18]（差 3.7 倍），标准差 0.25；5 折 CV 的均值更稳（0.71~0.79），每折标准差 0.14~0.20。单次切分的指标可能高估或低估模型能力，小样本必须用 K 折 CV 汇报均值±标准差。工程判据：样本 <1000 用 5~10 折 CV；样本充足时用固定验证集+多次随机种子训练取均值。

CNN 训练的评估注意：CNN 训练成本高，完整 K 折 CV 可能不现实。替代方案：固定验证集，训练 3~5 个随机种子的模型，汇报均值±标准差；或用"早停监控验证集 loss 趋势"代替单点指标（趋势稳定比单点数字更可信）。

import numpy as np

# numpy 手写卷积/池化: im2col + 互相关
def conv2d(x, k, stride=1, pad=0):
    # x: (H, W), k: (kh, kw) —— 2D 互相关(深度学习惯例,不做翻转)
    H, W = x.shape
    kh, kw = k.shape
    xp = np.pad(x, pad)
    Ho = (H + 2 * pad - kh) // stride + 1
    Wo = (W + 2 * pad - kw) // stride + 1
    out = np.zeros((Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            patch = xp[i * stride:i * stride + kh, j * stride:j * stride + kw]
            out[i, j] = (patch * k).sum()
    return out

def maxpool2d(x, size=2, stride=2):
    H, W = x.shape
    Ho = (H - size) // stride + 1
    Wo = (W - size) // stride + 1
    out = np.zeros((Ho, Wo))
    for i in range(Ho):
        for j in range(Wo):
            out[i, j] = x[i * stride:i * stride + size, j * stride:j * stride + size].max()
    return out

什么情况下用？ 输入是网格结构（图像、频谱图、2D 时频图），有局部相关性和平移不变性，样本量不足以训 ViT 时。图像分类、目标检测、语义分割的默认起点。微调场景：冻结预训练 CNN 主干，只重训末端全连接（或加低秩适配），是数据量有限时的稳定方案。

什么情况下别用？ 输入是一维序列且长距离依赖强（用 Transformer/RNN）；输入是表格特征无空间结构（用树模型 XGBoost/LightGBM）；数据量 >100 万且算力充足、需要长距离建模或统一多模态架构（用 ViT/Transformer）；要求严格可解释性（CNN 是黑盒，需 Grad-CAM 等事后解释工具补救）。

翻车长什么样？ 五种高频形态（每种都给了症状→根因→改法）：感受野不足（只看局部判错大局→加深/池化/空洞卷积）、初始化对称（核输出全同→随机初始化 He）、padding 伪影（边缘响应异常→reflect padding/valid 卷积）、stride 过大（小目标丢失→前层保持 stride=1/FPN 多尺度）、池化尺寸不匹配（shape 崩溃→先算输出尺寸公式）。写 CNN 代码前先用 §4.1 公式算清每层感受野和输出尺寸，能省掉大半 shape 调试时间。
