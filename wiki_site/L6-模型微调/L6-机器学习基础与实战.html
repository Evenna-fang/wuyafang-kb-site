L6 机器学习基础与实战

本文不按算法名词逐篇堆叠，而按“问题定义—数据切分—特征处理—基线—候选模型—诊断—交付”组织。它在 L6 中有两个用途：一是为分类、回归、聚类等下游任务建立可复现的传统基线；二是把数据泄漏、错误指标和预处理错配挡在大模型微调之前。所有代码与实验均为示例，未实跑，不沿用旧稿的本机分数、耗时或固定阈值。

大模型训练入口见《L6-模型微调-2026.md》，神经网络训练稳定性见《L6-损失优化与训练稳定性.md》。

大模型微调并不消除机器学习的基本问题。标签是否有噪声、同一用户是否同时出现在训练集和验证集、评分是否被多数类主导、预测时点是否真的能获得某字段，这些问题在逻辑回归、XGBoost 和 LoRA 中同样存在。模型越大，越可能把数据中的偶然相关和泄漏学得很熟；训练 loss 下降不能替代泛化验证。

传统机器学习对 L6 的直接价值有三层：

  1. 建立下界与对照：如果一个正则化线性模型已经解决表格分类，就没有必要默认微调 LLM。反之，传统基线失败也要先区分是表示不足、数据不足还是切分错误，不能据此直接证明“必须上大模型”。
  2. 复用实验纪律：训练/验证/测试分工、按时间或实体切分、预处理只在训练折拟合、指标服从业务代价，这些规则可直接迁移到 SFT 和偏好优化。
  3. 承担辅助任务：微调数据去重前可做聚类与降维，标注质量可做噪声诊断，推理日志可训练轻量分类器，线上路由可比较传统模型与生成模型的成本和效果。

本篇因此不追求算法百科全书，而要求能回答四个问题：预测对象是什么，评估是否可信，哪个模型假设与数据匹配，失败后如何回退。

1. 先按问题选模型，而不是先背算法3 个重点▾ 点开看本节重点
本节重点
  • 输出连续数值，是回归；输出离散类别，是分类；没有标签、希望发现结构，才考虑聚类；希望压缩或可视化表示，才考虑降维
  • 排序、异常检测、推荐、时间序列预测不能只靠改一个 estimator 名称完成，还需专用目标、切分和指标
  • “输入一段文本”并不自动等于要微调 LLM
3

第一步看输出和监督信号：

  • 输出连续数值，是回归；输出离散类别，是分类；没有标签、希望发现结构，才考虑聚类；希望压缩或可视化表示，才考虑降维。
  • 排序、异常检测、推荐、时间序列预测不能只靠改一个 estimator 名称完成，还需专用目标、切分和指标。
  • “输入一段文本”并不自动等于要微调 LLM。短文本分类可先用 TF-IDF 加线性模型或朴素贝叶斯；生成、开放域指令遵循和复杂上下文任务才更直接指向生成模型。

第二步检查数据结构：样本是否独立，是否有时间顺序，是否按用户/患者/设备分组，特征是否稀疏，标签是否不平衡，线上是否需要概率和解释。第三步才建立简单基线，再让复杂模型在同一数据和同一切分上证明收益。

一个稳健的顺序通常是：

  1. 多数类、均值或业务规则等朴素基线；
  2. 正则化线性回归/逻辑回归，或适合文本的朴素贝叶斯；
  3. 随机森林或梯度提升树作为表格强基线；
  4. 有明确理由时再试核 SVM、KNN、深度模型或大模型微调。

“通常”不是排行榜。最终选择要看验证集表现、数据假设、训练与推理成本、校准、可维护性和失败代价。

2. 线性回归与逻辑回归：可解释的基线

3

线性回归用 ŷ = wᵀx + b 拟合连续标签，最小二乘目标最小化平方误差。它适合关系近似线性、需要快速基线和系数解释的场景。MSE 对大误差敏感，异常值可能显著改变系数；共线特征会使系数方向和大小不稳定。Ridge 加 L2 收缩，Lasso 加 L1 惩罚并可能产生稀疏系数，Elastic Net 组合两者。

系数解释必须带单位与条件：原始系数表示其他列不变时，某列增加一个单位对应的预测变化；标准化后的系数表示特征变化一个训练集标准差时的变化。不能把相关模型的系数直接说成因果效应，也不能跨不同量纲比较原始系数绝对值来宣布“最重要特征”。

逻辑回归虽名为回归，实质是分类器。二分类时先算线性 logit，再经 sigmoid 得到正类概率：

[
p(y=1\mid x)=\sigma(w^Tx+b),\qquad \sigma(z)=\frac{1}{1+e^{-z}}
]

训练通常最小化对数损失。它适合需要快速、可解释、可输出分数的分类基线。多分类可由具体 solver 与多类策略支持，使用前应查当前 scikit-learn 文档，不沿用旧版本参数记忆。

逻辑回归的默认决策阈值不是不可更改的自然常数。阈值应按验证集上的误报/漏报代价选择，并作为模型配置一起版本化。ROC-AUC 衡量排序，概率是否反映真实频率则要另看校准；高 AUC 不保证某个阈值下的业务表现，也不保证概率校准良好。

3. 决策树、随机森林与 XGBoost：三种不同的树范式3 个重点▾ 点开看本节重点
本节重点
  • 决策树递归选择特征和切分点，让子节点更纯
  • 原论文的核心之一是对损失做二阶近似并加入正则化
  • 固定树结构时，一个叶子的最优权重可写成 「-G/(H+λ)」，体现二阶项与 L2 正则对更新步长的共同约束
3

决策树递归选择特征和切分点，让子节点更纯。分类可用基尼不纯度或熵，回归常看节点内平方误差。树能表达非线性和特征交互，单棵树可导出规则，但不受约束时容易把噪声切进叶节点。max_depth、min_samples_leaf 等用于控制容量，具体值由交叉验证而非通用阈值决定。树模型按阈值分裂，通常不要求标准化；这不代表它们不需要处理缺失、类别编码和泄漏。

随机森林对样本做 bootstrap，并在分裂时引入特征随机性，训练多棵较去相关的树，再投票或平均。它主要通过集成降低方差，常是表格数据的实用基线。袋外估计可提供辅助诊断，但不能在时间、分组或泄漏要求下机械替代正确的独立验证。

树的不纯度重要性可能偏向可切分点多的特征，也会受相关特征影响。置换重要性更接近“打乱该列后性能损失”，但仍不是因果解释，且相关特征之间会分摊或掩盖效果。

XGBoost属于梯度提升树：新树逐步修正当前集成的损失，而不是像随机森林那样独立种树。原论文的核心之一是对损失做二阶近似并加入正则化。对第 t 棵树，可概念化为：

[
Obj^{(t)}\approx\sum_i\left[g_i f_t(x_i)+\frac12h_i f_t(x_i)^2\right]+\Omega(f_t)
]

其中 g_i、h_i 是当前预测处的一阶、二阶导数，正则项包含叶节点数量与叶权重惩罚。固定树结构时，一个叶子的最优权重可写成 -G/(H+λ)，体现二阶项与 L2 正则对更新步长的共同约束。

工程上调参要理解耦合：学习率和树数量共同决定拟合程度，树深、子节点约束、行/列采样和正则共同影响容量。early stopping 使用的数据也参与模型选择，不能再把同一数据当完全未见测试集。XGBoost 适合结构化表格，不代表在原始文本、图像或所有稀疏任务上必然优于其他方法。

4. SVM、KNN 与朴素贝叶斯：假设决定适用边界

3

支持向量机寻找间隔较大的分类边界。软间隔用 C 控制间隔与训练违例之间的权衡；核方法通过内积隐式表达非线性特征映射，RBF 核可拟合弯曲边界。SVM 可在中小规模、高维或边界复杂的任务上表现良好，但核 SVM 的训练和存储成本随样本增长可能成为瓶颈。距离与内积受量纲影响，预处理和模型应放进同一 Pipeline。需要概率时，不能直接把 decision function 当概率，应使用有独立验证的校准流程。

KNN是惰性学习：训练时主要保存数据，预测时找最近邻，分类投票、回归平均。它适合低维、距离确有语义、需要局部方法基线的问题。k 小会更敏感，k 大会更平滑，应交叉验证选择。高维空间中距离对比可能减弱，大量样本又会增加预测成本，因此“训练很快”不等于“线上便宜”。KNN、KMeans 和 RBF-SVM 都应重点检查缩放。

朴素贝叶斯由贝叶斯公式和特征条件独立假设得到：

[
P(y\mid x)\propto P(y)\prod_jP(x_j\mid y)
]

它训练快、参数少，适合文本计数等基线。MultinomialNB 面向计数型特征，BernoulliNB 面向二值出现/不出现，GaussianNB 面向连续特征并采用高斯假设。拉普拉斯等平滑用于避免未见特征导致零概率。条件独立不成立时，相关或重复特征可能重复计证，使概率过度自信；分类仍可能可用，但概率不能直接当真。要精确概率时另做校准评估。

5. KMeans 与 PCA：无监督不等于无需验证3 个重点▾ 点开看本节重点
本节重点
  • KMeans最小化簇内平方距离，交替执行“分配到最近质心”和“用簇均值更新质心”
  • 它隐含依赖欧氏距离与均值，较适合尺度协调、近似凸且分离的簇
  • k 需预先给定，初始化可能影响局部解；可用多次初始化、簇内误差曲线、轮廓系数和稳定性辅助选 k，但不存在脱离业务语义的“最佳簇数”
3

KMeans最小化簇内平方距离，交替执行“分配到最近质心”和“用簇均值更新质心”。它隐含依赖欧氏距离与均值，较适合尺度协调、近似凸且分离的簇。k 需预先给定，初始化可能影响局部解；可用多次初始化、簇内误差曲线、轮廓系数和稳定性辅助选 k，但不存在脱离业务语义的“最佳簇数”。非凸簇、密度差异大或噪声明显时，应考虑密度、层次或谱聚类等其他假设。

聚类结果不能直接用分类 accuracy 评价。没有外部标签时可看 silhouette 等内部指标、不同抽样下稳定性和业务可解释性；有可信标签时才可辅以 ARI 等外部一致性指标。内部指标高不等于簇有业务价值。

PCA对中心化数据寻找方差最大的正交方向，可用 SVD 计算。它用于压缩、去相关、可视化和某些模型的前置降维。解释方差比说明保留了多少原始线性方差，不说明保留了多少标签判别信息；小方差方向也可能恰好区分类别。因此，监督任务中 PCA 必须和后续模型一起放进交叉验证 Pipeline，以最终任务指标选择维数，不能只看累计解释方差。稀疏高维数据还要考虑稠密化成本，可评估 TruncatedSVD 等适用工具。

6. 特征工程：让信息可用，同时挡住未来信息

3

数值特征：先查分布、异常值和单位，再决定变换。标准化把训练集均值和标准差用于缩放，适合许多距离或梯度模型；MinMax 缩放到固定区间，但会受极值影响；右偏非负变量可评估 log1p，分箱可表达分段效应。树模型通常不需要标准化，但 log、比值等有业务含义的变换仍可能帮助表达。任何统计量都只从训练折估计。

类别特征：无序类别常用 one-hot，避免虚构数值顺序；有序类别可按真实顺序编码，但间距是否有意义仍需说明。高基数类别会造成维度与稀疏性问题，可考虑合并稀有类、哈希、嵌入或目标编码。目标编码使用标签，必须采用严格的折外/时间安全策略，不能拿全量标签均值填训练与测试。

缺失值：先问为什么缺失，再选删除、均值/中位数/众数填充或增加缺失指示。完全随机缺失、与已观测变量相关缺失、与未观测因素相关缺失的影响不同，不能用一个缺失率阈值决定所有项目。线上预测时必须能执行同样策略，训练时“删掉缺失行”并不意味着线上也能删掉请求。

交互与构造：比值、时间差、滚动统计和领域规则往往比无脑全量多项式更可解释。构造前写清“预测时点是否可得”：事后处理结果、未来聚合、由标签生成的字段都属于高风险。滚动特征只使用当前时点之前的数据，窗口计算也要防止跨边界污染。

7. Pipeline 与数据切分：防泄漏要靠结构3 个重点▾ 点开看本节重点
本节重点
  • scikit-learn 的 Pipeline 把预处理和估计器串为一个对象；ColumnTransformer 可对不同列施加不同工序
  • 调用 「fit」 时，每一步只从传入的训练数据学习统计量；在交叉验证中，应把整个 Pipeline 交给 CV，使每个训练折独立 fit，再 transform 对应验证折
  • 独立同分布样本：可用随机切分；分类且类别不平衡时考虑分层切分
3

scikit-learn 的 Pipeline 把预处理和估计器串为一个对象；ColumnTransformer 可对不同列施加不同工序。调用 fit 时，每一步只从传入的训练数据学习统计量；在交叉验证中，应把整个 Pipeline 交给 CV，使每个训练折独立 fit，再 transform 对应验证折。

切分方式服从样本生成过程：

  • 独立同分布样本：可用随机切分；分类且类别不平衡时考虑分层切分。
  • 时间任务：训练集早于验证/测试集，可用时间顺序切分或 TimeSeriesSplit；随机 shuffle 会把未来信息带入训练。
  • 同实体多条记录：用 GroupKFold 等保证同一用户、患者或设备不跨训练与验证，避免模型靠识别实体得分。
  • 既有时间又有分组：只满足一个条件不够，需设计同时尊重时间和实体的切分，并核对每个折的覆盖与标签分布。

测试集应尽量只用于最终评估。反复根据测试分数选模型、阈值或特征，会把测试集变成训练过程的一部分。交叉验证的均值也要结合折间波动、数据规模和业务切片理解，不能把一个均值当确定保证。

8. 指标：从错误代价出发

3

分类先给混淆矩阵，再看指标：

  • precision 关注预测为正的样本中有多少正确，recall 关注真实正例找回多少，F1 平衡二者；
  • macro 平均让各类权重更均衡，weighted 按支持度加权，类别不平衡时 accuracy 可能掩盖少数类失败；
  • ROC-AUC 看排序，PR 曲线/PR-AUC 在正例稀少时常更贴近正类表现；
  • log loss、Brier score 和校准图评价概率质量，不能只靠 argmax 指标替代。

回归中，MAE 与标签同单位且较直观；RMSE 更重罚大误差；R² 相对均值基线描述解释程度，在分布变化或数据范围很窄时需谨慎解释。含零或近零标签时，MAPE 可能失真。必要时应按业务区间、时间和实体分组报告，而不是只报全量平均。

聚类没有统一 accuracy。内部指标、外部标签一致性、重采样稳定性和下游业务价值分别回答不同问题。降维则同时看重构/解释方差和最终下游任务，不能将二者混为一谈。

import numpy as np
import pandas as pd

from sklearn.compose import ColumnTransformer

from sklearn.model_selection import train_test_split

from sklearn.preprocessing import OneHotEncoder, StandardScaler

rng = np.random.default_rng(42)
n = 120
df = pd.DataFrame({
    "age": rng.integers(18, 70, n).astype(float),
    "usage_days": rng.integers(0, 365, n).astype(float),
    "monthly_fee": rng.normal(100, 30, n),

df["target"] = rng.binomial(1, prob)

# 人为制造输入缺失；标签不制造缺失
for col in ["age", "monthly_fee", "region"]:
    df.loc[rng.choice(n, size=8, replace=False), col] = np.nan

X = df.drop(columns="target")
y = df["target"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

numeric = ["age", "usage_days", "monthly_fee"]
categorical = ["region", "plan"]
num_pipe = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler()),
])
cat_pipe = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("onehot", OneHotEncoder(handle_unknown="ignore")),
])
preprocess = ColumnTransformer([
    ("num", num_pipe, numeric),
    ("cat", cat_pipe, categorical),
])
model = Pipeline([
    ("preprocess", preprocess),
    ("classifier", LogisticRegression(max_iter=1000)),
])

# fit 只接触训练集；测试集统计量不参与预处理学习
model.fit(X_train, y_train)
pred = model.predict(X_test)
prob_test = model.predict_proba(X_test)[:, 1]

print(confusion_matrix(y_test, pred))
print(classification_report(y_test, pred, zero_division=0))
print("ROC-AUC:", roc_auc_score(y_test, prob_test))
print("输出特征:", model.named_steps["preprocess"].get_feature_names_out())

  1. 写任务卡：明确一行数据代表什么、何时预测、标签何时产生、哪些字段线上可得。
  2. 冻结切分：先按时间/实体规则生成训练、验证、测试清单，再做任何用全量统计的特征工程。
  3. 跑朴素基线：多数类、均值或现有业务规则，给复杂模型一个比较下界。
  4. 跑简单 Pipeline：线性/逻辑回归；文本增加 TF-IDF+NB 或线性模型；表格增加 RF/XGBoost 候选。
  5. 同尺比较：所有模型复用相同折与主指标，同时记录训练/推理成本、概率、解释和失败切片。
  6. 只调有希望的候选：控制搜索预算，把整个 Pipeline 放进 CV；保存参数、折号、数据版本和随机种子。
  7. 最终测试与交付：选定后只在测试集做最终评估，保存完整 Pipeline、阈值、特征顺序、模型卡和回退版本。

产物：切分清单、基线表、每折结果、主辅指标、错误样本、最终 Pipeline、配置快照和回退说明。
验证：随机种子变化时结果是否稳定；分组是否跨折；时间是否倒置；线上特征是否与训练同口径；固定样例重载后是否一致。
