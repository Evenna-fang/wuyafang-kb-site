深度学习、Transformer 与训练稳定性

本文把神经网络、CNN、Transformer、损失函数与优化器放进同一条微调链路：文本如何变成张量，张量如何前向与反向传播，Decoder-only 模型如何改写表示，以及 loss、梯度、混合精度和 LoRA 挂接怎样验收。所有代码与实验均为示例，未实跑；旧稿中的本机指标不沿用。

微调主流程见预训练/CPT/SFT，低秩公式、显存成本与合并见LoRA/QLoRA，分布式 OOM 见框架与分布式。

WHY3 个重点▾ 点开看本章重点
本章重点
  • L6 微调不是“把 JSON 交给 Trainer 后等 loss 下降”
  • 3. 理解为什么能微调而不是重训：预训练已经提供通用表示；LoRA 冻结主干，只学习选定线性层的低秩增量，减少可训练参数与优化器状态
  • 4. 把故障定位到层：注意力 mask 错、归一化维度错、激活尺度失控和过拟合是不同问题，不能用“再训练几轮”统一处理
2

L6 微调不是“把 JSON 交给 Trainer 后等 loss 下降”。数据要先经 Tokenizer 变成 input_ids，再经 Embedding 变成连续向量；每个 Transformer block 通过注意力与前馈网络更新这些向量；监督微调再用目标 token 的交叉熵产生梯度，更新全部参数或少量适配参数。任何一个环节错位，都可能表现为 loss 不降、输出乱码、显存溢出或训练集全对而验证集无效。

基础理论在这里承担四个实际任务：

  1. 对齐数据与模型：理解 token、序列长度、隐藏维数和 batch 维，才能发现 padding、标签平移和词表不一致。
  2. 判断模型是否真的在学习：前向只说明能算出结果，反向梯度非零、有限且到达目标参数，才说明训练链路接通。
  3. 理解为什么能微调而不是重训：预训练已经提供通用表示；LoRA 冻结主干，只学习选定线性层的低秩增量，减少可训练参数与优化器状态。
  4. 把故障定位到层：注意力 mask 错、归一化维度错、激活尺度失控和过拟合是不同问题，不能用“再训练几轮”统一处理。

CNN 不是 Decoder-only LLM 的必备组成，但它提供了理解“归纳偏置”的对照：局部连接和权值共享把图像先验写入结构；标准自注意力则用内容相关的全局交互换取灵活性。多模态系统中，视觉编码器与语言模型也可能采用不同归纳偏置，因此不能把某套视觉经验直接套到文本微调上。

WHAT

1. 从标量到计算图：微调在更新什么3 个重点▾ 点开看本节重点
本节重点
  • 张量是带 shape 和 dtype 的多维数组
  • 注意力权重：单头时为 「[B, T, T]」，多头时常写为 「[B, H, T, T]」
  • 计算图也解释显存消耗：不仅权重占显存，注意力分数、激活、梯度和优化器状态都可能占显存
3

张量是带 shape 和 dtype 的多维数组。标量没有轴，向量是一维，矩阵是二维；Transformer 中常见的隐藏状态是三维张量：

  • input_ids: [B, T]，B 为 batch 大小，T 为序列长度，元素是词表中的整数 ID。
  • token 隐藏状态 X: [B, T, D]，D 为隐藏维数。
  • 注意力权重：单头时为 [B, T, T]，多头时常写为 [B, H, T, T]。
  • 输出 logits: [B, T, V]，V 为词表大小。

这些名称只是约定，实际框架可能合并 batch 与序列轴，或把多头维放在不同位置。可靠做法不是死记布局，而是阅读模型实现并打印一次 shape。尤其不要把 [B, T, D] 误当成 [T, B, D] 后仍继续训练：有些矩阵乘法恰好能执行，却会静默地算错对象。

计算图把前向运算记录为有向无环图。节点是矩阵乘法、激活、归一化、掩码、求和等算子，边是张量。前向时保存反向所需中间值，反向时按逆拓扑顺序应用链式法则。若标量损失为 L，则对任意参数 θ 求 ∂L/∂θ，优化器再按学习率和自身状态更新参数。

一个最小训练步是：

  1. 清上一步梯度；
  2. 前向得到 logits；
  3. 只对允许计算损失的位置求标量 loss；
  4. backward() 沿图求梯度；
  5. 可选地做梯度裁剪；
  6. optimizer.step() 更新参数，scheduler.step() 调整学习率。

计算图也解释显存消耗：不仅权重占显存，注意力分数、激活、梯度和优化器状态都可能占显存。冻结参数可减少其梯度与优化器状态，但若前向仍经过主干，中间激活并不会自动全部消失。

2. 前向、反向与损失：先确认优化对象

3

对一层线性映射 Z = XW + b，若 X 为 [N, D]、W 为 [D, H]，则 Z 为 [N, H]。非线性激活使多层网络不再等价于单个线性变换。反向传播仍遵循链式法则，例如 ReLU 的负区梯度为零，正区梯度为一。

语言模型通常学习下一 token 条件分布。对位置 t 的 logits，softmax 为：

[
p_{t,v}=\frac{\exp(z_{t,v})}{\sum_{u=1}^{V}\exp(z_{t,u})}
]

训练使用交叉熵，而不是 accuracy，因为 accuracy 不可提供有用的连续梯度。数值实现要采用框架的稳定交叉熵或 log-sum-exp，不要手写 log(softmax(z)) 后随意加一个很大截断常数。

因果语言模型的输入与标签通常错开一个位置：根据截至 t 的上下文预测 t+1。很多因果模型内部已经处理 logits 与 labels 的平移，重复手动 shift 会再错一位；也有底层实现要求调用者自己 shift。必须查所用模型接口，并用一个人工短序列验证，不能凭框架名猜。

损失掩码决定哪些位置参与训练。padding 一般不应计损；指令微调还可能只训练回答部分，把 prompt 对应标签设为忽略值。忽略值取什么由损失接口规定，例如 PyTorch 常见接口默认 -100，但使用前应查当前版本文档。

3. 激活、初始化与归一化：让深层网络可训练3 个重点▾ 点开看本节重点
本节重点
  • Sigmoid：输出在 0 与 1 之间，适合门控或二分类概率；两端饱和时梯度很小，不宜不加判断地堆在深层隐藏层
  • Tanh：输出零中心，也会在大绝对值区域饱和
  • ReLU：正区梯度不饱和，但负区为零，部分单元可能长期失活
3

常见激活的职责不同：

  • Sigmoid：输出在 0 与 1 之间，适合门控或二分类概率；两端饱和时梯度很小，不宜不加判断地堆在深层隐藏层。
  • Tanh：输出零中心，也会在大绝对值区域饱和。
  • ReLU：正区梯度不饱和，但负区为零，部分单元可能长期失活。
  • GELU：平滑门控式激活，许多 Transformer 使用前馈网络采用它或其变体。具体模型也可能使用 SwiGLU 等门控结构，不能把所有模型都写成同一种 FFN。

初始化的目标是打破对称并控制前向激活、反向梯度的尺度。全零初始化会让同类隐藏单元获得相同梯度，无法分工。Xavier/Glorot 与 He 初始化分别从不同激活与方差假设出发，但预训练微调通常继承已有初始化；真正需要谨慎的是新加的 LoRA 分支和任务头。LoRA 常让一条低秩分支从零附近开始，使初始增量接近零，避免一开始破坏预训练表示。

归一化要与维度对齐。BatchNorm 使用 batch 统计量，训练与推理行为不同；LayerNorm 通常在单个 token 的隐藏特征维上归一化，不依赖同 batch 其他样本，适合变长序列和 Transformer。其形式可写为：

[
\operatorname{LN}(x)=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta
]

其中均值和方差沿约定的特征轴计算，γ、β 可学习。若误沿 batch 或序列轴归一化，样本之间会相互影响，训练和推理也可能不一致。

Transformer 有 Pre-LN 与 Post-LN 等结构差异。Pre-LN 在子层前归一化，残差主路较直接；Post-LN 在残差相加后归一化。排查模型时必须按实际实现画 block，不要把一张通用图当成所有 LLM 的真实结构。

4. CNN：局部性、权值共享与归纳偏置

3

二维卷积在深度学习框架中通常实现为互相关：一个小卷积核在局部窗口滑动并做加权求和。输入高宽为 H、W，核大小为 k，步长为 s，单边填充为 p 时，一个空间维的输出大小为：

[
\left\lfloor\frac{H+2p-k}{s}\right\rfloor+1
]

多通道卷积的参数量约为 k_h × k_w × C_in × C_out，另加偏置。关键不在公式记忆，而在两种结构先验：

  • 局部性：一个输出单元先只看附近区域，深层再逐步扩大感受野。
  • 权值共享：同一个核在所有位置复用，参数量不随空间位置数线性增长，并带来平移等变性质。

这与标准全注意力形成对照。卷积默认“邻近位置更相关、同一模式可在不同位置复用”；自注意力不预先限定邻域，而是由 Q、K 内容计算每对位置的权重。由此不能直接推出“CNN 一定适合小数据、Transformer 一定更好”：结果还取决于预训练、数据规模、增强、算力、分辨率和任务结构。归纳偏置的正确用法是提出待验证假设，不是替代同数据对照实验。

对微调的启发是：结构先验影响优化与泛化，参数高效微调则是在已有结构上加约束。冻结 CNN 主干只训练任务头，与冻结 LLM 主干只训练 LoRA，都利用预训练表示，但挂接位置、训练目标和评估方式并不相同。

5. 文本入口：Tokenizer、Embedding 与位置表示3 个重点▾ 点开看本节重点
本节重点
  • Tokenizer 把字符串映射为 token ID
  • 没有位置机制时，纯自注意力对输入排列本身不提供类似 RNN 的先后归纳偏置
  • 它们的数学和外推行为不同，本文只要求统一原则：微调时沿用基座位置机制与上下文配置，不把一种模型的位置公式强套到另一种模型
3

Tokenizer 把字符串映射为 token ID。词、子词或字节级单元都是可能选择，BPE 类方法能用子词组合处理未登录词。微调时应遵守基座模型的 tokenizer、特殊 token、对话模板和最大长度，不要另训一个 tokenizer 后仍直接复用原 Embedding 与输出词表。

数据侧至少检查：

  1. input_ids 全在词表范围内；
  2. padding 与真实 token 不混淆；
  3. attention_mask 中 1/0 的语义与模型接口一致；
  4. BOS、EOS、角色分隔符与训练时模板一致；
  5. 截断是否切掉回答或 EOS；
  6. 训练、验证和推理使用同一模板版本。

Embedding 把离散 ID 查表为连续向量。若 ID 矩阵是 [B, T]，Embedding 输出就是 [B, T, D]。它不是把字符串直接做数值编码，也不是固定不变的“词义数据库”；预训练和微调都可改变向量及其后续使用方式。

位置表示补足顺序信息。没有位置机制时，纯自注意力对输入排列本身不提供类似 RNN 的先后归纳偏置。原始 Transformer 使用正弦位置编码，也讨论可学习位置嵌入；后续模型可采用 learned absolute position、RoPE、ALiBi 或其他相对位置方案。它们的数学和外推行为不同，本文只要求统一原则：微调时沿用基座位置机制与上下文配置，不把一种模型的位置公式强套到另一种模型。

6. 自注意力：公式、shape 与复杂度

3

对隐藏状态 X，通过可学习线性映射得到：

[
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
]

缩放点积注意力为：

[
\operatorname{Attention}(Q,K,V)=
\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V
]

其中 d_k 是每个注意力头的键维数，M 是可选掩码。除以 √d_k 是为避免维数增大时点积尺度过大，使 softmax 过度饱和。softmax 沿被关注的 key 轴归一化，每个 query 对应一行的权重和为 1。

标准稠密注意力要形成 query-key 配对，序列维上的时间和注意力分数存储随 T² 增长；对 V 加权求和也涉及序列二次项。说“Transformer 是 O(T²)”时必须限定是标准全注意力的序列维复杂度，不是整个模型所有计算的完整复杂度。线性投影和 FFN 仍与 T 及隐藏维相关，实际实现还可能用 FlashAttention 等方式减少中间矩阵物化与显存访问，但不等于任意长度都无成本。

多头注意力把表示分到 H 个头，分别学习注意力，再拼接并做输出投影：

[
\operatorname{MultiHead}(Q,K,V)=
\operatorname{Concat}(head_1,\ldots,head_H)W_O
]

多头的意义是让不同子空间学习不同关系，不是简单把同一个头复制 H 次。常见设置为 D = H × d_k，但应以具体模型配置为准。

因果 mask 在 Decoder-only 自回归训练中禁止位置 t 关注未来位置 j>t。常在 softmax 前把禁止位置加为负无穷或足够小的掩码值。因果 mask 与 padding mask 不是一回事：前者防未来信息，后者忽略补齐位置；二者常需同时正确处理。 Encoder 双向表示、Decoder-only 因果表示和 Encoder-Decoder 交叉注意力的可见范围也不同。

7. Decoder-only block：残差、LayerNorm 与 FFN3 个重点▾ 点开看本节重点
本节重点
  • 最后经归一化和输出投影得到词表 logits
  • 实际模型可能使用 RMSNorm、旋转位置编码、分组查询注意力或门控 FFN；上图用于说明数据流，不冒充所有模型的逐行实现
  • FFN在每个 token 位置独立做非线性变换，注意力负责跨位置混合，FFN 负责位置内的特征变换
3

一个概念化的 Pre-LN block 可写成：

[
H'=H+\operatorname{MHA}(\operatorname{LN}(H))
]

[
Y=H'+\operatorname{FFN}(\operatorname{LN}(H'))
]

最后经归一化和输出投影得到词表 logits。实际模型可能使用 RMSNorm、旋转位置编码、分组查询注意力或门控 FFN；上图用于说明数据流，不冒充所有模型的逐行实现。

残差连接保留直接信息通路，也提供较直接的梯度通路，缓解深层堆叠的优化困难。LayerNorm控制子层输入尺度。FFN在每个 token 位置独立做非线性变换，注意力负责跨位置混合，FFN 负责位置内的特征变换。二者不能互相替代。

Decoder-only 训练可并行计算整段序列各位置的下一 token 损失，因为因果 mask 阻止未来泄漏；自回归推理则通常逐 token 生成，并可用 KV cache 复用历史键值。不要把“训练可并行”误写成“生成也一次全部并行完成”。

8. LoRA 挂接位置与训练稳定性

3

对预训练线性映射 Y = XW，LoRA 冻结 W，学习低秩增量：

[
Y=XW+sXBA
]

若 W ∈ R^{D_out×D_in}，则 A ∈ R^{r×D_in}、B ∈ R^{D_out×r}，r 远小于相关维度，s 是由实现与配置决定的缩放。具体矩阵方向可能因框架而异，验收应看实际参数 shape，而不是背 A、B 谁在前。

常见挂接对象是注意力的 q/k/v/o 投影，也可覆盖 FFN 的上、下投影或门控投影。没有跨模型通用的“最佳 target_modules”：模块名、结构和任务不同。选完后必须打印命中模块和可训练参数，确认没有因名称不匹配而零挂接，也没有误把 Embedding、LayerNorm 或输出头纳入计划。

训练稳定性至少看四组信号：

  • shape：batch、序列、头数、隐藏维、词表维是否逐层一致；
  • 数值：loss 和梯度是否出现 NaN/Inf，softmax 行是否有效，混合精度是否需调整；
  • 优化：目标参数是否收到非零梯度，冻结参数是否保持 requires_grad=False，学习率调度是否生效；
  • 泛化：训练 loss 下降时验证 loss、任务样例和通用能力是否同步改善。

小样本过拟合检查应在正式训练前做：取极少且标签明确的样本，看模型能否拟合。如果连小集合都无法拟合，优先查数据、mask、标签平移、冻结范围和优化器；如果能迅速记住训练集但验证无改善，再查数据覆盖、正则、训练轮数与评估切分。这个测试只证明训练链路能记忆，不证明模型有泛化能力。

9. 交叉熵、AdamW 与更新尺度：四组职责不要混用

3

训练不稳定时，直接换优化器或把学习率除以十，往往只把故障推迟。先把职责拆开：损失函数决定优化什么；优化器决定如何利用梯度；学习率调度、weight decay、梯度裁剪分别控制步长曲线、参数正则和异常梯度；结构与数值精度决定梯度传播和溢出风险。

对目标 token 的交叉熵为 L_t=-log p_theta(y_t|x_<t)。模型输出 logits，不应先手动 softmax 再交给已包含稳定数值处理的交叉熵。因果语言模型存在一位位移，但高层模型通常内部完成；自写 collator 时必须明确由谁 shift，避免重复位移。真正常见的微調错误是监督范围：prompt、padding 和工具返回可设为 -100，目标回答及需要学习的 EOS 保留。若整个 batch 都是 -100，不是“收敛慢”，而是没有有效训练目标。

Adam 为每个参数维护一阶矩和二阶矩估计；AdamW 将 weight decay 从梯度中的 L2 项解耦。它是 Transformer 微调的常见起点，不会修复错误标签。几个超参不能互相替代：

  • 学习率控制步长；LoRA 与全参不能直接共用所谓标准值。
  • warmup按优化器更新步逐步放开学习率，不是按梯度累积的微批次计数。
  • 调度器决定 warmup 后的衰减曲线；总更新步数改变后要重算。
  • weight decay约束部分权重增长，不等于梯度裁剪，也不等于简单给 loss 加同一个 L2 项。
  • 梯度裁剪处理异常大梯度，不能治疗空标签、过小学习率或深层梯度消失。

小实验可围绕当前稳定值 lr0 比较 0.3×lr0、lr0、3×lr0，其他条件不变；这些倍数只是诊断起点，不是通用搜索空间。裁剪阈值先看不裁剪基线的 pre-clip grad norm 分布，再选择只约束异常尾部的值；如果几乎每个 step 都强裁剪，可能长期欠拟合。

类别不平衡也不应一律换 Focal Loss。先修采样、切分和指标，再比较类别加权交叉熵或重采样；容易负例仍主导时才评估 Focal。任何改变目标的损失都要同时看少数类召回、多数类误报和概率校准。普通生成式 SFT 的词表频率不均，不等于要给所有稀有 token 加权。

10. 梯度消失、爆炸与混合精度：按最早异常分流

3

深层网络的上游梯度与一系列 Jacobian 连乘有关，尺度持续缩小会使前层几乎不学习，持续放大则可能出现 spike、Inf/NaN。残差连接提供直接梯度通路，LayerNorm/RMSNorm 稳定层内尺度，Xavier/He 初始化控制从头训练的前向与反向方差，ReLU/GELU 等影响饱和特性。它们不是“梯度永远正常”的保证；微调已有预训练主干时，更不能看到 NaN 就重新初始化整个模型。

症状 先取证据 有序处理
第一步或前几步 NaN/Inf 首个坏 batch、有效标签数、logits/loss、精度与 loss scale 固定坏 batch → FP32 小跑 → 查标签/数据 → 降 lr → 查内核
训练中偶发 loss spike spike 前后样本 ID、pre-clip norm、lr、长度 回放样本 → 缩小 batch/长度 → 调整裁剪/lr → 从好 checkpoint 恢复
loss 长期不降 有效 token、可训练参数、实际 optimizer step、分层梯度 先证明有标签、有梯度、有更新，再谈模型容量
前层几乎不动 各层梯度相对量级、冻结策略、LoRA 命中模块 先查 requires_grad 和挂接；从头训练再查结构与初始化
train loss 降、验证指标降 独立验证、重复样本、通用回归 回退数据与训练预算，按业务指标早停

FP16 表示范围较小，梯度可能上溢或下溢。动态 loss scaling 先放大 loss，反向后、裁剪前必须 unscale_，再检查非有限梯度；溢出时框架可能跳过更新并降低 scale。因此“loss 仍在打印”不证明参数每次都更新。BF16 指数范围更接近 FP32，通常不采用 FP16 式 GradScaler，但硬件和算子支持仍需核对。

FP32 对照是重要分流工具：同配置 FP32 仍 NaN，优先查数据、标签、学习率和模型；FP32 稳定而 FP16 NaN，优先查溢出、scale 和算子精度；单卡稳定而多卡 NaN，查各 rank 数据和最早失败 rank。禁止把 NaN 静默替换成零或无限跳过坏 batch 来制造“恢复”。

11. 本地论文：注意力改造与梯度归因的正确用法

3

ZHA（arXiv:2610.42112）在 KV cache 上构建递归压缩 key 摘要树，让 query 自顶向下检索稀疏 key 子集；摘要称包括路由与最终注意力在内达到次二次、但超线性的渐近复杂度，已有预训练模型需经过数十亿 token 的短 KL 蒸馏适配。我们怎么用：评估长上下文结构改造时，要把 indexer 成本、适配训练与最终任务回归一起计入，不能只看注意力的 Big-O。边界：百万上下文以上的优势主要来自性能模型，“数亿/数十亿 token”是潜力而非已验证能力，方法也不是 training-free。

CATT（arXiv:2610.40655）用虚构知识微调构造明确的数据归因真值，发现冗余和词汇干扰会降低归因效果；把交叉熵梯度换成 negative log-odds 梯度并只聚合 top token 分数，在其诊断基准上提高真值召回。我们怎么用：做训练数据排错时，不应机械平均整篇文档的 token 归因；可单独评估损失梯度和聚合方式。边界：negative log-odds 在这里是数据归因信号，不是建议替换 SFT 的交叉熵训练损失；合成事实上的增益不能无条件外推真实语料。

1. 最小多头因果注意力实验3 个重点▾ 点开看本节重点
本节重点
  • 目标：不加载大模型，用 NumPy 验证 Q/K/V、多头 reshape、因果 mask、padding mask 和输出 shape
  • 产物：注意力权重、输出和一组断言
  • return x.reshape(B, T, H, dk).transpose(0, 2, 1, 3)
3

目标：不加载大模型，用 NumPy 验证 Q/K/V、多头 reshape、因果 mask、padding mask 和输出 shape。
输入：随机 X[B,T,D]，其中 B=2、T=4、D=8、H=2。
产物：注意力权重、输出和一组断言。
代码状态：示例，未实跑。

import numpy as np

rng = np.random.default_rng(7)
B, T, D, H = 2, 4, 8, 2
dk = D // H
X = rng.normal(size=(B, T, D))
Wq = rng.normal(scale=0.1, size=(D, D))
Wk = rng.normal(scale=0.1, size=(D, D))
Wv = rng.normal(scale=0.1, size=(D, D))
Wo = rng.normal(scale=0.1, size=(D, D))

def split_heads(x):
    # [B,T,D] -> [B,H,T,dk]
    return x.reshape(B, T, H, dk).transpose(0, 2, 1, 3)

Q = split_heads(X @ Wq)
K = split_heads(X @ Wk)
V = split_heads(X @ Wv)
assert Q.shape == K.shape == V.shape == (B, H, T, dk)

scores = Q @ K.transpose(0, 1, 3, 2) / np.sqrt(dk)
assert scores.shape == (B, H, T, T)

# 因果 mask：上三角的未来位置不可见
causal = np.triu(np.ones((T, T), dtype=bool), k=1)
scores = np.where(causal[None, None, :, :], -np.inf, scores)

# 示例 padding mask：第 0 个样本最后两个 key 是 padding
valid = np.array([[1, 1, 0, 0], [1, 1, 1, 1]], dtype=bool)
scores = np.where(valid[:, None, None, :], scores, -np.inf)

weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
weights /= weights.sum(axis=-1, keepdims=True)
context = weights @ V                         # [B,H,T,dk]
merged = context.transpose(0, 2, 1, 3).reshape(B, T, D)
out = merged @ Wo

assert np.isfinite(out).all()
assert out.shape == (B, T, D)
assert np.allclose(weights.sum(axis=-1), 1.0)
assert np.allclose(weights[:, :, causal], 0.0)
assert np.allclose(weights[0, :, :, 2:], 0.0)
print("shape 与 mask 断言通过")

验证顺序：先断言 shape，再看有限值，再看权重和，最后看被 mask 的位置。若被 mask 行可能全部无效，需要单独处理，避免全为 -inf 后产生 NaN。真实框架的 padding 方向可能不同，应用前读接口说明。
