0. 三件事循环：前向→损失→反向→更新3 个重点▾ 点开看本章重点
本章重点
  • 神经网络的学习不是"猜参数"，是把一个可微分的函数链反复微调，让损失函数下降
  • 1. 前向传播：输入 x 经过各层线性变换+非线性激活，得到预测 ŷ
  • 2. 算损失：比较 ŷ 与真实标签 y，得到标量 loss（衡量"现在有多差"）
2

神经网络的学习不是"猜参数"，是把一个可微分的函数链反复微调，让损失函数下降。整个循环只有四步：

  1. 前向传播：输入 x 经过各层线性变换+非线性激活，得到预测 ŷ。
  2. 算损失：比较 ŷ 与真实标签 y，得到标量 loss（衡量"现在有多差"）。
  3. 反向传播：用链式法则从 loss 往回求每个参数的偏导 ∂loss/∂W。
  4. 参数更新：W ← W − lr·∂loss/∂W（学习率 lr 控制步长）。

循环跑几百到几万轮（epoch），直到 loss 收敛或验证集指标不再提升。这三件事的数学内核很简单，翻车全在细节：激活函数选错、学习率设错、初始化不对、没加正则，每一样都能让网络"看起来在训练但完全没学到东西"。本篇按"怎么写→怎么选→怎么翻车→怎么改"四段展开。

适用场景：需要从数据学复杂映射（分类/回归/序列/图像），特征工程成本高或根本无法手工设计特征时。
别用的场景：样本量极小（<100）且特征维度不高——线性模型/SVM 通常更稳更快；要求可解释性极强的风控/医疗决策——神经网络是黑盒，解释成本高。
翻车总纲：loss 不降→学习率/初始化/梯度消失三查；train_acc=1.0 但 test_acc 差→过拟合，加正则或增数据；loss 震荡发散→学习率过大或 batch 太小。每种形态在 §5 给症状→根因→改法三段。

1. 前向传播：矩阵形式怎么写

1.1 单层：线性变换 + 激活3 个重点▾ 点开看本节重点
本节重点
  • X: 形状 (n, d)，n 个样本、d 维特征
  • 矩阵乘法一次性算完所有样本，比 for 循环快几十倍——这是"多维数组运算一次算完"的关键点
  • 为什么用矩阵乘法而不是逐样本循环：numpy 的 「@」 底层调 BLAS（如 OpenBLAS/MKL），对连续内存的矩阵乘法做了向量化+多线程优化，比 Python 层 for 循环快 50~100 倍
3

一层的计算就两步：先线性变换 z = X·W + b，再过激活函数 a = f(z)。

  • X: 形状 (n, d)，n 个样本、d 维特征
  • W: 形状 (d, h)，h 个隐藏单元的权重
  • b: 形状 (h,)，偏置
  • 输出 a: 形状 (n, h)
import numpy as np

X = np.random.randn(4, 3)   # 4个样本, 3维特征
W = np.random.randn(3, 5)   # 5个隐藏单元
b = np.zeros(5)

z = X @ W + b                # (4,5)
a = np.maximum(0, z)         # ReLU 激活, 仍是 (4,5)
print("前向输出形状:", a.shape)

实跑输出形状 (4, 5)。矩阵乘法一次性算完所有样本，比 for 循环快几十倍——这是"多维数组运算一次算完"的关键点。

为什么用矩阵乘法而不是逐样本循环：numpy 的 @ 底层调 BLAS（如 OpenBLAS/MKL），对连续内存的矩阵乘法做了向量化+多线程优化，比 Python 层 for 循环快 50~100 倍。样本数 n 越大，差距越明显。写神经网络代码的铁律是：只要有矩阵乘法就用 @，不要写 for 循环遍历样本。

偏置 b 的作用：权重 W 控制输入信号的重要性（特征加权），偏置 b 调整神经元被激活的容易程度（把激活阈值平移）。没有 b 的话，所有超平面都过原点，表达能力受限。实现上 b 通过 numpy 广播加到每个样本（形状 (h,) 广播到 (n, h)），不需要显式建矩阵。

训练模式 vs 推理模式的区别：BatchNorm/Dropout 在训练和推理时行为不同（训练用 batch 统计量、推理用全局统计量；训练随机丢弃、推理不丢弃）。实现网络时要把这个开关做进 forward()，否则推理结果会系统性偏差。这一点在手写网络时最容易忘，也是深度学习框架里 model.train() 和 model.eval() 两个方法存在的原因。

1.2 多层堆叠：形状链式跟踪

3

把多层串起来，每层输出形状是下层输入形状。写代码时先手算形状，能提前发现矩阵维度错误：

# 2层网络: 3维输入 -> 16隐藏 -> 4类输出
X = np.random.randn(4, 3)
W1, b1 = np.random.randn(3, 16), np.zeros(16)
W2, b2 = np.random.randn(16, 4), np.zeros(4)

z1 = X @ W1 + b1          # (4,16)
a1 = np.maximum(0, z1)    # ReLU
z2 = a1 @ W2 + b2         # (4,4)
print("逐层形状:", X.shape, "->", z1.shape, "->", z2.shape)

实跑输出 (4, 3) -> (4, 16) -> (4, 4)。形状链是调 bug 的第一道防线：矩阵乘法报 "matmul operands shapes not aligned" 时，先打印每层形状，80% 的维度错误立刻显形。

通用近似定理的工程含义：理论上，一个包含足够多隐藏单元的两层神经网络可以逼近任意连续函数。但"足够多"可能是天文数字，实际工程中用"更深+每层更窄"替代"更浅+每层更宽"，因为深度带来的组合表达效率更高（三个 3x3 卷积等效一个 7x7 但参数更少、非线性更强，这是同一逻辑在 CNN 里的体现）。这条定理的价值是"神经网络能拟合复杂映射"的理论保证，不是"随便搭两层就能用"的工程指南。

输出层设计的分工：回归问题输出层用恒等函数（不做压缩，输出无界），分类问题用 softmax（输出概率分布，各类和为 1）。多分类且只需 argmax 结果时，推理阶段 softmax 可以省略（单调变换不改变 argmax），但训练阶段因为交叉熵损失需要概率输入，不能省。二分类用 sigmoid 输出单个概率。

2.1 链式法则展开

3

反向传播不是魔法，就是多元链式法则的递归应用。对两层网络：

∂loss/∂W2 = a1ᵀ · (∂loss/∂z2)
∂loss/∂W1 = Xᵀ · (∂loss/∂z1)，其中 ∂loss/∂z1 = (∂loss/∂z2 · W2ᵀ) ⊙ f'(z1)

⊙ 是逐元素乘，f'(z1) 是激活函数的导数（ReLU 就是 z1>0 的布尔掩码）。每一层的梯度都是"上游梯度 × 本层导数 × 本层输入"三件套，从输出层往输入层逐层传。

2.2 数值梯度 vs 解析梯度：验证反向传播没写错3 个重点▾ 点开看本节重点
本节重点

  • 这是唯一能证明你的梯度实现正确的方法，比"loss 下降了"可靠得多（loss 下降也可能只是学习率凑巧合适，梯度仍算错了）
  • return -np.log(P[np.arange(n), y] + 1e-12).mean()
3

写完 backward() 后必须核对：用数值微分（中心差分）算一遍梯度，比对两者误差。误差 <1e-6 才算反向传播写对了。这是唯一能证明你的梯度实现正确的方法，比"loss 下降了"可靠得多（loss 下降也可能只是学习率凑巧合适，梯度仍算错了）。

import numpy as np

rng = np.random.default_rng(1)
n, d, h, c = 8, 6, 10, 3
X = rng.normal(size=(n, d))
y = rng.integers(0, c, size=n)
W1 = rng.normal(0, 0.5, size=(d, h)); b1 = np.zeros(h)
W2 = rng.normal(0, 0.5, size=(h, c)); b2 = np.zeros(c)

def loss_fn(p):
    W1, b1, W2, b2 = p
    a1 = np.maximum(0, X @ W1 + b1)
    z2 = a1 @ W2 + b2
    z2 = z2 - z2.max(axis=1, keepdims=True)   # 数值稳定 softmax
    P = np.exp(z2); P /= P.sum(axis=1, keepdims=True)
    return -np.log(P[np.arange(n), y] + 1e-12).mean()

def analytic(p):
    W1, b1, W2, b2 = p
    z1 = X @ W1 + b1; a1 = np.maximum(0, z1)
    z2 = a1 @ W2 + b2
    z2s = z2 - z2.max(axis=1, keepdims=True)
    P = np.exp(z2s); P /= P.sum(axis=1, keepdims=True)
    dz2 = P.copy(); dz2[np.arange(n), y] -= 1; dz2 /= n   # softmax+交叉熵联合梯度
    dW2 = a1.T @ dz2; db2 = dz2.sum(axis=0)
    dz1 = (dz2 @ W2.T) * (z1 > 0)                         # ReLU 导数掩码
    dW1 = X.T @ dz1; db1 = dz1.sum(axis=0)
    return [dW1, db1, dW2, db2]

p = [W1, b1, W2, b2]
g_ana = analytic(p)

def numeric(p, eps=1e-6):
    gs = []
    for arr in p:
        g = np.zeros_like(arr)
        it = np.nditer(arr, flags=["multi_index"])
        while not it.finished:
            idx = it.multi_index
            old = arr[idx]
            arr[idx] = old + eps; lp = loss_fn(p)
            arr[idx] = old - eps; lm = loss_fn(p)
            arr[idx] = old
            g[idx] = (lp - lm) / (2 * eps)
            it.iternext()
        gs.append(g)
    return gs

g_num = numeric(p)
for name, ga, gn in zip(["W1", "b1", "W2", "b2"], g_ana, g_num):
    diff = np.abs(ga - gn).max()
    print(f"{name}: max|analytic-numeric| = {diff:.2e}")

W1: max|analytic-numeric| = 8.27e-11
b1: max|analytic-numeric| = 6.45e-11
W2: max|analytic-numeric| = 6.93e-11
b2: max|analytic-numeric| = 8.73e-11

四个参数张量的解析梯度与数值梯度误差都在 8e-11 量级（浮点精度极限附近），说明反向传播实现正确。这个核对是训练任何网络前的必做步骤，尤其当你手写 backward、改激活函数、加新层时。

2.3 softmax 与交叉熵的数值稳定性

3

softmax 直接对 logit 做 exp，遇到大数值（如 logit>500）会浮点溢出变成 inf/inf=nan。标准解法是减去每行最大值再 exp（数学上等价，因为 softmax 平移不变）。交叉熵也有两种写法：先 softmax 得概率再取 log（两阶段），或用 logsumexp 技巧直接算 log 概率（联合法）。实跑对照：

import numpy as np

rng = np.random.default_rng(2)
z = rng.normal(0, 1, size=(32, 4)) * 30.0   # 大 logit
y = rng.integers(0, 4, size=32)

def softmax_stable(z):
    z = z - z.max(axis=1, keepdims=True)   # 减 max 防溢出
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

P = softmax_stable(z)
p_true = P[np.arange(len(y)), y]
print("真实类概率最小值:", float(p_true.min()))
print("下溢到<1e-12 的样本数:", int((p_true < 1e-12).sum()))

# 联合 logsumexp: 数学上恒等于 -log(p_true), 但不需要显式算 p
z_shift = z - z.max(axis=1, keepdims=True)
log_p_true = z_shift[np.arange(len(y)), y] - np.log(np.exp(z_shift).sum(axis=1))
print("联合法 loss:", round(float(-log_p_true.mean()), 6))
print("无截断两阶段 loss:", round(float(-np.log(p_true).mean()), 6))
print("加1e-12截断两阶段 loss:", round(float(-np.log(p_true + 1e-12).mean()), 6))

实跑输出：

真实类概率最小值: 7.18725924612689e-49
下溢到<1e-12 的样本数: 17
联合法 loss: 36.776503
无截断两阶段 loss: 36.776503
加1e-12截断两阶段 loss: 17.477417

怎么读：真实类概率最小到 7.2e-49，17 个样本的概率低于 1e-12（浮点下溢区）。联合法与无截断两阶段结果完全一致（36.776503），但加了 1e-12 截断的两阶段结果变成 17.477，误差 19.3——截断常数把下溢的 log 概率"顶"回 log(1e-12)≈-27.6，让 loss 系统性偏低。这是"为什么框架都用 logsumexp 联合实现"的原因：不用显式算概率，就没有下溢和截断误差。手写损失函数时必须用联合法，不要写成 log(softmax(z)[y] + eps)。

溢出演示：logit=1000 时朴素 softmax 直接算 exp(1000)=inf，输出全 nan；减 max 后变成 exp(0)=1，输出 [1, 0, 0, 0] 正确。任何用到 exp 的地方（softmax、sigmoid）都要防溢出：sigmoid 用 1/(1+exp(-clip(x)))，softmax 减 max 后再 exp。

2.4 计算图视角：把反向传播看成数据结构3 个重点▾ 点开看本节重点
本节重点
  • 更工程化的视角是把前向过程构建成计算图（有向无环图）：每个节点是一个运算（加法、乘法、激活），存住前向的中间结果，反向就是拓扑逆序遍历每个节点，应用局部梯度（本节点的导数）链乘上去
  • PyTorch/TensorFlow 的自动微分（autograd）就是这个原理的工业化实现
  • 手写小网络时不需要建图，直接按链式法则展开就够（如本篇 §6 的完整例子）
3

更工程化的视角是把前向过程构建成计算图（有向无环图）：每个节点是一个运算（加法、乘法、激活），存住前向的中间结果，反向就是拓扑逆序遍历每个节点，应用局部梯度（本节点的导数）链乘上去。PyTorch/TensorFlow 的自动微分（autograd）就是这个原理的工业化实现。

手写小网络时不需要建图，直接按链式法则展开就够（如本篇 §6 的完整例子）。但理解计算图视角有两个好处：

  1. debug 友好：图里每个节点可以单独做数值梯度核对（§2.2），定位错在哪一步，不用整体黑盒猜测。
  2. 扩展性强：加新层（BatchNorm、Dropout、残差连接）只需要实现该节点的 forward/backward 两个函数，插进图里即可，不用改整体框架。

数值微分 vs 符号微分 vs 自动微分：数值微分（有限差分）精度低（1e-6 量级）但通用，适合调试核对；符号微分（公式推导）精确但表达式可能膨胀爆炸；自动微分（计算图+链式法则）精确且高效，是现代框架的标配。工程实践里：调试用数值微分核对，生产用自动微分。

3.1 为什么必须非线性2 个重点▾ 点开看本节重点

  • 非线性打破这个等价性，让多层网络能逼近任意复杂函数（通用近似定理）

激活函数用线性函数的话，多层网络等价于单层线性变换（线性函数的复合还是线性），堆层数毫无意义。非线性打破这个等价性，让多层网络能逼近任意复杂函数（通用近似定理）。

3.2 四种激活函数的输出范围与梯度分布

3

同一输入分布下，四种激活函数的输出范围、梯度均值、梯度<0.01 的比例（衡量"死区"大小）：

import numpy as np

rng = np.random.default_rng(3)
x = np.concatenate([rng.normal(0, 1, 5000), rng.normal(0, 3, 1000)])  # 含少量大值

def sigmoid(v):
    return 1.0 / (1.0 + np.exp(-np.clip(v, -500, 500)))

acts = {
    "sigmoid": (sigmoid(x), sigmoid(x) * (1 - sigmoid(x))),
    "tanh": (np.tanh(x), 1 - np.tanh(x) ** 2),
    "relu": (np.maximum(0, x), (x > 0).astype(float)),
    "leaky_relu(0.01)": (np.where(x > 0, x, 0.01 * x), np.where(x > 0, 1.0, 0.01)),
}
for name, (a, g) in acts.items():
    print(f"{name:18s} out[{a.min():+.3f},{a.max():+.3f}] grad_mean={g.mean():.4f} "
          f"grad<0.01占比={(g < 0.01).mean():.3f}")

怎么读这张表：

  • sigmoid：输出压缩到 (0,1)，适合"概率"语义的输出层（二分类最后一层）。梯度均值仅 0.19，且饱和区（|x|>4）梯度趋近 0——隐藏层别用 sigmoid，深层网络会梯度消失。
  • tanh：输出零中心 (-1,1)，比 sigmoid 好一点（梯度均值 0.54），但饱和问题仍在。RNN 遗忘门/门控单元里常用，前馈隐藏层现在基本被 ReLU 家族取代。
  • relu：计算快、正区梯度恒为 1（不衰减），是前馈网络隐藏层的默认选择。缺点：负区梯度为 0，约 50% 的"死区"（grad<0.01 占比 0.496）是正常现象，只要不是"永久死"（见 §5.4 死神经元）就没事。
  • leaky_relu：负区给 0.01 的小斜率，彻底消除死区（占比 0.000），适合发现 ReLU 训练后期有单元死亡时替换。

3.5 激活函数选型的决策流程3 个重点▾ 点开看本节重点
本节重点
  • 1. 输出层先定：回归用恒等、多分类用 softmax、二分类用 sigmoid
  • 3. 训练中监控死神经元比例（激活恒 0 的单元数/总单元数）：>20% 时换 LeakyReLU/GELU，或降学习率
  • 2. 隐藏层默认 ReLU：计算快、梯度不衰减、绝大多数前馈/CNN 适用
3

面对一个新网络，激活函数按这个顺序选：

  1. 输出层先定：回归用恒等、多分类用 softmax、二分类用 sigmoid。这由任务类型决定，没有选择空间。
  2. 隐藏层默认 ReLU：计算快、梯度不衰减、绝大多数前馈/CNN 适用。
  3. 训练中监控死神经元比例（激活恒 0 的单元数/总单元数）：>20% 时换 LeakyReLU/GELU，或降学习率。
  4. RNN/LSTM 门控单元：tanh（候选态）+ sigmoid（门控），因为门控需要 (0,1) 的开关语义和 (-1,1) 的候选状态。
  5. 小网络（2~3 层）或传统机器学习特征映射：tanh 也行，饱和问题不突出。

不选 sigmoid/tanh 当隐藏层的理由不是"它们错"，而是深层网络下梯度消失训练不动。浅层网络（2 层）用 sigmoid 完全可以，只是没必要——ReLU 更快。

3.6 GELU/Swish：平滑版 ReLU

3

ReLU 在 0 点不可导（工程上无所谓，subgradient 随便取一边），且负区硬性归零。GELU（Gaussian Error Linear Unit）和 Swish 是平滑替代品：

  • Swish：f(x) = x · sigmoid(x)，在负区有小的负值输出（不完全锁死），平滑可导。
  • GELU：f(x) = x · Φ(x)（Φ 是标准正态 CDF），Transformer（BERT/GPT）的默认激活，近似 Swish 但有概率解释（按输入大小随机门控）。

实测中 GELU/Swarm 在 Transformer 类架构上略优于 ReLU，但在前馈/CNN 上差异很小。判据：Transformer 用 GELU，CNN/前馈用 ReLU，别在这上面花太多调参时间。

4.1 损失函数选型

3
  • 回归：均方误差 MSE = mean((ŷ−y)²)，对异常值敏感；鲁棒版用 Huber（小误差平方、大误差线性）。
  • 多分类：交叉熵 CE = −mean(log p_y)，配合 softmax 输出。不能用识别精度（accuracy）当损失——精度是阶跃函数，几乎处处导数为 0，参数根本无法更新。这是"为什么损失函数不能用准确率"的核心原因。
  • 二分类：BCE = −mean(y·log p + (1−y)·log(1−p))，配合 sigmoid 输出。
4.2 L2 正则化：权重衰减3 个重点▾ 点开看本节重点
本节重点
  • 在损失里加 「λ·ΣW²」，梯度里多出 「λ·W」 项，权重被持续拉向 0，防止过拟合
  • 判据：λ 太小（1e-3）没效果，太大（1.0）把真实信号也压没了（真实权重 3.0/-2.0 被压到 1.418/-1.014）
  • λ 选对的标准是"训练 acc 略降、验证 acc 提升"
3

在损失里加 λ·ΣW²，梯度里多出 λ·W 项，权重被持续拉向 0，防止过拟合。实测（岭回归，100 样本 10 维，2 个真实特征）：

import numpy as np

rng = np.random.default_rng(5)
X = rng.normal(size=(100, 10))
w_true = np.zeros(10); w_true[:2] = [3.0, -2.0]
y = X @ w_true + rng.normal(0, 0.5, size=100)

def fit_ridge(l2, steps=2000, lr=0.01):
    w = np.zeros(10)
    for _ in range(steps):
        g = X.T @ (X @ w - y) / len(y) + l2 * w
        w -= lr * g
    return w

for l2 in [0.0, 1e-3, 1e-1, 1.0]:
    w = fit_ridge(l2)
    print(f"l2={l2:<6} ||w||2={np.linalg.norm(w):.3f}  w[:2]={np.round(w[:2], 3)}")

4.3 Dropout：训练期随机丢弃

3

训练时以概率 p 随机把激活置 0，推理时乘以 (1−p) 缩放保持期望一致。训练/推理的尺度差异必须理解：

import numpy as np

r = np.random.default_rng(5)
a = np.maximum(0, r.normal(size=(1, 1000)))
p = 0.5
mask = (r.random(a.shape) > p) / (1 - p)
print("原激活均值:", round(float(a.mean()), 4))
print("训练期dropout后均值:", round(float((a * mask).mean()), 4))
print("推理期乘(1-p)均值:", round(float((a * (1 - p)).mean()), 4))

实跑输出：

原激活均值: 0.3991
训练期dropout后均值: 0.3974
推理期乘(1-p)均值: 0.1995

训练期 dropout（inverted dropout，除以 1−p）保持均值≈原均值 0.399，而推理期直接乘 (1−p) 均值变成 0.20——如果训练用 inverted dropout，推理期不能再乘 (1−p)，否则预测值系统性偏小，分类边界整体偏移。这是 Dropout 最常见的实现 bug。

4.5 BatchNorm 的机制与坑

3

BatchNorm 在每个 mini-batch 内对每层输入做标准化（减均值除标准差），再用可学习的 γ、β 缩放平移。作用：

  • 加速训练：消除了内部协变量偏移（每层输入分布随训练变化），允许更大学习率。
  • 轻微正则：batch 统计量引入噪声（等效于对输入加噪），有类似 dropout 的正则效果。
  • 降低对初始化的敏感度：即使初始化尺度不理想，BN 会把激活拉回标准分布。

坑：batch size 很小（<8）时 batch 统计量噪声太大，BN 反而有害——此时用 LayerNorm（按单样本的特征维度归一化，与 batch 无关）。Transformer 用 LayerNorm，CNN 用 BatchNorm，就是这个原因。

  • 按时间切分：时序预测/推荐系统必须用，否则未来信息泄漏到训练集，指标虚高

验证集必须与训练集、测试集三者不重叠，且分布一致（同分布随机切分或按时间切分）。切分方式选错会带来虚假指标：

  • 随机切分：适合样本独立同分布的情况（图像分类）。
  • 按时间切分：时序预测/推荐系统必须用，否则未来信息泄漏到训练集，指标虚高。

5.1 学习率与 batch size2 个重点▾ 点开看本节重点
本节重点

学习率是最敏感的超参数。同一网络、同一数据，只改 lr：

import numpy as np

rng = np.random.default_rng(21)
N, D, H, C = 240, 20, 32, 3
centers = rng.normal(0, 2.0, size=(C, D))
X = np.concatenate([rng.normal(c, 1.0, size=(N // C, D)) for c in centers])
y = np.repeat(np.arange(C), N // C)

def run(lr, clip=None, epochs=8, seed=7):
    r = np.random.default_rng(seed)
    W1 = r.normal(0, np.sqrt(2.0 / D), size=(D, H)); b1 = np.zeros(H)
    W2 = r.normal(0, np.sqrt(2.0 / H), size=(H, C)); b2 = np.zeros(C)
    losses = []
    for ep in range(epochs):
        z1 = np.maximum(0, X @ W1 + b1)
        z2 = z1 @ W2 + b2
        z2s = z2 - z2.max(axis=1, keepdims=True)
        P = np.exp(z2s); P /= P.sum(axis=1, keepdims=True)
        loss = -np.log(P[np.arange(N), y] + 1e-12).mean()
        losses.append(round(float(loss), 3))
        dz2 = P.copy(); dz2[np.arange(N), y] -= 1; dz2 /= N
        dz1 = (dz2 @ W2.T) * (z1 > 0)
        grads = [X.T @ dz1, dz1.sum(0), z1.T @ dz2, dz2.sum(0)]
        if clip is not None:
            gn = np.sqrt(sum(float((g ** 2).sum()) for g in grads))
            if gn > clip:
                grads = [g * clip / gn for g in grads]
        dW1, db1, dW2, db2 = grads
        W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    return losses

print("[1] lr爆炸 症状: lr=50 loss轨迹:", run(50.0))
print("[1] 改法 lr=0.5:", run(0.5))
print("[1] 改法 lr=50+梯度裁剪(clip=5):", run(50.0, clip=5.0))

5.2 翻车形态：梯度消失

3
  • 症状：前几层权重几乎不动，loss 卡平台期不降。
  • 根因：sigmoid 导数最大仅 0.25，多层连乘后梯度指数衰减。实测 8 层 sigmoid 网络梯度范数从 2.08 衰减到 0.00012（衰减 1.7 万倍）：
import numpy as np

def sig(v): return 1.0 / (1.0 + np.exp(-np.clip(v, -500, 500)))
def flow(act, depth=8, size=64):
    r = np.random.default_rng(11)
    g = np.ones((1, size)); norms = []
    for d in range(depth):
        W = r.normal(0, np.sqrt(2.0 / size), size=(size, size))
        z = r.normal(size=(1, size)) @ W
        delta = sig(z) * (1 - sig(z)) if act == "sig" else (z > 0).astype(float)
        g = (g * delta) @ W.T
        norms.append(round(float(np.linalg.norm(g)), 5))
    return norms
print("sigmoid 8层梯度范数:", flow("sig"))
print("relu    8层梯度范数:", flow("relu"))

import numpy as np

rng = np.random.default_rng(99)

def train_eval(l2=0.0, dropout=0.0, epochs=300, lr=0.1, seed=1):
    r = np.random.default_rng(seed)
    X2 = rng.normal(size=(60, 10)); y2 = (X2[:, 0] + 0.5 * X2[:, 1] > 0).astype(int)
    Xtr, ytr, Xte, yte = X2[:40], y2[:40], X2[40:], y2[40:]
    W1 = r.normal(0, 0.5, size=(10, 40)); b1 = np.zeros(40)
    W2 = r.normal(0, 0.5, size=(40, 2)); b2 = np.zeros(2)
    for ep in range(epochs):
        a1 = np.maximum(0, Xtr @ W1 + b1)
        mask = (r.random(a1.shape) > dropout) / (1 - dropout) if dropout > 0 else 1.0
        a1d = a1 * mask
        z2 = a1d @ W2 + b2
        z2s = z2 - z2.max(axis=1, keepdims=True)

        dz2 = P.copy(); dz2[np.arange(len(ytr)), ytr] -= 1; dz2 /= len(ytr)
        dW2 = a1d.T @ dz2 + l2 * W2; db2 = dz2.sum(0)
        da1 = (dz2 @ W2.T) * mask
        dz1 = da1 * (Xtr @ W1 + b1 > 0)
        dW1 = Xtr.T @ dz1 + l2 * W1; db1 = dz1.sum(0)
        W2 -= lr * dW2; b2 -= lr * db2; W1 -= lr * dW1; b1 -= lr * db1
    def acc(Xa, ya, train):
        a1 = np.maximum(0, Xa @ W1 + b1)
        if not train and dropout > 0: a1 = a1 * (1 - dropout)
        return float(((a1 @ W2 + b2).argmax(1) == ya).mean())
    return acc(Xtr, ytr, True), acc(Xte, yte, False)

print("[3] 过拟合 症状 no reg:", train_eval())
print("[3] 改法 l2=0.01:", train_eval(l2=0.01))
print("[3] 改法 dropout=0.5:", train_eval(dropout=0.5))

5.4 翻车形态：死神经元

3
  • 症状：某层激活全为 0，对应权重梯度为 0，训练中该单元永久不动。
  • 根因：lr 太大把权重推到负区，ReLU 恒输出 0，梯度恒为 0，单元"死亡"无法恢复。实测：
import numpy as np

rng = np.random.default_rng(99)
N, D, H, C = 240, 20, 32, 3
centers = rng.normal(0, 2.0, size=(C, D))
X = np.concatenate([rng.normal(c, 1.0, size=(N // C, D)) for c in centers])
y = np.repeat(np.arange(C), N // C)

def dead_units(lr, epochs=30, seed=3):
    r = np.random.default_rng(seed)
    W1 = r.normal(0, np.sqrt(2.0 / D), size=(D, H)); b1 = np.zeros(H)
    W2 = r.normal(0, np.sqrt(2.0 / H), size=(H, C)); b2 = np.zeros(C)
    for ep in range(epochs):
        z1 = X @ W1 + b1; a1 = np.maximum(0, z1)
        z2 = a1 @ W2 + b2
        z2s = z2 - z2.max(axis=1, keepdims=True)
        P = np.exp(z2s); P /= P.sum(axis=1, keepdims=True)
        dz2 = P.copy(); dz2[np.arange(N), y] -= 1; dz2 /= N
        dz1 = (dz2 @ W2.T) * (z1 > 0)
        W1 -= lr * (X.T @ dz1); b1 -= lr * dz1.sum(0)
        W2 -= lr * (a1.T @ dz2); b2 -= lr * dz2.sum(0)
    z1 = X @ W1 + b1
    return int((np.maximum(0, z1) == 0).all(axis=0).sum()), H

nd2, total = dead_units(lr=0.5)
print(f"[4] 改法 lr=0.5: {nd2}/{total} 个单元全零激活")

  • 改法：增大 batch / 加动量平滑历史梯度

  • 症状：loss 震荡剧烈，无法平稳下降。
  • 根因：batch=1 时梯度是单样本估计，方差极大，更新方向随机跳。
  • 改法：增大 batch / 加动量平滑历史梯度。实测梯度标准差：
import numpy as np

rng = np.random.default_rng(99)
N, D, H, C = 240, 20, 32, 3
centers = rng.normal(0, 2.0, size=(C, D))

def grad_noise(batch, trials=30, seed=5):
    r = np.random.default_rng(seed)
    W = r.normal(0, 0.5, size=(D, C))
    gs = []
    for t in range(trials):
        idx = r.choice(N, size=batch, replace=False)
        xb, yb = X[idx], y[idx]
        z = xb @ W; z = z - z.max(axis=1, keepdims=True)
        P = np.exp(z); P /= P.sum(axis=1, keepdims=True)
        dz = P.copy(); dz[np.arange(batch), yb] -= 1; dz /= batch
        gs.append((xb.T @ dz).ravel())
    return float(np.array(gs).std(axis=0).mean())

print(f"[5] 梯度噪声 batch=1 std={grad_noise(1):.4f}")
print(f"[5] 改法 batch=64 std={grad_noise(64):.4f}")

5.6 优化器选型：SGD / Momentum / Adam

3

SGD 是最简单的更新规则（W ← W − lr·g），但在病态曲面（各方向曲率差异大，条件数高）上收敛很慢。Momentum 累积历史梯度方向，Adam 给每个参数自适应学习率。实测（病态二次型 f=0.5·(w1² + 100·w2²)，条件数 100，起点 (10,1)）：

import numpy as np

def loss_g(w):
    return 0.5 * (w[0] ** 2 + 100.0 * w[1] ** 2), np.array([w[0], 100.0 * w[1]])

def run_sgd(steps=200, lr=0.01):
    w = np.array([10.0, 1.0])
    for t in range(steps):
        l, g = loss_g(w)
        w = w - lr * g
    l, _ = loss_g(w)
    return float(l), w

def run_momentum(steps=200, lr=0.01, beta=0.9):
    w = np.array([10.0, 1.0]); v = np.zeros(2)
    for t in range(steps):
        l, g = loss_g(w)
        v = beta * v - lr * g
        w = w + v
    l, _ = loss_g(w)
    return float(l), w

def run_adam(steps=200, lr=0.1, beta1=0.9, beta2=0.999, eps=1e-8):
    w = np.array([10.0, 1.0]); m = np.zeros(2); v = np.zeros(2)
    for t in range(1, steps + 1):
        l, g = loss_g(w)
        m = beta1 * m + (1 - beta1) * g
        v = beta2 * v + (1 - beta2) * g ** 2
        mh = m / (1 - beta1 ** t); vh = v / (1 - beta2 ** t)
        w = w - lr * mh / (np.sqrt(vh) + eps)
    l, _ = loss_g(w)
    return float(l), w

for name, fn in [("SGD lr=0.01", run_sgd), ("SGD+momentum lr=0.01", run_momentum), ("Adam lr=0.1", run_adam)]:
    final_loss, w = fn()
    print(f"{name:22s} 200步后 loss={final_loss:.6f} w={np.round(w, 4).tolist()}")

def run_sched(sched, steps=300, lr0=0.02):
    w = np.array([10.0, 1.0])
    for t in range(steps):
        l, g = loss_g(w)
        if sched == "const":
            lr = lr0
        elif sched == "exp":
            lr = lr0 * (0.99 ** t)
        elif sched == "cos":
            lr = lr0 * 0.5 * (1 + np.cos(np.pi * t / steps))
        w = w - lr * g
    l, _ = loss_g(w)
    return float(l)

5.8 超参数搜索的纪律

3

神经网络有十几个超参数（lr、batch、隐藏宽度、深度、激活函数、初始化、正则系数、dropout 率……），网格搜索组合爆炸。工程纪律：

  1. 先调 lr：lr 是最敏感的，其他超参数在 lr 不合适时都调不出效果。lr 从 1e-1 到 1e-4 按对数网格找量级。
  2. 再调 batch 与正则：batch 影响梯度噪声和训练速度，正则系数影响泛化。两者一起调。
  3. 最后调结构：深度、宽度、激活函数。结构改动后前面的超参数可能要重调。
  4. 用验证集选超参数，测试集只在最终评估用一次：用测试集调参=信息泄漏，指标虚高。
  5. 记录实验配置：每次实验记录超参数+验证指标，避免重复试错、方便回滚。

# 手写数字小识别(合成的 8x8 "数字"图案, 纯 numpy): 完整前向/反向/SGD

rng = np.random.default_rng(2026)

def make_class(proto, n, noise=0.3):
    return np.clip(proto[None] + rng.normal(0, noise, size=(n,) + proto.shape), 0, 1)

H = W = 8
p0 = np.zeros((H, W)); p0[3:5, 1:7] = 1.0            # 横线
p1 = np.zeros((H, W)); p1[1:7, 3:5] = 1.0            # 竖线

p3 = np.zeros((H, W)); p3[1:7, 1:7] = 1.0; p3[2:6, 2:6] = 0.0  # 方框

n_per = 80
data, labels = [], []
for i, p in enumerate([p0, p1, p2, p3]):
    data.append(make_class(p, n_per))
    labels.append(np.full(n_per, i))
X = np.concatenate(data).reshape(-1, H * W)
y = np.concatenate(labels)

n_test = 80
Xtr, ytr, Xte, yte = X[:-n_test], y[:-n_test], X[-n_test:], y[-n_test:]

D, H1, C = H * W, 64, 4
def init(rng):
    return [rng.normal(0, np.sqrt(2.0 / D), size=(D, H1)), np.zeros(H1),
            rng.normal(0, np.sqrt(2.0 / H1), size=(H1, C)), np.zeros(C)]

def forward(X, p):
    W1, b1, W2, b2 = p
    z1 = X @ W1 + b1; a1 = np.maximum(0, z1)
    z2 = a1 @ W2 + b2
    z2 = z2 - z2.max(axis=1, keepdims=True)
    P = np.exp(z2); P /= P.sum(axis=1, keepdims=True)
    return z1, a1, P

def step(X, y, p, lr, l2=1e-3):
    W1, b1, W2, b2 = p
    z1, a1, P = forward(X, p)
    n = len(y)
    loss = -np.log(P[np.arange(n), y] + 1e-12).mean()
    loss += 0.5 * l2 * (np.sum(W1 ** 2) + np.sum(W2 ** 2))
    dz2 = P.copy(); dz2[np.arange(n), y] -= 1; dz2 /= n
    dW2 = a1.T @ dz2 + l2 * W2; db2 = dz2.sum(0)
    dz1 = (dz2 @ W2.T) * (z1 > 0)
    dW1 = X.T @ dz1 + l2 * W1; db1 = dz1.sum(0)
    p = [W1 - lr * dW1, b1 - lr * db1, W2 - lr * dW2, b2 - lr * db2]
    return p, loss

r = np.random.default_rng(7)
p = init(r)
batch = 32
hist = []
for ep in range(120):

        p, loss = step(Xtr[bi], ytr[bi], p, lr=0.5)

_, _, Ptr = forward(Xtr, p)

print("epoch1 loss:", round(hist[0], 4), " epoch120 loss:", round(hist[-1], 4))

  1. 数据生成（make_class）：4 类 8x8 合成图案 + 高斯噪声，模拟"每类有原型、实例有变异"的真实数据结构。合成数据的好处是类别可分性已知，能验证网络是否学到正确的判别边界。

def fit(Xtr, ytr, Xte, yte, l2=0.01, steps=500, lr=0.05):
    w = np.zeros(Xtr.shape[1])
    for _ in range(steps):
        g = Xtr.T @ (Xtr @ w - ytr) / len(ytr) + l2 * w
        w -= lr * g
    pred = Xte @ w
    return float(((pred - yte) ** 2).mean())

mses = []
for seed in range(10):
    r = np.random.default_rng(seed)
    idx = r.permutation(N)
    tr, te = idx[:48], idx[48:]
    mses.append(fit(X[tr], y[tr], X[te], y[te]))
print("单次切分 10个种子 MSE: 均值=%.4f 标准差=%.4f 范围=[%.4f, %.4f]" % (
    mean(mses), stdev(mses), min(mses), max(mses)))

def kfold(k=5, seed=0):
    r = np.random.default_rng(seed)
    idx = r.permutation(N)
    folds = np.array_split(idx, k)
    mses = []
    for i in range(k):
        te = folds[i]
        tr = np.concatenate([folds[j] for j in range(k) if j != i])
        mses.append(fit(X[tr], y[tr], X[te], y[te]))
    return mses

mses = kfold(5, 0)
print("5折CV: 每折MSE=%s 均值=%.4f 标准差=%.4f" % ([round(m, 4) for m in mses], mean(mses), stdev(mses)))

单次切分 10 个种子的 MSE 范围 [0.31, 1.18]（差 3.7 倍），而 5 折 CV 均值更稳。判据：样本 <1000 用 5~10 折 CV；样本充足时固定验证集+多个随机种子取均值±标准差。汇报指标永远带波动范围，不报单点数字。

8.2 训练监控：看什么、怎么看

3

训练时盯这几条曲线，翻车早发现：

  • train loss / val loss：双降=正常收敛；train 降 val 升=过拟合（加正则/早停）；都不降=欠拟合或 lr 太小；震荡爆炸=lr 太大。
  • 梯度范数：每层梯度的 L2 范数，突然变 0（死神经元/梯度消失）或突然变大（梯度爆炸）都要查。
  • 激活值分布：每层激活的均值/方差，全 0（死神经元）或方差爆炸（初始化/BN 问题）是早期信号。
  • 学习率曲线：确认调度器按预期在降，没设错导致 lr 一直是 0 或一直是初始值。
8.3 混合精度与显存优化3 个重点▾ 点开看本节重点
本节重点
  • 混合精度（AMP）：前向/反向用 fp16 计算、权重用 fp32 保存、loss scaling 防 fp16 梯度下溢
  • 速度提升 1.5~3 倍，显存省 30~50%
  • 梯度检查点（activation checkpointing）：前向不存中间激活，反向时重算，用计算换显存（时间多 30%，显存省 60%+）
3

大模型训练显存不够是常态，标准手段：

  • 混合精度（AMP）：前向/反向用 fp16 计算、权重用 fp32 保存、loss scaling 防 fp16 梯度下溢。速度提升 1.5~3 倍，显存省 30~50%。
  • 梯度累积：模拟大 batch——算 4 个小 batch 的梯度累加后再更新一次，显存不变但等效 batch×4。
  • 梯度检查点（activation checkpointing）：前向不存中间激活，反向时重算，用计算换显存（时间多 30%，显存省 60%+）。
  • 模型并行：单卡放不下的模型按层/按张量切到多卡，每卡算一部分。

判据：先用混合精度+梯度累积解决 90% 的显存问题；还不够再上梯度检查点；模型真的超大（>100B 参数）才需要模型并行+张量并行。

8.4 迁移学习：冻结主干、只调末端

3

数据少时不要从头训网络，用预训练模型（在大数据集上训好的权重）做迁移学习：

  1. 特征提取：冻结所有卷积层（权重不动），只重训末端全连接（分类头）。适合数据很少（<1000）的情况。
  2. 微调（fine-tune）：解冻后面几层卷积，用很小的学习率（预训练权重的 1/100）一起训。适合数据中等（1000~10 万）。
  3. 从头训：数据充足（>10 万）且与预训练分布差异大时才考虑。

为什么有效：CNN 浅层学到的是通用特征（边缘、纹理），深层才是任务相关特征。冻结浅层=复用通用特征，只调深层=适配新任务。多模态场景（课件 §5.7）的 CNN 提特征+LLM 推理也是同一逻辑：CNN 主干当特征提取器，Transformer 当任务头。

10. 三问速查

2

什么情况下用？ 数据量中等以上（>1000 样本）、特征间关系复杂（图像/语音/序列/多特征交互）、手工特征工程成本高时。前馈网络是默认起点，先跑通 2 层小网络验证 pipeline，再加深加宽。

什么情况下别用？ 样本量极小（<100）且特征维度不高——线性模型/SVM 更稳更快；要求严格可解释性——神经网络是黑盒，需要额外可解释性工具（SHAP/探针）补救，成本高；数据有明显结构化先验（如表格数据强特征）——树模型（XGBoost/LightGBM）通常更优。

翻车长什么样？ 五种高频形态（每种都给了症状→根因→改法）：lr 爆炸（loss 跳到 17+ 震荡→降 lr/梯度裁剪）、梯度消失（前层不动→换 ReLU/残差连接）、过拟合（train 1.0 test 0.7→L2/早停/增数据）、死神经元（激活全 0→降 lr/换 LeakyReLU）、batch 噪声（loss 震荡→增大 batch/加动量）。训练前先做 §2.2 的梯度核对，能省掉 80% 的"为什么不收敛"排查时间。
