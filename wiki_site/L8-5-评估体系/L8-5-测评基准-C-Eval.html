C-Eval 是目前使用最广的中文知识类评测之一，特点有三个：按初中、高中、大学、专业四级难度分层；带一个专门拉开顶尖模型差距的 Hard 子集；test 集答案不公开，官方成绩必须把预测结果提交榜单。第三点决定了它的用法：本地能自测的只有 val 集（1346 题），那只是个"自检用的小样本"，误差大，不能当正式成绩。本文给出完整操作：下载数据、用 lm-evaluation-harness 与 OpenCompass 跑 val、用自写脚本跑 val 并按类别与难度汇总、生成 test 提交文件、读懂结果和避开常见错误。

一、是什么

2

C-Eval（Huang 等，2023，arXiv:2305.08322）是一份中文多学科四选一选择题库，共 13948 题，覆盖 52 个学科。数据按用途分三份：

子集 题数 是否带答案 用途
dev 260（每科 5 题） 带答案，还带解析（explanation） 做 few-shot 示例，解析可构造思维链示例
val 1346 带答案 本地自测、调模板、调超参
test 12342 不带答案 提交官方榜单取得正式成绩

学科按难度分四级：初中、高中、大学、专业（如法律职业资格、医师资格、会计师等考试），再按领域归为 STEM、社会科学、人文、其他四大类。C-Eval Hard 是其中最难的 8 个学科（高等数学、离散数学、概率统计、大学化学、大学物理、高中数学、高中化学、高中物理），需要多步推理，直答几乎无法得高分。论文发表时 GPT-4 的平均成绩约 68.7%，在 Hard 子集上只有约 54.9%，当时这个差距是它最有价值的地方。

三个基准的横向对比如下，选型时对照使用。

维度 MMLU CMMLU C-Eval
语言 英文 中文 中文
学科数 57 67 52
题量（约） 15908 11528 13948
难度分层 无显式分层 无显式分层 初中/高中/大学/专业，另有 Hard
中国语境 无 强（单列 China-specific 类） 中等（含中国职业资格考试）
本地可得完整成绩 是（test 公开） 是（test 公开） 否（需提交榜单，本地仅 val）
数据来源 英文公开考试与教材 中文考试与教材 中文模拟考试与真题改编
本地自测题量 14042 约 11528 1346
单次自测误差（95% 置信区间） 约 ±0.8 点 约 ±0.9 点 约 ±2.5 点
典型用途 英文能力、跨模型横比 中文知识与中国语境 中文难度分层、Hard 区分度

最后两行的数字由二项分布估算：准确率 p 约 0.5 到 0.7 时，95% 置信区间半宽约为 1.96 倍的 √(p(1−p)/n)。C-Eval val 的 1346 题给出约 ±2.5 点，所以在 val 上两个模型差 2 点以内，不能说谁更强。

二、为什么要用它3 个重点▾ 点开看本章重点
本章重点
  • 1. 它是中文模型的通用名片
  • 不要对单科分数下结论，只看大类汇总和整体趋势
  • 例如初中 85%、专业 55%，说明模型有常识但缺专业知识，该考虑补 RAG 或领域继续预训练；如果各级都低，通常是中文能力本身不足
2

1. 它是中文模型的通用名片。 国内发布的模型几乎都会报 C-Eval，榜单上能查到大量对手的成绩，做中文基座选型时这些数据是现成的参照系。

2. 难度分层能定位能力断层。 同一个模型在初中和专业两级的分差，反映知识深度。例如初中 85%、专业 55%，说明模型有常识但缺专业知识，该考虑补 RAG 或领域继续预训练；如果各级都低，通常是中文能力本身不足。MMLU 和 CMMLU 没有这种分层视角。

3. Hard 子集能拉开顶尖模型。 MMLU 在前沿模型上已经饱和，C-Eval Hard 偏理科多步推理，直答与带思维链的成绩差距巨大，适合考察推理增强是否真的有效。

4. 但它有几个必须带着用的限制。
- test 答案不公开，是为了防污染，同时意味着你无法本地复核榜单成绩，也无法对预测结果做错题分析。
- val 只有 1346 题，平均每科约 26 题，单科准确率的 95% 置信区间在 ±15 到 ±20 点。不要对单科分数下结论，只看大类汇总和整体趋势。
- 题目和答案已在网络流传多年，val 集尤其容易被训练语料覆盖，val 上分数高不等于 test 同样高。
- 提示模板敏感：直答、思维链、选项字母位置的细微变化都会引起几个点的波动。

5. 它和 MMLU、CMMLU 是互补关系。 MMLU 说明模型的英文通用知识，CMMLU 说明中文知识和中国语境，C-Eval 说明中文知识在不同难度上的分布。三者放在一起看，能回答"这个模型的短板在语言、在领域还是在难度"。例如 CMMLU 与 C-Eval 都高、MMLU 偏低，通常是中文强化模型；三者同步偏低，说明基座本身知识不足，换模型比调 prompt 更有效。

6. 它能为业务选型提供准入门槛。 做中文业务落地时，常见做法是设一个最低线，比如 C-Eval val 总分不低于某个基线模型减去误差范围，过了线才投入更贵的业务评测（golden set、人工评审）。这样可以先用几分钟的自动测评淘汰明显不合格的候选，把人工和算力留给通过初筛的模型。

所以 C-Eval 的定位是："榜单成绩"和"本地回归"两件事分开做。本地回归用 val 加上自己的私有题，榜单成绩靠提交 test。

先把 MMLU 与 CMMLU 一文 3.5 节 的 mc_eval.py 保存到工作目录，然后新建下面的 ceval_eval.py。它做三件事：加载 C-Eval 的学科中文名、在 val 上评测、按大类和难度汇总。

# ceval_eval.py  （与 mc_eval.py 放同一目录）
import csv, json, sys
from pathlib import Path
import mc_eval as m

m.HEAD["ceval"] = "以下是中国关于{subject}考试的单项选择题，请选出其中的正确答案。\n\n"
m.SUFFIX["ceval"] = "答案："

HARD = {
    "advanced_mathematics", "discrete_mathematics", "probability_and_statistics",
    "college_chemistry", "college_physics",
    "high_school_mathematics", "high_school_chemistry", "high_school_physics",
}


def load_mapping(root):
    mp = Path(root) / "subject_mapping.json"   # 若数据里附带：{学科: [英文名, 中文名, 大类]}
    if not mp.exists():
        return {}, {}
    raw = json.loads(mp.read_text(encoding="utf-8"))
    return {k: v[1] for k, v in raw.items()}, {k: v[2] for k, v in raw.items()}


def load_split(root, split, sub):
    return m.read_rows(Path(root) / split / f"{sub}_{split}.csv", header=True)


def group_acc(per, groups):
    out = {}
    for g, members in groups.items():
        sel = [per[s] for s in members if s in per]
        if sel:
            out[g] = sum(x["correct"] for x in sel) / sum(x["n"] for x in sel)
    return out


def run_val(root, scorer, k=5, limit=None):
    root = Path(root)
    subs = sorted(p.name[: -len("_val.csv")] for p in (root / "val").glob("*_val.csv"))
    names, cats = load_mapping(root)
    per, macro, micro = m.evaluate(
        "ceval", subs, lambda sp, s: load_split(root, sp, s), scorer,
        k=k, limit=limit, eval_split="val", names=names,
    )
    groups = {"Hard": HARD}
    for s, c in cats.items():
        groups.setdefault(c, set()).add(s)
    return per, macro, micro, group_acc(per, groups)


def predict_test(root, scorer, k=5):
    """生成官方提交格式 {学科: {id: 字母}}；提交前请对照榜单页面当前的格式说明"""
    root = Path(root)
    names, _ = load_mapping(root)
    result = {}
    for p in sorted((root / "test").glob("*_test.csv")):
        sub = p.name[: -len("_test.csv")]
        with open(p, newline="", encoding="utf-8-sig") as f:
            ids = [r["id"] for r in csv.DictReader(f)]
        dev, rows = load_split(root, "dev", sub), load_split(root, "test", sub)
        shown = names.get(sub, sub)
        result[sub] = {i: scorer(m.build_prompt("ceval", shown, dev, it, k), k) for i, it in zip(ids, rows)}
    return result


if __name__ == "__main__":
    mode, root, model_path, out = sys.argv[1:5]
    k = int(sys.argv[5]) if len(sys.argv) > 5 else 5
    limit = int(sys.argv[6]) if len(sys.argv) > 6 else None
    scorer = m.make_hf_scorer(model_path)
    if mode == "val":
        per, macro, micro, groups = run_val(root, scorer, k, limit)
        Path(out).write_text(json.dumps(
            {"macro": macro, "micro": micro, "groups": groups, "per": per}, ensure_ascii=False, indent=1))
        print(f"ceval val k={k} macro={macro:.4f} micro={micro:.4f}")
        for g, a in sorted(groups.items()):
            print(f"  {g}: {a:.4f}")
    else:
        Path(out).write_text(json.dumps(predict_test(root, scorer, k), ensure_ascii=False))
        print("submission written:", out)

运行：

3.5 汇总：按大类、按难度、Hard 单独报

3

脚本已输出大类分数和 Hard 分数。难度分层（初中/高中/大学/专业）需要按学科名归类：

难度 学科名特征
初中 文件名以 middle_school_ 开头
高中 文件名以 high_school_ 开头
大学 文件名以 college_ 开头，以及 advanced_mathematics、discrete_mathematics、probability_and_statistics 等大学课程
专业 各类职业资格考试，如 law、clinical_medicine、accountant 等

按前缀把 groups 字典补全即可，例如：

level = {"初中": "middle_school_", "高中": "high_school_", "大学": "college_"}
groups = {lv: {s for s in per if s.startswith(pre)} for lv, pre in level.items()}

报告里至少写这几行：整体（macro 与 micro）、四大类、四级难度、Hard。单科分数只放附录，不放结论，原因见第二节第 4 点。

3.6 提交 test 到官方榜单3 个重点▾ 点开看本节重点
本节重点
  • 1. 在官方榜单站点注册账号（入口见 C-Eval 仓库 README，本文不转录链接，避免过期）
  • 正确做法：用 val 和私有题调好所有设置，最后只提交一次
  • 以榜单提交页当前的格式说明为准，格式不符会被直接拒收
3
  1. 在官方榜单站点注册账号（入口见 C-Eval 仓库 README，本文不转录链接，避免过期）。
  2. 用 3.4 节生成 submission.json，格式为 {学科名: {题目 id: 选项字母}}，例如 {"computer_network": {"0": "A", "1": "C"}}。以榜单提交页当前的格式说明为准，格式不符会被直接拒收。
  3. 提交前自查：学科数应为 52，每科条目数等于对应 test csv 的行数，所有答案都是 A/B/C/D 之一，没有空值。下面的检查脚本可以在提交前跑：
import csv, json
from pathlib import Path

sub = json.loads(Path("submission.json").read_text(encoding="utf-8"))
root = Path("ceval/test")
problems = []
for p in sorted(root.glob("*_test.csv")):
    name = p.name[: -len("_test.csv")]
    with open(p, newline="", encoding="utf-8-sig") as f:
        n = sum(1 for _ in csv.DictReader(f))
    got = sub.get(name, {})
    if len(got) != n:
        problems.append((name, "题数", n, len(got)))
    if any(v not in ("A", "B", "C", "D") for v in got.values()):
        problems.append((name, "含非法答案"))
print("学科数", len(sub), "问题数", len(problems))
for x in problems:
    print(x)
  1. 提交次数和公开展示规则以榜单页面为准。常见约束是限制提交频率，并禁止针对 test 反复调参（不然 test 也会被"拟合"）。正确做法：用 val 和私有题调好所有设置，最后只提交一次。

3.7 提示模板与 shot 的取舍

3
设置 适用 注意
5-shot 直答 基座模型、与公布值对账 示例取 dev 前 5 题，不要换，否则不可比
0-shot 直答 已做指令微调的对话模型 对话模型常需套用其对话模板，否则偏低
5-shot 思维链 考察推理能力，尤其 Hard 子集 dev 的 explanation 可作为示例推理；输出长，必须用生成式解析，成本高
生成式（API） 无 logprobs 的接口 带推理的模型要放大 max_tokens，并标注"带推理"，与直答不可同榜

固定下来之后，所有后续回归都用同一套，不要为了"让分数好看"临时调模板。

3.8 对账与可信度控制3 个重点▾ 点开看本节重点
本节重点
  • 1. 先复现已知模型：拿一个公布过 C-Eval 成绩的小模型，用同样 5-shot 设置跑 val，与公布值（多数公布的是 test 或 val 平均）差距应在 val 误差范围（约 ±2.5 点）内
  • 要判断改动有效，在 val 之外补一份私有题，累计题量到 3000 以上再下结论
  • 6. Hard 子集单独看：Hard 的准确率可能只有 30% 到 50%，随机基线仍是 25%，要和直答、思维链两种设置分别对比，不要混报
3
  1. 先复现已知模型：拿一个公布过 C-Eval 成绩的小模型，用同样 5-shot 设置跑 val，与公布值（多数公布的是 test 或 val 平均）差距应在 val 误差范围（约 ±2.5 点）内。差得多，先查流程。
  2. val 成绩要标注为 val：对外不要把 val 成绩说成"C-Eval 成绩"，榜单成绩特指 test。
  3. 同尺子对比：量化、微调、换版本的前后比较，使用同一份脚本、同一硬件、同一精度，一次只改一个因素。
  4. 差异显著性：整体 micro 差小于 2.5 点视为噪声。要判断改动有效，在 val 之外补一份私有题，累计题量到 3000 以上再下结论。
  5. 污染自查：对 val 题干做续写，能近乎逐字续出选项则说明已被训练覆盖。此时 val 分数仅作流程自检，决策依据换成私有题。
  6. Hard 子集单独看：Hard 的准确率可能只有 30% 到 50%，随机基线仍是 25%，要和直答、思维链两种设置分别对比，不要混报。

3

报告放在 eval/reports/，文件名带日期和模型名。固定包含以下字段，缺一项别人就无法复现：

字段 示例

3.12 常见问答3 个重点▾ 点开看本节重点
本节重点
  • 问：val 成绩很高，能说模型"C-Eval 很强"吗
  • 按科看只用来定位"哪一类知识明显偏弱"，且只看趋势，不对单个数字下结论
  • 问：每科只有二十多题，为什么还要按科看
3

问：val 成绩很高，能说模型"C-Eval 很强"吗？ 不能。val 集公开了答案，被训练语料收录的概率高。val 只用来自检流程和做回归，榜单成绩特指 test。

问：每科只有二十多题，为什么还要按科看？ 按科看只用来定位"哪一类知识明显偏弱"，且只看趋势，不对单个数字下结论。想做可靠的分科判断，需要把私有题补到每科 100 题以上。

问：Hard 子集为什么直答分数那么低？ 这 8 科是理科多步推理，直答要求模型心算出结果。用思维链后分数常大幅提升，但输出长度和成本也同步上升，所以两种设置必须分开报告。

问：能不能把 CMMLU 和 C-Eval 的分数取平均当"中文能力"？ 不建议。两个基准的难度分布和汇总口径不同，平均后的数字没有明确含义，并排给出两个数更诚实。

问：test 提交失败怎么排查？ 先用 3.6 的自查脚本核对学科数、题数和答案合法性；再确认 id 取自 csv 的 id 列而非行号；最后查看榜单页面当前的格式要求有没有变化。
