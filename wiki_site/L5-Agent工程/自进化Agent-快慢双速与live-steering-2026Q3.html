自进化Agent：快慢双速与live-steering（2026 Q3）

WHY

2026 Q2-Q3 自进化 Agent 从"概念演示"进入"工程可用"阶段。六员体系若想持续进化、不被旧技能拖后腿，必须吸收三个核心方向：快慢双速固化、实时纠偏（live steering）、过程级评测（防退化）。本页汇总最对口的一手论文结论 + 我们能直接落地的改造点。

WHAT

一、快慢双速自进化框架（Experience Funnel）

  • 核心思路：交互轨迹先蒸馏成显式文本状态（技能/harness，快速可改可验证），再把跨状态修订仍有效的行为"transition-aware 蒸馏"进模型策略（慢速固化），两层交替循环。
  • 论文：arXiv 2609.08919（2026-09-08）
  • 为什么重要：纯文本技能改起来快但不可携带、纯参数微调更新太慢——快慢双速是工程上唯一可落地的折中。
  • 我们能直接用：显式文本状态层 = 我们已有的技能库 / AGENTS.md；只需实现"慢速层"的定期固化（把反复验证有效的技能沉淀为更强的流程规则），不需要微调。与 task_state 状态机天然衔接。

二、实时纠偏与当场蒸馏（PILOT supervisor-worker）

  • 核心思路：独立 supervisor 在执行中实时重定向/中止 worker（live steering），同时把执行中暴露的失败模式当场蒸馏成可复用技能与记忆（live self-evolution），而非等任务结束再复盘。
  • 论文：arXiv 2608.26530（2026-08-27）
  • 实测效果：Terminal-Bench 2.0 上最高 +9.8pp；自改进设定下 GLM-5.1 +14.6pp、Kimi-K2.6 +12.4pp；输出 token 降 42.9%/47.4%，每百万 token 成功评测数 +110%/+134%。
  • 我们能直接用：六员分工里"流程硬执行"角色天然就是 supervisor——审查员在第 1 轮发现问题时不是打回等下一轮，而是当场给执行者发 steering（改方向/中止），同时把该失败写进错误台账/技能草案。纯 prompt+流程改动，零新依赖。

三、过程级评测与技能回归门禁（EvoPathBench）

  • 核心思路：固定基座模型+工具，在演化检查点冻结记忆/技能工件，用留出任务评测三项能力：泛化、保持（retention）、规则适应。结论：被选中落地的演化更新普遍低于候选更新的潜力；"候选评估与选择"是关键瓶颈。
  • 论文：arXiv 2609.24663（2026-09-21）
  • 我们能直接用：给技能库加"技能变更回归检查"——每次 Workshop 技能 update 后，用固定样例集跑一次 verify，防止技能演化悄悄退化。这正是 receipt 门禁的自然延伸。

四、其他高价值方向（可选择性吸收）

  1. 跨任务模式自动提炼（AlgoEvo，arXiv 2609.15820）：把搜索轨迹组织成任务级树，跨任务共性模式固化为可复用技能。落地路径：每周让一个 agent 扫描本周 receipt/台账，重复≥2次的成功模式起草成技能提案，走 Workshop pending → 人审 apply。
  2. 免训练技能进化（Reflect, Revise, Reuse，arXiv 2609.17653）：不微调，通过"反思→修订→复用"三步自动迭代技能文档本身。映射到 skill_workshop 的 revise/patch 流：给技能加"失败即触发 revise 提案"的机制。
  3. 双轨事实记忆（MemSIF，arXiv 2608.01742）：CoreFact 写入时固化稳定事实；ActiveFact 按需成形，被多来源历史与反复查询需求支持后才"晋升"为长期事实。落地：给 MEMORY.md 加晋升规则——会话记忆先落草稿区，被第 2 次独立任务复用后才晋升进主记忆。

五、安全护栏（自进化的前置阀门，必看）

  1. Authority 坍缩问题（AuthMem-Bench，arXiv 2608.01679）：固化记忆时丢掉"这条信息允许被怎么用"的来源约束，记忆被赋予超过来源的权威。49个配置中48个存在该问题。自动标注并持久化 authority 标签后，未授权行动率 16.9% → 0.0%。
  2. 落地：每条记忆/技能必须带来源标签（人下令 / 已验证 receipt / 仅观察），低权威条目禁止被当指令执行。一行 frontmatter 约定即可。
  3. 自投毒攻击（EvoMal，arXiv 2608.25776）：自写工具的 coding agent 会把检索到的恶意技能当模板模仿，生成携带载荷的新技能并回写技能库，形成自传播蠕虫。153个 SWE-bench 任务上自投毒率 20.3%–41.8%。
  4. 落地：保持"自动起草、人审发布"不放松；从外部引入的技能（shared-skills 拉取）加静态扫描步骤。

HOW（落地三步）

  1. 第一步（本周）：技能变更回归门禁——workshop 发布技能前，跑固定 5 条样例集 verify，防退化。
  2. 第二步（下月）：supervisor 当场 steering——审查员发现问题当场发方向修正，不等下一轮；同时写错误台账。
  3. 第三步（长期）：记忆晋升机制——草稿区被第2次独立任务复用才晋升主记忆；技能带来源标签。
