Agent 怎么落地到具体业务：从 7 本书的项目案例提炼

← 返回总入口

这个问题的答案是什么

一句话：Agent 不是"通用智能助手"，而是"某个具体痛点的数字员工"——7 本书给出的 20+ 个落地案例，全部遵循同一个公式：一个明确的重复劳动 + 一个可验证的输出 + 一个能被工具化的数据源。

能落地的 vs 不能落地的，分界在哪：

能落地（数字员工） 不落地（玩具）
输入是结构化的（发票/标书/聊天记录） 输入是开放的"帮我想想"
输出可验证（对/错、过/不过） 输出只能主观评价
有现成工具能查真相（OCR/数据库/API） 只能靠模型脑补
人工原来就要花 1 小时以上 人工 5 分钟搞定，Agent 反而更慢

详细内容

一、7 本书的项目案例分类（按业务域）

A. 文档/票据处理类（最成熟） - 发票识别 Agent（《零基础搭建》第 7 章）：OCR + 字段抽取 + 结构化输出，"告别手动录入"。 - 标书阅读 Agent（第 8 章）：合规性检查，"减少标书违规"。 - 知识问答 Agent（第 9 章）：企业知识库 RAG，"让知识库活起来"。 - 财报检索 Agent（《动手做 AI Agent》第 8 章）：LlamaIndex + ReAct RAG。

B. 人机交互/陪练类 - 模拟面试官 Agent（第 10 章）：结构化面试流程。 - 小学生英语陪练 Agent（第 11 章）：多模态对话 + 引导逻辑。

C. 信息收集/内容生产类 - 旅游助手 Agent（第 12 章）：查航班、酒店、攻略。 - 抖音/小红书文案提取仿写 Agent（第 13 章）：短链抓取 + 风格仿写。 - 新闻播报智能体（第 4 章提到）：插件取新闻 + 卡片化输出。

D. 工程/自动化类 - 创作 PPT Agent（《动手做》第 4 章）：Assistants API + DALL·E 3。 - 鲜花定价 Agent（第 6 章）：ReAct + 外部 API 查询价格。 - 库存调度 Agent（第 7 章）：Plan-and-Execute。 - 辅助编程 Agent（《大模型项目实战》第 12 章）：AutoGen 多 Agent。 - 多智体图像应用（第 15 章）：Qwen-Agent + CogVLM2。

E. 企业监控类 - 运营/财务异常监控（《零基础搭建》划线上提到）：实时监控、发现异常、提醒排查——"财务造假、设备故障、合规风险"。

二、落地的 5 步通用流程（跨书提炼）

  1. 找痛点：挑一个"每周重复 ≥ 3 次、单次 ≥ 30 分钟、出错代价高"的活。《动手做》引的创业建议："初期专注特定、小规模业务场景，深入解决具体问题，而不是追求建立大型平台。"
  2. 定输入输出：输入是什么格式（PDF/Excel/聊天记录）、输出是什么格式（结构化 JSON / 卡片 / 邮件）。
  3. 选工具：哪些是 RAG（查知识库）、哪些是 FC（调 API）、哪些是代码执行（Python 算）。
  4. 搭循环：简单用 ReAct，复杂用 Plan-and-Execute，要质量加 Reflection。
  5. 接日志和回调：《零基础搭建》特别强调 LangChain 的回调处理器——"每次用户提问、链的运行状态、模型输出都记录到日志文件，出问题能快速定位"。这一步是从 demo 到生产的分水岭。

三、低代码 vs 代码：不同阶段的选型

（详见同目录《Coze-Dify-LangChain边界在哪》，这里只给落地视角的判断）： - 老板演示 / 1 周内要出结果 → Coze。发票识别、文案仿写这类，Coze 工作流节点拖一拖就出。 - 企业内网 / 数据不能出公司 → Dify 私有化。知识问答、标书阅读。 - 要断点续跑 / 多 Agent / 和业务系统耦合 → LangChain/LangGraph。库存调度、运营监控。

四、常见的失败模式（从书里反推）

  • 追求"通用 Agent"：一个 Bot 什么都能干 = 什么都干不好。7 本书所有成功案例都是单痛点。
  • 跳过 RAG 直接让模型答："大模型在专业领域（医疗/法律/企业内部知识）会回答不准、信息滞后"——这是《零基础搭建》划线上的第 1 名，2379 人同意。
  • 不做日志：用户反馈"回复异常"时无法定位。
  • 忽视数学/数字短板：《零基础搭建》第 3 章专门讲"为什么 AI 无法准确识别数字、为什么有数学逻辑短板"——涉及金额、数量的必须外挂计算器/代码执行，不能让模型心算。

来自哪些书的哪些观点

  • 《零基础搭建 Coze+Dify+LangChain》（徐洋）：13 个章节全部是业务案例，是"落地视角"最完整的一本。
  • 《动手做 AI Agent》（黄佳）：7 个 Agent 从简单到复杂（Assistants→FC→ReAct→Plan-and-Execute→RAG→AutoGen→多 Agent），是"技术栈递进"最清晰的一本。
  • 《大模型项目实战》（高强文）：覆盖 GLM-4/AgentScope/LangChain/LangGraph/AutoGen/CrewAI/LlamaIndex/Qwen-Agent 8 个框架的对比，是"框架选型"最丰富的一本。
  • 《Building Agentic AI Systems》：企业级视角——信任、安全、偏见、检查点恢复，是"生产化"视角。
  • 《MCP 原理与实战》/《一本书讲透 MCP》：当你的 Agent 要接 5+ 个外部系统时，工具层该用 MCP 而不是写 5 套集成。
